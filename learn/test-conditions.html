5.1 Big Test: If / elif / else

25 questions on If, elif and else only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    Reorder
Checked

    4 is less than 5, so the indented line runs. The last line is not indented, so it always runs.

  2. Basic. n = 37. Use if-else to print 37 is odd or 37 is even.

    Your code should print exactly:

    37 is odd
    Answer

    n % 2 == 0 is True for even numbers. else catches every other case.

  3. Basic. balance = 1500 and withdraw = 2000. If withdraw is more than balance, print Not enough balance. At the end, always print Done.

    Your code should print exactly:

    Not enough balance
Done
    Answer

    Only the indented line belongs to the if. The Done line is not indented, so it runs every time.

  4. Basic. This code should print Heat alert, but it crashes. Fix it.

    It should print:

    Heat alert
    Answer

    Every if line must end with a colon :.

  5. Basic. price = 899. If the price is 500 or more, print Free delivery. Otherwise print Delivery: ₹40.

    Your code should print exactly:

    Free delivery
    Answer

    >= means "500 or more", so 500 itself also gets free delivery.

  6. Basic. Type exactly what this code prints.

    Answer
    C

    Python checks from the top. 72 fails >= 90 and >= 75, then passes >= 60, so the grade is C and the rest is skipped.

  7. Basic. temp = 15. Print Cold if it is below 18, Pleasant if it is from 18 to 30, and Hot if it is above 30.

    Your code should print exactly:

    Cold
    Answer

    Once the first test fails, we already know temp is 18 or more, so the elif only needs to check <= 30.

  8. Basic. temp = 28 and humidity = 70. Print Good day for a walk if the temperature is from 20 to 30 AND the humidity is below 80. Otherwise print Stay in.

    Your code should print exactly:

    Good day for a walk
    Answer

    and needs both parts True. A chained comparison like 20 <= temp <= 30 checks a range in one go.

  9. Medium. order_value = 2600. Discount: 20% for 5000 or more, 10% for 2000 or more, 5% for 1000 or more, otherwise none. Print the amount to pay.

    Your code should print exactly:

    2340.0
    Answer

    Check the biggest slab first. 2600 fails >= 5000 and then matches >= 2000, so the discount is 10%.

  10. Medium. Sales of 120000 should print Gold, but this code prints Silver. Fix it.

    It should print:

    Gold
    Answer

    Python stops at the first True test. 120000 is also >= 50000, so the bigger limit must be checked first.

  11. Medium. Type exactly what this code prints.

    Answer
    one or two

    choice == 1 or 2 means (choice == 1) or 2. The 2 on its own is truthy, so the if is always True. Write choice == 1 or choice == 2.

  12. Medium. is_member = True and amount = 1200. Members get 10% off when the amount is 1000 or more, and 5% off otherwise. Non-members get no discount. Use a nested if and print the amount to pay.

    Your code should print exactly:

    1080.0
    Answer

    The outer if checks membership. Only members reach the inner if, which picks the discount.

  13. Medium. Type exactly what this code prints.

    Answer
    No name
City: Pune

    Empty text is falsy, so the first if goes to else. Text with letters is truthy.

  14. Medium. stock = 0. Use the ternary operator to store "In stock" or "Out of stock" in status, then print status.

    Your code should print exactly:

    Out of stock
    Answer

    A if condition else B picks one of two values in a single line.

  15. Medium. day = 6. Use match-case to print Weekday for 1 to 5, Weekend for 6 or 7, and Invalid day for anything else.

    Your code should print exactly:

    Weekend
    Answer

    | joins several values in one case. case _: catches everything else, like else.

  16. Medium. This code should print Working age, but it crashes. Fix it.

    It should print:

    Working age
    Answer

    Each side of and must be a full comparison: age > 18 and age < 60 (or 18 < age < 60).

  17. Medium. remarks = "". Print No remarks if it is empty, otherwise print the remarks. Use the truthiness of the text: do not compare it with "".

    Your code should print exactly:

    No remarks
    Answer

    Empty text is falsy, so if remarks: is False and the else runs.

  18. Medium. amount = 600. The discount rule is not decided yet. Write if amount > 500: with pass inside, then print Bill printed after the if.

    Your code should print exactly:

    Bill printed
    Answer

    A block cannot be empty. pass is a placeholder that does nothing, so the code runs without an error.

  19. Challenge. year = 1900. A year is a leap year if it divides by 400, or if it divides by 4 but not by 100. Print 1900 is a leap year or 1900 is not a leap year, using if-elif-else.

    Your code should print exactly:

    1900 is not a leap year
    Answer

    Order matters: test 400 first, then 100, then 4. 1900 divides by 100 but not by 400, so it is not a leap year.

  20. Challenge. a, b, c = 5, 5, 8 are the sides of a triangle. Print Not a triangle if any side is as long as the other two together or longer. Otherwise print Equilateral, Isosceles or Scalene.

    Your code should print exactly:

    Isosceles
    Answer

    Check the impossible case first with or. Then all equal, then any two equal. Here two sides are 5, so it is isosceles.

  21. Challenge. units = 260. The electricity bill charges ₹3 per unit for the first 100 units, ₹5 per unit for the next 100, and ₹8 per unit for the rest. Print Bill: ₹1280.

    Your code should print exactly:

    Bill: ₹1280
    Answer

    Each slab adds its own part: 300 for the first 100, 500 for the next 100, and 60 × 8 = 480 for the rest.

  22. Challenge. Type exactly what this code prints.

    Answer
    only a
a wins

    The outer test is True, the inner one is False, so only a prints. The last line is a one-line if, and 7 > 3.

  23. Challenge. user is not admin, so this code should print only Unknown user. It prints Welcome instead. Fix it with a nested if.

    It should print:

    Unknown user
    Answer

    The PIN check must sit inside the user check, and the else must belong to the user check.

  24. Challenge. Code 3 should print Refund, but this code crashes. Fix it.

    It should print:

    Refund
    Answer

    Inside case, several values are joined with |, not with or.

  25. Challenge. A form has email = "asha@mail.com" and phone = "". Print Complete if both are filled, Partial if only one is filled, and Empty if neither is. Use truthiness with and / or.

    Your code should print exactly:

    Partial
    Answer

    Filled text is truthy. Check and (both) first, then or (at least one). What is left is empty.
