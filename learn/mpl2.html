Matplotlib layouts and style: subplots, heatmaps and finishing touches

Go from one chart to a polished dashboard. Use the object way (fig, ax), put several charts in one figure, draw a correlation heatmap, and add the finishing touches: styles, clean axes, rupee labels, values on bars, annotations, a second y-axis, trend lines and insets.

In this chapter you will learn

  • Use the object way: fig, ax = plt.subplots() and ax.set_title()
  • Build multi-chart figures with plt.subplots(rows, cols) and fig.suptitle()
  • Draw a correlation heatmap with imshow, a colour bar and values in the cells
  • Style charts: colours, style sheets, legends, spines, ticks and a rupee axis
  • Add value labels, annotations, a second y-axis, a polyfit trend line and an inset chart

Figure and axes: the object way

There are two ways to write Matplotlib. The quick way uses plt. functions, which draw on "the current chart". The object way asks for the figure and its axes by name: fig, ax = plt.subplots(), then you call methods on ax. It is clearer, and you need it as soon as a figure holds more than one chart.

Quick way (plt.)Object way (ax.)
plt.plot(), plt.bar() ...ax.plot(), ax.bar() ...
plt.title("T")ax.set_title("T")
plt.xlabel() / plt.ylabel()ax.set_xlabel() / ax.set_ylabel()
plt.xticks(rotation=45)ax.tick_params(axis="x", rotation=45)
plt.xlim(0, 10)ax.set_xlim(0, 10)
plt.legend(), plt.grid()ax.legend(), ax.grid()
Trap!

ax.title("T") is an error: on an axes the names start with set_. ax.set_title("T"), ax.set_xlabel(...).

Several charts in one figure: subplots

plt.subplots(rows, cols) gives a figure and a grid of axes. With one row, pick a chart with axes[0]; with several rows, use axes[row, col]. fig.suptitle() puts one title over the whole figure.

Diagram: plt.subplots(2, 2) returns 4 axes in a 2 × 2 grid. Count rows and columns from 0, like a NumPy array.

Animated explainer: Building a dashboard step by step

  1. Step 1: fig, axes = plt.subplots(2, 2) makes the figure and four empty axes. Nothing is drawn yet.
  2. Step 2: axes[0, 0].plot(...) draws on the top-left chart only, and axes[0, 0].set_title(...) names it.
  3. Step 3: fill the other three with axes[0, 1], axes[1, 0] and axes[1, 1]. Look closely: titles and tick labels crowd each other.
  4. Step 4: fig.suptitle(...) adds one title over everything, and plt.tight_layout() spaces the charts so nothing overlaps.

Here is a real 2 × 2 sales dashboard, built from sales_data.csv like in the course notes. Each chart answers a different question.

The older one-at-a-time style also works: plt.subplot(rows, cols, n) picks chart number n (counting from 1), and the next plt. lines draw on it.

Predict the output

  1. (3, 2) 6
  2. (2, 3) 6
  3. (3, 2) 5
  4. 6 6
Answer

(3, 2) 6. 3 rows and 2 columns: the array has shape (3, 2), and the figure holds 6 axes.

Easy tip

Always end a multi-chart figure with plt.tight_layout(). Without it, titles and tick labels of neighbouring charts often overlap.

Heatmaps with imshow

A heatmap colours the cells of a grid by their value. The classic analyst heatmap is a correlation matrix (Chapter 26): which columns move together? plt.imshow() draws the colours, plt.colorbar() explains them, and a loop of plt.text() writes the numbers.

Read it like a table: the cell in row Sales and column Profit is 0.78, a strong positive link. The diagonal is always 1, because every column matches itself. vmin=-1, vmax=1 fixes the colour scale, so 0 is always the middle colour.

Easy tip

cmap="coolwarm" is a diverging colour scale (blue, white, red): good when values go negative. For counts or amounts that only go up, use one colour from light to dark, like cmap="Blues".

Colours, style sheets and legends

Colours can be names ("teal"), hex codes ("#E74C3C") or RGB tuples ((0.2, 0.4, 0.6)). A style sheet changes the look of every chart at once.

Trap!

A style stays on until you change it: in Jupyter it affects every later cell. Switch back with plt.style.use("default"). (On this site each code box starts fresh.) Try "seaborn-v0_8", "fivethirtyeight" or "bmh" too.

Spines, ticks and number formats

The spines are the four lines around a chart. Hiding the top and right ones gives a cleaner look. tick_params() styles the ticks, and a formatter changes how the axis numbers are written, for example in rupees.

plt.FuncFormatter takes a function with two inputs: the tick value and its position. It returns the text to show. f"₹{value:,.0f}" adds the rupee sign and commas, with no decimals.

Value labels and annotations

Readers like exact numbers on bars. ax.bar_label(bars) writes them for you. The course notes do it by hand with plt.text() at the top of each bar; both work.

ax.annotate() points an arrow at one spot: xy= is the point, xytext= is where the text sits. Use it to call out the peak.

Easy tip

With text labels on the x-axis (like month names), the positions are 0, 1, 2 ... So xy=(peak, value) uses the position of the peak, which argmax() gives you.

Two y-axes with twinx

To show two series with different units on one chart, like rupees and order counts, give the second series its own y-axis on the right: ax2 = ax1.twinx(). Colour each axis like its line, and combine the two legends into one.

Predict the output

  1. 2
  2. 1
  3. 3
  4. 0
Answer

2. twinx() adds a second axes to the same figure, so the figure now holds 2 axes. They share the x-axis.

Trap!

Each axes keeps its own legend. Calling ax1.legend() and ax2.legend() gives two boxes on top of each other; collect both with get_legend_handles_labels() for one legend.

Trend lines with polyfit

A trend line is the straight line that fits a scatter best. np.polyfit(x, y, 1) finds its slope and intercept (the 1 means a straight line), and np.poly1d() turns them into a function you can draw. R² (R squared, from 0 to 1) says how well the line fits.

The slope means "each extra ₹1 of sales brings about ₹0.15 more profit". transform=ax.transAxes places the text by share of the chart (0 to 1) instead of by data values, and text between $ signs is written as a maths formula.

Inset charts and global settings

An inset is a small chart inside a big one, for zooming in on a part. inset_axes(ax, width="40%", height="40%", loc="upper right") makes one.

plt.rcParams holds the default settings of every chart. Change them once at the top of a notebook to give all your charts the same look, and put them back with plt.rcdefaults().

    Hint

    Solution

    On an axes, every label method starts with set_.

  2. Make a figure with 1 row and 2 charts: on the left a line of [5, 8, 6, 9], on the right a histogram of [1, 2, 2, 3, 3, 3, 4] with 3 bins. Give each chart a title and the figure the title My first dashboard.

    Hint

    fig, axes = plt.subplots(1, 2), then axes[0].plot(...), axes[1].hist(...) and fig.suptitle(...).

    Solution

    One figure, two axes: each one gets its own drawing and title.

  3. Draw a bar chart of months = ["Jan", "Feb", "Mar"] and revenue = [125, 98, 143] with the value written on every bar (use ax.bar_label). Hide the top and right spines and add a title.

    Hint

    bars = ax.bar(...), ax.bar_label(bars), ax.spines["top"].set_visible(False) and the same for "right".

    Solution

    bar_label adds one text per bar, so the checker finds 3 texts.

  4. x = [1, 2, 3, 4, 5] and y = [2.1, 3.9, 6.2, 7.8, 10.1]. Draw them as a scatter, find the straight trend line with np.polyfit(x, y, 1) and draw it as a red line. Print the slope and intercept rounded to 2 decimals, and add a legend.

    Hint

    slope, intercept = np.polyfit(x, y, 1); then ax.plot(x, [slope * v + intercept for v in x], "r-", label=...).

    Solution

    The slope is about 2: y grows by 2 when x grows by 1.

  5. Draw a heatmap of grid = [[1, 0.8, -0.2], [0.8, 1, 0.1], [-0.2, 0.1, 1]] with plt.imshow and cmap="coolwarm", add a colour bar, and use the names ["Sales", "Profit", "Age"] on both axes.

    Hint

    plt.imshow(grid, cmap="coolwarm", vmin=-1, vmax=1), plt.colorbar(), plt.xticks(range(3), names) and plt.yticks(range(3), names).

    Solution

    xticks(positions, names) swaps the numbers 0, 1, 2 for the column names.

    Hint

    fig, axes = plt.subplots(1, 2, figsize=(10, 4)); axes[0].bar(...); axes[1].pie(counts.values, labels=counts.index, autopct="%1.1f%%").

    Solution

    Two different questions, one figure.

  2. Draw the monthly total profit as a line and mark the best month with ax.annotate and an arrow. Use a rupee formatter on the y-axis.

    Hint

    Group by dt.to_period("M"); best = profit.values.argmax(); ax.annotate("Best", xy=(best, profit.values[best]), xytext=..., arrowprops=dict(arrowstyle="->")).

    Solution

    November is the best month for profit too.

  3. Make a scatter of Customer_Age (x) against Satisfaction_Score (y), add a straight trend line with np.polyfit, and print R² (the squared correlation) rounded to 3 decimals. Label both axes.

    Hint

    slope, intercept = np.polyfit(x, y, 1) and np.corrcoef(x, y)[0, 1] ** 2.

    Solution

    R² is close to 0: age tells you almost nothing about satisfaction. A flat trend line says the same.

Key takeaways

  • fig, ax = plt.subplots() and ax. methods give you control; labels on an axes start with set_.
  • plt.subplots(r, c) returns a grid axes[row, col]; finish with fig.suptitle() and plt.tight_layout().
  • Heatmap: imshow(corr, cmap="coolwarm", vmin=-1, vmax=1) + colorbar() + xticks/yticks + text in a loop.
  • Clean style: hide top/right spines, a light grid behind the data, FuncFormatter for ₹, bar_label and annotate to tell the story.
  • twinx() for a second unit, np.polyfit(x, y, 1) for a trend line (R² for the fit), inset_axes to zoom, rcParams for every chart.

Chapter quiz
  1. Which line sets the title of the axes ax?
    1. ax.title("Sales")
    2. ax.set_title("Sales")
    3. ax.settitle("Sales")
    4. plt.ax.title("Sales")
    Answer
    ax.set_title("Sales"). Axes methods for labels start with set_.
  2. What does this print?
    1. (2, 2) 4
    2. (4,) 4
    3. (2, 2) 2
    4. 4 4
    Answer
    (2, 2) 4. A 2 × 2 grid: the axes array has shape (2, 2) and the figure holds 4 axes.
  3. In fig, axes = plt.subplots(2, 3), which chart is in the second row, last column?
    1. axes[2, 3]
    2. axes[1, 2]
    3. axes[2, 1]
    4. axes[1][3]
    Answer
    axes[1, 2]. Rows and columns count from 0: row 1, column 2.
  4. Why add vmin=-1, vmax=1 to plt.imshow() for a correlation matrix?
    1. To make it faster
    2. So the colour scale always runs from -1 to 1, with 0 in the middle
    3. To hide the diagonal
    4. To round the values
    Answer
    So the colour scale always runs from -1 to 1, with 0 in the middle. Without it the colours stretch to the smallest and largest value in this grid.
  5. What does ax.spines["top"].set_visible(False) do?
    1. Hides the title
    2. Hides the line along the top of the chart
    3. Hides the top tick labels
    4. Moves the legend
    Answer
    Hides the line along the top of the chart. Spines are the four border lines of the axes.
  6. You want sales in rupees on the left and the number of orders on the right. What do you use?
    1. plt.subplots(1, 2)
    2. ax2 = ax1.twinx()
    3. inset_axes
    4. plt.style.use()
    Answer
    ax2 = ax1.twinx(). twinx() makes a second y-axis that shares the x-axis.
  7. What does this print?
    1. [2. 1.]
    2. [1. 2.]
    3. [3. 0.]
    4. [2. 0.]
    Answer
    [2. 1.]. The points lie on y = 2x + 1: slope 2, intercept 1.
  8. What does transform=ax.transAxes mean in ax.text(0.05, 0.95, "...", transform=ax.transAxes)?
    1. The text is rotated
    2. 0.05 and 0.95 are shares of the chart's width and height, not data values
    3. The text goes on the x-axis
    4. The text is in bold
    Answer
    0.05 and 0.95 are shares of the chart's width and height, not data values. (0, 0) is the bottom-left corner of the axes and (1, 1) the top-right.
  9. After plt.style.use("ggplot") in Jupyter, what happens to the next cells' charts?
    1. Nothing
    2. They use the ggplot style too, until you change it
    3. Only the next one changes
    4. An error
    Answer
    They use the ggplot style too, until you change it. A style stays on. Switch back with plt.style.use("default").
  10. Which call writes the value on top of every bar?
    1. ax.bar_label(bars)
    2. ax.legend(bars)
    3. ax.set_xticks(bars)
    4. ax.grid(bars)
    Answer
    ax.bar_label(bars). bar_label adds one text per bar; fmt= sets the number format.
