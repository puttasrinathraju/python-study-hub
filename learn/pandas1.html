Pandas basics: Series, DataFrames and reading files

Meet the library every data analyst uses. Make Series and DataFrames, read CSV and Excel files, and give any new table a quick health check: its size, its types, its statistics, its gaps and its duplicates.

In this chapter you will learn

  • Make a Series and a DataFrame, and pick columns from it
  • Read CSV and Excel files, and save a DataFrame to a file
  • Look at the data with head(), tail() and sample()
  • Check a table with shape, info() and describe()
  • Count missing values with isna().sum() and repeats with duplicated()

What Pandas is

Pandas is the Python library for tables of data. If you know Excel or Power Query in Power BI, you already know the ideas: load a file, look at it, clean it, filter it, group it, summarise it. Pandas does the same jobs with a few lines of code that you can run again on next month's file.

Pandas has two main objects. A DataFrame is a whole table. A Series is one column of that table. Every row has a label called the index.

Diagram: A DataFrame. Column names run along the top, the index (0, 1, 2 ...) runs down the left, and each column, like the highlighted salary, is a Series.

Analysts spend most of their time loading, checking and cleaning tables. With Pandas every step is written down, so you can repeat it, share it and fix it, instead of clicking through the same menus every month.

Series: one labelled column

Make a Series from a list. Pandas adds the index 0, 1, 2 ... on the left. The last line, dtype, is the type of the values: int64 means whole numbers.

Animated explainer: How a Series pairs labels with values

  1. You start with three values in a list.
  2. index= gives each value a label. The first label goes with the first value, and so on.
  3. Now you can ask for a value by its label, like a dictionary: sales["Tue"] gives 950.
  4. Maths works on every value at once, like a NumPy array, and the labels stay attached.

Predict the output

  1. 160
  2. 70
  3. bc
  4. A KeyError
Answer

160. s["b"] is 70 and s["c"] is 90, so the sum is 160. Labels work like dictionary keys.

Think of it like this

A Series is a NumPy array with name tags. The values do the fast maths; the index is a tag on each value so you can find it by name.

DataFrame: a table of columns

The usual way to make a DataFrame is a dictionary of lists. Each key becomes a column name, and each list becomes that column's values. All the lists must be the same length.

Animated explainer: From a dictionary to a table

  1. A dictionary with 4 keys. Each value is a list of 5 items.
  2. The first key, "name", becomes the first column. Pandas adds the index 0 to 4 on the left.
  3. The next key becomes the next column, lined up row by row.
  4. With all 4 columns in place, each row is one person: row 1 is Vikram from HR in Delhi.
Trap!

staff["salary"] with one pair of brackets gives a Series. staff[["name", "salary"]] has a list inside the brackets, so it gives a smaller DataFrame. staff["name", "salary"] (no inner list) is a KeyError.

Predict the output

  1. (5, 4)
  2. (4, 5)
  3. 20
  4. 5
Answer

(5, 4). shape is always (rows, columns): 5 people, 4 columns.

Reading files

Real data comes from files. pd.read_csv() reads a CSV file into a DataFrame in one line. This site has a practice file, employees.csv: 41 rows of staff data with some messy values that you will clean in the next chapter.

Easy tip

read_excel needs the openpyxl package. On your laptop, run pip install openpyxl once. This site has it already.

Data also lives in databases and behind web APIs. These two need a network connection or a database server, so they do not run on this site. Try them on your laptop in Jupyter.

Trap!

Forgot index=False in to_csv? The file gets an extra column of row numbers. When you read it back you will see a column called Unnamed: 0. The fix is index=False when saving, or index_col=0 when reading.

Looking at the data: head, tail and sample

Never trust a file you have not looked at. head() shows the first 5 rows, tail() the last 5, and sample() a few random ones. Give a number to see more or fewer.

Easy tip

The ... in the middle means "some columns are hidden because the table is too wide for the screen". Pick the columns you want, like df[["name", "salary"]].head(). The last line tells you the real size: 5 rows x 8 columns.

Remember this

Look at the data before you analyse it. In just these few rows you can already see problems: extra spaces in names, bengaluru in small letters, and three different date styles.

Shape, info and describe

Three commands give you a health check of any table: shape (how big), info() (each column's type and how many values are filled in) and describe() (quick statistics of the number columns).

Easy tip

On your laptop, plain df.info() also prints a last line with the memory the table uses. We hide it here with memory_usage=False, because the number depends on the computer.

Read info() like this: 41 rows in total, but salary has only 38 non-null values, so 3 salaries are missing. float64 means decimal numbers (a number column with a gap always becomes decimal, so salary shows float64), and object usually means text. join_date is text too: Pandas does not know it is a date yet.

  2. 3

Answer

2. count() counts only the values that are filled in. The None is missing, so the count is 2, while len(df) is 3.

Missing values and duplicates

Missing cells show as NaN ("not a number"). isna() turns every cell into True (missing) or False (filled). Add .sum() and you get the number of missing cells in each column, because True counts as 1.

Animated explainer: How isna().sum() counts the gaps

  1. A small table. Three cells are empty (NaN).
  2. df.isna() gives a table of the same shape: True where a value is missing.
  3. .sum() adds up each column. True counts as 1, so you get the number of gaps: name 0, salary 2, score 1.

A duplicate is a row that appears twice. duplicated() marks every repeat (not the first copy) with True. You can check whole rows, or just an ID column.

Predict the output

  1. 2
  2. 3
  3. 1
  4. 4
Answer

2. The first E1 is not a duplicate. The second and third ones are, so the count is 2.

Trap!

Duplicates in an ID column are a problem. Duplicates in a category column, like department, are normal: many people work in IT. Always ask which column should be unique.

Key takeaways

  • A DataFrame is a table, a Series is one column, and the index labels the rows.
  • pd.DataFrame(dict_of_lists) builds a table: keys become columns. df["a"] is a Series, df[["a", "b"]] a DataFrame.
  • pd.read_csv() and pd.read_excel() load files; to_csv(..., index=False) saves them.
  • Always look first: head(), tail(), sample(), then shape, info() and describe().
  • isna().sum() counts gaps per column; duplicated().sum() counts repeated rows.

Flashcards

What is a DataFrame?
A table of data in Pandas: columns with names, and rows with an index.
What is a Series?
One column of a DataFrame: values with labels (the index).
What is the index?
The labels of the rows, shown on the left: 0, 1, 2 ... unless you choose your own.
df["a"] vs df[["a"]]
One pair of brackets gives a Series. A list inside the brackets gives a DataFrame.
How do you read a CSV file?

head() vs tail() vs sample()
First 5 rows, last 5 rows, random rows (random_state makes them repeat).

A tuple: (rows, columns).

Every column's type and how many values are filled in (non-null).
What does df.describe() show?
count, mean, std, min, 25%, 50% (median), 75% and max of each number column.

df.isna().sum()
How do you count duplicate rows?
df.duplicated().sum(): repeats after the first copy.

Usually text (strings). Numbers stored as text also show as object.
