24.1 Big Test: Cleaning data

25 questions on Cleaning data with Pandas only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. visits = pd.DataFrame({"guest": ["Om", "Lata", "Om"], "room": [101, 102, 101]}). Remove the repeated row and print the table.

    Your code should print exactly:

      guest  room
0    Om   101
1  Lata   102
    Answer

    drop_duplicates() keeps the first copy of each repeated row.

  2. Basic. rain = pd.Series([12, None, 30]). Fill the gap with 0 and print the values as a list.

    Your code should print exactly:

    [12.0, 0.0, 30.0]
    Answer

    No reading on a dry day can honestly mean 0 mm of rain.

  3. Basic. Type exactly what this code prints.

    Answer
    [4.0, 4.0, 4.0, 9.0]

    ffill() copies the last known value (4) down into both gaps. A column with gaps holds decimals, so you see 4.0.

  4. Basic. Read employees.csv, drop the email and city columns and print the new column names as a list.

    Your code should print exactly:

    ['emp_id', 'name', 'department', 'salary', 'score', 'join_date']
    Answer

    drop(columns=[...]) returns a table without those columns.

  5. Basic. names = pd.Series(["asha rao", "RAVI TEJA"]). Print the names in title case as a list.

    Your code should print exactly:

    ['Asha Rao', 'Ravi Teja']
    Answer

    .str.title() gives each word a capital first letter and small letters after it.

  6. Basic. This code should print ['Pune', 'Goa'], but it stops with an AttributeError. Fix it.

    It should print:

    ['Pune', 'Goa']
    Answer

    A Series has no strip() method. Add .str to use string methods on every value.

  7. Basic. Type exactly what this code prints.

    Answer
    ['Yes', 'N', 'Yes']

    replace() changes the values it finds in the dictionary and keeps the rest, so N stays.

  8. Basic. d = pd.Series(["2025-03-01", "2025-01-15"]). Turn it into dates and print the earliest one.

    Your code should print exactly:

    2025-01-15 00:00:00
    Answer

    Real dates can be compared, so min() finds the earliest.

  9. Medium. Read employees.csv and print how many rows are left after removing the rows with no score.

    Your code should print exactly:

    39
    Answer

    subset= makes dropna() look only at the columns you name.

  10. Medium. pay = pd.Series(["UPI", None, "Cash", "UPI"]). Fill the gap with the most common value and print the list.

    Your code should print exactly:

    ['UPI', 'UPI', 'Cash', 'UPI']
    Answer

    mode() returns a Series; [0] takes the most common value, UPI.

  11. Medium. This code should fill the gap with the average and print [10.0, 20.0, 30.0]. Fix the fill line.

    It should print:

    [10.0, 20.0, 30.0]
    Answer

    fillna() returns a new Series. Store the result, or the gap stays.

  12. Medium. Type exactly what this code prints.

    Answer
    [6.0, 6.0, nan]

    bfill() copies the next value up. The last gap has nothing below it, so it stays nan.

  13. Medium. Read employees.csv. Drop the rows whose score is below 60 and print how many rows remain.

    Your code should print exactly:

    35
    Answer

    Filter the rows you want to remove, then pass their .index to drop(). Rows with no score are not below 60, so they stay.

  14. Medium. Running this cell a second time should not crash: it should print the column names without email. Fix the drop line so it never raises a KeyError.

    It should print:

    ['emp_id', 'name', 'department', 'salary', 'score', 'join_date', 'city']
    Answer

    The second drop finds no email column. errors="ignore" skips names that are not there.

  15. Medium. amounts = pd.Series(["₹1,500", "₹320", "₹2,000"]). Remove the ₹ and the commas, turn the text into whole numbers, and print the total.

    Your code should print exactly:

    3820
    Answer

    Text cannot be added up. Remove the symbols first, then astype("int64").

  16. Medium. Read employees.csv and print how many email addresses contain yahoo. Missing emails count as no.

    Your code should print exactly:

    8
    Answer

    contains() gives True/False per row; na=False treats a missing email as False.

  17. Medium. Type exactly what this code prints.

    Answer
    ['Small', 'Medium', nan]

    map() looks up every value, and XL is not in the dictionary, so it becomes nan.

  18. Medium. d = pd.to_datetime(pd.Series(["2025-08-15", "2025-10-02"])). Print the day names as a list, then the dates as text in the style 15-Aug-2025.

    Your code should print exactly:

    ['Friday', 'Thursday']
['15-Aug-2025', '02-Oct-2025']
    Answer

    %d is the day, %b the short month name and %Y the full year.

  19. Challenge. Read employees.csv into raw, clean a copy: drop the duplicate row and the rows with no salary. Print the number of rows of raw and of the clean table.

    Your code should print exactly:

    41 37
    Answer

    Working on a copy keeps raw unchanged, so you can compare before and after.

  20. Challenge. Read employees.csv. Tidy the department names (strip the spaces, then title case) and print how many different departments there are now.

    Your code should print exactly:

    5
    Answer

    Twelve spellings become five. They read It and Hr now, not IT and HR: a replace() afterwards fixes those two.

  21. Challenge. Read employees.csv. Convert join_date (mixed styles, day first, bad values to NaT) and print how many people joined in 2022.

    Your code should print exactly:

    8
    Answer

    Convert first, then compare the year; NaT years are not equal to 2022, so they are not counted.

  22. Challenge. This code should read the date as 3 April 2025 and print 4. Fix the conversion.

    It should print:

    4
    Answer

    Without dayfirst=True, Pandas reads 03/04 as March 4.

  23. Challenge. Type exactly what this code prints.

    Answer
    59

    January has 31 days and February 2025 has 28, so the gap is 59 days.

  24. Challenge. This code should fill each gap with the last known value, and only the gap at the very start with the next value. Fix it.

    It should print:

    [30.0, 30.0, 30.0, 30.0, 26.0, 26.0]
    Answer

    The order matters. ffill() first fills every gap after a value with the last known value; then bfill() only has the gap at the start left to fill.

  25. Challenge. df = pd.DataFrame({"name": ["Asha Rao", "Om Shah"], "code": ["HYD", "BLR"]}). Split name into first and last, add a column city that maps HYD to Hyderabad and BLR to Bengaluru, and print the table without the name and code columns.

    Your code should print exactly:

      first  last       city
0  Asha   Rao  Hyderabad
1    Om  Shah  Bengaluru
    Answer

    Three cleaning tools in a row: split into columns, translate with map, then drop what you no longer need.
