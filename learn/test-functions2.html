15.1 Big Test: Functions advanced

25 questions on Functions: advanced tools only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    0 5 6

    *nums collects any number of arguments into a tuple, even none. The sum of an empty tuple is 0.

  2. Basic. Write largest(*nums) that returns the biggest of any number of values, using max(). Print largest(4, 19, 7).

    Your code should print exactly:

    19
    Answer

    Inside the function, nums is a tuple, so built-ins like max() work on it.

  3. Basic. Write show(**info) that prints each key and value as key: value. Call show(name="Asha", city="Pune").

    Your code should print exactly:

    name: Asha
city: Pune
    Answer

    **info collects the keyword arguments into a dictionary.

  4. Basic. Make a lambda called gst that adds 18% to a price, and print gst(100).

    Your code should print exactly:

    118.0
    Answer

    lambda parameter: expression is a tiny function that returns the expression.

  5. Basic. students = [("Asha", 82), ("Ravi", 67), ("Neha", 91)]. Sort them by marks, highest first, with key=lambda, and print the list of names.

    Your code should print exactly:

    ['Neha', 'Asha', 'Ravi']
    Answer

    The lambda tells sorted() what to compare: item 1 of each tuple, the marks.

  6. Basic. This code should print 1, but it crashes. Fix it with global.

    It should print:

    1
    Answer

    Assigning to count inside the function makes it local, so Python cannot read the old value. global count says: use the outside one. (Returning the new value is often cleaner.)

  7. Basic. Type exactly what this code prints.

    Answer
    50 100

    The x inside the function is a new local variable. The global x is not touched.

  8. Basic. This code should print 68, but it crashes. Fix the call.

    It should print:

    68
    Answer

    Passing the list makes numbers a tuple holding one list. *values unpacks the list into separate arguments.

  9. Medium. Write a recursive function power(base, exp) (for exp of 0 or more): anything to the power 0 is 1. Print power(2, 10).

    Your code should print exactly:

    1024
    Answer

    The base case (exp == 0) stops the recursion. Every other call makes the problem one step smaller.

  10. Medium. nums = [3, -1, 8, -5, 2]. Use filter() with a lambda to keep the negative numbers, and map() with a lambda to square every number. Print both lists.

    Your code should print exactly:

    [-1, -5]
[9, 1, 64, 25, 4]
    Answer

    filter() keeps the items where the lambda is True. map() applies the lambda to every item. Wrap both in list() to see them.

  11. Medium. Type exactly what this code prints.

    Answer
    10
20
30

    next() takes 10 from the iterator. The for loop then continues from where it left off.

  12. Medium. Write a generator evens(n) that yields the even numbers from 2 up to n. Print list(evens(10)).

    Your code should print exactly:

    [2, 4, 6, 8, 10]
    Answer

    yield hands out one value at a time. list() collects them all.

  13. Medium. The second call should print ['milk'], but it prints ['apple', 'milk']. Fix it.

    It should print:

    ['apple']
['milk']
    Answer

    A default list is made only once and shared by every call. Use None as the default and make a fresh list inside.

  14. Medium. Write order(item, qty=1, **notes) that prints 2 x Pizza, then each note as - key: value. Call order("Pizza", 2, spicy=True, table=4).

    Your code should print exactly:

    2 x Pizza
- spicy: True
- table: 4
    Answer

    Normal parameters are filled first. Every extra keyword argument lands in the notes dictionary.

  15. Medium. Type exactly what this code prints.

    Answer
    1 2 []

    Each next() runs to the next yield. After two values the generator is used up, so list(g) is empty.

  16. Medium. products = {"pen": 12, "ink": 45, "pad": 30}. Use max() with key=lambda on items() to print the most expensive product and its price.

    Your code should print exactly:

    ink 45
    Answer

    items() gives (name, price) pairs, and the lambda tells max() to compare the prices.

  17. Medium. Write make_counter() that returns an inner function. Each call of the inner function adds 1 to a counter (use nonlocal) and returns it. Make one counter, call it 3 times, and print the 3 results on one line.

    Your code should print exactly:

    1 2 3
    Answer

    nonlocal lets the inner function change a variable of the outer function. The counter remembers its value between calls.

  18. Medium. fact(5) should be 120, but this code prints 0. Fix the base case.

    It should print:

    120
    Answer

    Every result is multiplied by the base case, so a base case of 0 makes everything 0. 0! is 1.

  19. Challenge. Write a decorator shout that makes the text returned by a function upper case. Decorate greet(name), which returns f"hello {name}", and print greet("asha").

    Your code should print exactly:

    HELLO ASHA
    Answer

    The decorator returns a wrapper that calls the original function and changes its result. @shout swaps greet for that wrapper.

  20. Challenge. Write a recursive flatten(items) that turns nested lists into one flat list. Use isinstance(x, list) to spot an inner list. Print flatten([1, [2, [3, 4]], 5]).

    Your code should print exactly:

    [1, 2, 3, 4, 5]
    Answer

    When an item is itself a list, the function calls itself on it. Plain items are added directly.

  21. Challenge. Write a generator running_total(values) that yields the total so far after each value. Print list(running_total([5, 10, 20])).

    Your code should print exactly:

    [5, 15, 35]
    Answer

    The generator keeps total between yields, so each value builds on the last one.

  22. Challenge. Type exactly what this code prints.

    Answer
    hi
hi

    @twice replaces hi with wrapper, which calls the original hi two times.

  23. Challenge. words = ["cherry", "apple", "kiwi", "plum"]. Sort them by their LAST letter, using key=lambda, and print the list.

    Your code should print exactly:

    ['apple', 'kiwi', 'plum', 'cherry']
    Answer

    The lambda returns w[-1], so sorted() compares the last letters: e, i, m, y.

  24. Challenge. Write report(title, *values, **opts). It prints the title, a colon, then the total of values, with opts["unit"] in front when given. So report("Sales", 100, 250, unit="₹") prints Sales: ₹350 and report("Units", 3, 4) prints Units: 7.

    Your code should print exactly:

    Sales: ₹350
Units: 7
    Answer

    *values is a tuple of the numbers and **opts a dictionary of options. get() gives an empty unit when none was passed.

  25. Challenge. This code should print [1, 4, 9], but it crashes. Fix it so the function hands out every square.

    It should print:

    [1, 4, 9]
    Answer

    return ends the function with one number, and list() cannot loop over a number. yield turns the function into a generator of all the squares.
