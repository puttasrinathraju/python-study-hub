Part 2 projects: decisions and loops

Three programs that keep asking for data until the work is done, make decisions with if, and summarise the results. They use Part 1 and Part 2 only: no lists, no string methods and no functions yet.

In the interactive version you write each program in the browser, run it with your own numbers, and press Submit to get an automatic score out of 100 with feedback. A score of 70 or more means you are ready for the next project.

Project 2.1 (Beginner): Daily bills summary

Read any number of bills and summarise the day.

Kiran runs a small electronics repair shop in Vijayawada. Every customer gets a bill, and some days there are 3 bills, other days 30. At closing time he wants a quick summary: how many bills, the total, the average, the biggest and smallest bill, and how many big bills (₹1,000 or more) there were.

Write a program that first asks how many bills there were today, then asks for each bill amount with a loop, and prints the summary.

What you will practise

  • Repeat a question with a for loop and range()
  • Keep running totals and counts inside a loop
  • Track the highest and lowest value with if
  • Handle the "no data" case before dividing

You may use: everything from Part 1, if / elif / else, for loops with range(), += to add up and count.
Do not use yet: lists [ ], string methods like .lower(), indexing [0], your own functions, import, max(), min(), sum().

Your tasks

  1. Ask How many bills today? with input() and convert it with int().
  2. If there are 0 bills, print Bills entered: 0 and No bills today, and nothing else.
  3. Otherwise, use a for loop with range() to ask for each bill amount (Bill 1 amount: , Bill 2 amount: ...). Amounts can have paise, so use float().
  4. Inside the loop, add each amount to a running total, and count the big bills (₹1,000 or more).
  5. Inside the loop, also keep the highest and the lowest bill seen so far. The first bill is both the highest and the lowest so far.
  6. After the loop, work out the average: the total divided by the number of bills.
  7. Print the summary lines exactly as shown below, with money as ₹ + :,.2f.
  8. Add comments that explain your steps.

Lines your output must contain

Bills entered: <count>
Total: ₹<amount>
Average bill: ₹<amount>
Highest bill: ₹<amount>
Lowest bill: ₹<amount>
Big bills (₹1,000 or more): <count>

<amount> means money with commas and 2 decimals (:,.2f), like 4,350.50. <count> is a plain whole number. With 0 bills, print only Bills entered: 0 and No bills today.

Example run

Typed values: 5, 1200, 350.50, 800, 1800, 200.

How many bills today? 5
Bill 1 amount: 1200
Bill 2 amount: 350.50
Bill 3 amount: 800
Bill 4 amount: 1800
Bill 5 amount: 200
Bills entered: 5
Total: ₹4,350.50
Average bill: ₹870.10
Highest bill: ₹1,800.00
Lowest bill: ₹200.00
Big bills (₹1,000 or more): 2

Edge cases to think about

  • 0 bills: you cannot divide by 0, so check for it before working out the average.
  • Just 1 bill: it is the total, the average, the highest and the lowest.
  • A bill of exactly ₹1,000 counts as big (>=).
  • The first bill is the biggest (or the smallest): make sure your highest and lowest still come out right.
  • A bill of ₹0, big amounts, and numbers typed with spaces.

Hint 1

Read the count first: bill_count = int(input("How many bills today? ")). Then if bill_count == 0: print the two lines, and put everything else under else:.

Hint 2

Project 2.2 (Intermediate): Class marks and grades

Grade every student as the marks come in, then summarise the class.

Mrs. Lakshmi teaches a Python batch at a training institute in Hyderabad. After each test she types the marks into a spreadsheet and works out the grades by hand.

Write a program that keeps asking for marks until she types done. Each valid mark gets a grade at once. Marks below 0 or above 100 are typing mistakes: the program says so and skips them. At the end it prints a class summary: how many students, the average, how many passed, how many got each grade, and the highest and lowest marks.

What you will practise

  • Keep a while True loop going until the user types a stop word
  • Skip bad data with continue
  • Choose one of five grades with if / elif / else
  • Count per category and summarise after the loop

You may use: everything from Part 1, if / elif / else, while True, break, continue, for loops.
Do not use yet: lists [ ], string methods like .lower(), indexing [0], your own functions, import, max(), min(), sum().

Your tasks

  1. In a while True loop, ask for the next student's marks with input(). The question can be like Marks for student 1 (or done): .
  2. If the user typed done (exactly, small letters), leave the loop with break.
  3. Otherwise convert the text to a whole number with int().
  4. If the marks are below 0 or above 100, print Invalid marks, skipped and go to the next round with continue. Skipped entries do not get a student number.
  5. For a valid mark, give a grade: A for 90 or more, B for 75 or more, C for 60 or more, D for 35 or more, F below 35. Print Student 1: 78 -> Grade B.
  6. Keep a count of students, the total of the marks, the number passed (35 or more), a count for each grade, and the highest and lowest marks.
  7. After the loop: if no valid marks were entered, print No marks entered. Otherwise print the summary lines shown below.
  8. Use clear names and add comments.

Lines your output must contain

Student <n>: <marks> -> Grade <letter>
Invalid marks, skipped
Students: <count>
Class average: <number>
Passed: <count> of <count>
Grades: A=<count> B=<count> C=<count> D=<count> F=<count>
Highest: <marks>
Lowest: <marks>

<number> has 2 decimals (:.2f), like 61.80. Marks and counts are plain whole numbers. Print Invalid marks, skipped only when an entry is out of range, and No marks entered (instead of the summary) when there were no valid marks.

Example run

Typed values: 78, 92, 45, 28, 66, done.

Marks for student 1 (or done): 78
Student 1: 78 -> Grade B
Marks for student 2 (or done): 92
Student 2: 92 -> Grade A
Marks for student 3 (or done): 45
Student 3: 45 -> Grade D
Marks for student 4 (or done): 28
Student 4: 28 -> Grade F
Marks for student 5 (or done): 66
Student 5: 66 -> Grade C
Marks for student 6 (or done): done
Students: 5
Class average: 61.80
Passed: 4 of 5
Grades: A=1 B=1 C=1 D=1 F=1
Highest: 92
Lowest: 28

Edge cases to think about

  • The user types done straight away: no students, so no average (do not divide by 0).
  • Boundary marks like 90, 75, 60 and 35 get the higher grade (>=).
  • Marks of 0 and 100 are valid. -5 or 101 are not.
  • Only one student: they are the highest and the lowest.
  • Marks typed with spaces, like 78 : int() ignores the spaces. (done is always typed exactly.)

Hint 1

Start your counters before the loop: count = 0, total = 0, passed = 0, and one per grade like grade_a = 0. Inside while True: read entry = input(...) and check if entry == "done": break before you call int().

Project 2.3 (Challenging): Loan repayment schedule

Simulate a loan month by month and catch the cases that never end.

A small finance company in Guntur gives business loans to shop owners. Before a loan is signed, the analyst prints a repayment schedule: month by month, the interest added, the amount paid (the EMI) and the balance left.

To keep the numbers simple, the company works in whole rupees: each month the interest is the balance × the monthly rate ÷ 100, rounded down with //. The interest is added first, then the EMI is paid. In the last month the customer pays only what is left.

Some requests are impossible: if the EMI is not bigger than the first month's interest, the loan would grow or stay the same forever. And the company never schedules more than 120 months.

What you will practise

  • Simulate a process month by month with a while loop
  • Stop a loop on two conditions (paid off, or 120 months)
  • Catch the inputs that would make a loop run forever
  • Print a clean schedule with comma formats

You may use: everything from Part 1, if / elif / else, while loops, break, // for rounding down, :, for commas.
Do not use yet: lists [ ], string methods like .lower(), indexing [0], your own functions, import, max(), min().

Your tasks

  1. Ask for 3 whole numbers with input(), in this order: the loan amount, the monthly interest rate in % (like 1 or 2), the monthly EMI. Convert each with int().
  2. If the loan is 0, print Nothing to repay and stop.
  3. If the EMI is not more than the first month's interest (loan × rate // 100), print EMI too low: the loan would never be repaid and stop.
  4. Otherwise repeat, month by month, while there is a balance left and fewer than 120 months have passed: interest = balance × rate // 100; add it to the balance; pay the EMI, or only the balance if that is smaller; take the payment off the balance.
  5. Print one line per month: Month 1: interest ₹1,000, paid ₹10,000, balance ₹91,000.
  6. Add up the total interest and the total paid as you go.
  7. After the loop: if the balance is 0, print Months to repay: <months>. If not, print Not repaid in 120 months. Balance left: ₹<amount>. Then print Total interest and Total paid.
  8. Use clear names and comments: other analysts will read your code.

Lines your output must contain

Month <n>: interest ₹<amount>, paid ₹<amount>, balance ₹<amount>
Months to repay: <n>
Not repaid in 120 months. Balance left: ₹<amount>
Total interest: ₹<amount>
Total paid: ₹<amount>
Nothing to repay
EMI too low: the loan would never be repaid

All amounts are whole rupees with commas (:,), like ₹91,000. Print only the lines that apply: Months to repay when the loan is paid off, Not repaid in 120 months... when it is not, and the two stop messages only for those cases.

Edge cases to think about

  • Allowed values: whole numbers, loan 0 or more, rate 0 or more, EMI more than 0.
  • A loan of 0: nothing to schedule.
  • An EMI that only covers the interest (or less): the loop would run forever. Catch it before the loop.
  • An EMI just above the interest: the loan takes more than 120 months, so stop at 120.
  • The last payment is smaller than the EMI: pay only what is left, so the balance ends at exactly 0.
  • A 0% rate loan: no interest at all.
