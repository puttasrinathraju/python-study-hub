8.1 Big Test: Strings

25 questions on Strings in depth only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    HELLO hello

    upper() makes every letter capital and lower() makes every letter small.

  2. Basic. word = "Python". Print its first and its last character.

    Your code should print exactly:

    P n
    Answer

    Index 0 is the first character and -1 is always the last one.

  3. Basic. s = "data". Use a slice to print the two middle letters.

    Your code should print exactly:

    at
    Answer

    [1:3] starts at index 1 and stops before index 3.

  4. Basic. Type exactly what this code prints.

    Answer
    True False

    isdigit() is True only when every character is a digit. The dot in 20.5 is not a digit.

  5. Basic. word = "python". Print it in capital letters, then how many characters it has.

    Your code should print exactly:

    PYTHON 6
    Answer

    upper() gives the capital version and len() counts the characters.

  6. Basic. city = " goa ". Print it with the spaces removed from both ends, inside square brackets.

    Your code should print exactly:

    [goa]
    Answer

    strip() removes the spaces at both ends. The brackets show that no spaces are left.

  7. Basic. This code should print the last letter of the name, but it crashes. Fix it.

    It should print:

    a
    Answer

    "Asha" has 4 letters, at indexes 0 to 3, so index 4 does not exist. name[-1] (or name[3]) is the last letter.

  8. Basic. line = "red,green,blue". Split it at the commas and print the list you get.

    Your code should print exactly:

    ['red', 'green', 'blue']
    Answer

    split(",") cuts the text at every comma and gives a list of strings.

  9. Medium. s = "Python". Print its last 3 characters using a negative slice.

    Your code should print exactly:

    hon
    Answer

    -3 starts three characters from the end. With no stop, the slice runs to the end.

  10. Medium. Type exactly what this code prints.

    Answer
    adg

    A step of 3 takes every third character: indexes 0, 3 and 6.

  11. Medium. s = "Python". Print it backwards.

    Your code should print exactly:

    nohtyP
    Answer

    A step of -1 walks from the end to the start: [::-1] reverses any string.

  12. Medium. This code should print Asha, but it crashes. Fix it.

    It should print:

    Asha
    Answer

    Strings cannot be changed in place: they are immutable. Build a new string and store it back. (name = name.capitalize() also works.)

  13. Medium. text = "banana". Print how many times a appears, then the position of the first n.

    Your code should print exactly:

    3 2
    Answer

    count() counts the matches. find() gives the position of the first match (and -1 if there is none).

  14. Medium. Type exactly what this code prints.

    Answer
    True False

    startswith() and endswith() care about capitals. Report starts with a capital R.

  15. Medium. This code should print 1300, but it crashes. Fix it.

    It should print:

    1300
    Answer

    int() cannot read the comma. Remove it first with replace(",", ""), then convert.

  16. Medium. raw = " aSHA reddy ". Print the name cleaned up: no extra spaces, and a capital first letter on each word.

    Your code should print exactly:

    Asha Reddy
    Answer

    strip() removes the spaces and title() fixes the capitals. You can chain them.

  17. Medium. word = "education". Use a loop to count the vowels (a, e, i, o, u) and print the count.

    Your code should print exactly:

    5
    Answer

    A loop visits one character at a time, and ch in "aeiou" checks if it is a vowel.

  18. Medium. date = "2026 10 30". Print it as 2026-10-30 using split() and join().

    Your code should print exactly:

    2026-10-30
    Answer

    split() cuts at the spaces, then "-".join(...) glues the pieces with - between them.

  19. Challenge. email = "raman@company.in". Use find() and slicing to print the name, then the domain in capitals.

    Your code should print exactly:

    raman COMPANY.IN
    Answer

    find("@") gives the position of @. [:at] stops before it and [at + 1:] starts just after it.

  20. Challenge. This code should print the list of words, but it prints something strange. Fix it.

    It should print:

    ['learn', 'python', 'every', 'day']
    Answer

    Without brackets, text.split is the method itself, not its result. Add () to run it.

  21. Challenge. Type exactly what this code prints.

    Answer
    data_analyst

    Chained methods run left to right. strip() goes first, so only the middle space becomes _.

  22. Challenge. This code should print found, because "FUN" is in the text. Fix it.

    It should print:

    found
    Answer

    in cares about capitals. Make the text small with lower() first, then search for the small word.

  23. Challenge. text = "data is fun". Reverse each word but keep the words in the same order.

    Your code should print exactly:

    atad si nuf
    Answer

    Loop over text.split(), reverse each word with [::-1], and add it to a result string. strip() removes the last extra space.

  24. Challenge. word = "Level". Print True if it reads the same backwards (a palindrome), ignoring capital letters.

    Your code should print exactly:

    True
    Answer

    Make it small first, so L and l match. Then compare it with its reversed copy.

  25. Challenge. phone = "9848012345". Hide every digit except the last 4 with *.

    Your code should print exactly:

    ******2345
    Answer

    phone[-4:] keeps the last 4 digits. "*" * n repeats the star once for every hidden digit.
