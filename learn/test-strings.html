8.1 Big Test: Strings

25 questions on Strings in depth only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Which of these is a string?

    1. "42"
    2. 42
    3. 42.0
    4. True
    Answer

    A. "42"

    Anything inside quotes is a string, even digits. 42 is an int, 42.0 is a float and True is a bool.

  2. Basic. What does this print?

    1. 7
    2. 8
    3. 9
    4. 2
    Answer

    B. 8

    len() counts every character, and the space counts too: H, i, space, t, h, e, r, e = 8.

  3. Basic. What does this print?

    1. P n
    2. P o
    3. y n
    4. An error
    Answer

    A. P n

    Index 0 is the first character and -1 is the last one.

  4. Basic. What does this print?

    1. at
    2. ata
    3. da
    4. dat
    Answer

    A. at

    The start (1) is included and the stop (3) is not, so you get indexes 1 and 2: a and t.

  5. Basic. What does this print?

    1. HELLO hello
    2. Hello hello
    3. HELLO HELLO
    4. hello HELLO
    Answer

    A. HELLO hello

    upper() makes every letter capital and lower() makes every letter small.

  6. Basic. Which method removes the spaces at both ends of " hi "?

    1. strip()
    2. split()
    3. replace()
    4. trim()
    Answer

    A. strip()

    strip() cleans both ends. lstrip() and rstrip() clean one side. Python has no trim().

  7. Basic. What do you get from "a,b,c".split(",")?

    1. A list of strings: ['a', 'b', 'c']
    2. One string: 'a b c'
    3. A number: 3
    4. Nothing: it changes the original string
    Answer

    A. A list of strings: ['a', 'b', 'c']

    split() cuts the text at every comma and gives back a list. The original string does not change.

  8. Basic. word = "python". Print it in capital letters, then how many characters it has.

    Your code should print exactly:

    PYTHON 6
    Answer

    upper() gives the capital version and len() counts the characters.

  9. Medium. What does this print?

    1. hon
    2. Pyt
    3. ho
    4. n
    Answer

    A. hon

    -3 starts three characters from the end. With no stop, the slice goes to the end.

  10. Medium. What does this print?

    1. adg
    2. abc
    3. cfh
    4. beh
    Answer

    A. adg

    A step of 3 takes every third character: indexes 0, 3 and 6, which are a, d and g.

  11. Medium. What does this print?

    1. 3 2 -1
    2. 3 2 0
    3. 2 2 -1
    4. 3 3 -1
    Answer

    A. 3 2 -1

    There are 3 a's. The first n is at index 2. find() gives -1 when the text is not there.

  12. Medium. This code should print Asha, but it crashes. Which line should replace line 2?

    It should print:

    Asha

    Replace line 2 with:

    1. name = "A" + name[1:]
    2. name[0] = name[0].upper()
    3. name[0].upper()
    4. name.upper()
    Answer

    A. name = "A" + name[1:]

    Strings cannot be changed in place: they are immutable. Build a new string and store it back in name. (name = name.capitalize() also works.)

  13. Medium. What does this print?

    1. True False
    2. True True
    3. False False
    4. False True
    Answer

    A. True False

    startswith() and endswith() care about capitals. Report starts with a capital R, not r.

  14. Medium. What does this print?

    1. 2026-10-30
    2. 2026 - 10 - 30
    3. -2026-10-30
    4. 2026-10-30-
    Answer

    A. 2026-10-30

    split() cuts at the spaces, then join() puts - between the pieces, never at the ends.

  15. Medium. This code should print 1300, but it crashes. Which line should replace line 2?

    It should print:

    1300

    Replace line 2 with:

    1. total = int(price.replace(",", "")) + 50
    2. total = int(price.strip()) + 50
    3. total = price + 50
    4. total = int(price) + "50"
    Answer

    A. total = int(price.replace(",", "")) + 50

    int() cannot read the comma. Remove it first with replace(",", ""), then convert.

  16. Medium. qty is text typed by a user, like "12" or "12a". Which check makes sure it has only digits before you use int(qty)?

    1. qty.isdigit()
    2. qty.isalpha()
    3. qty.isupper()
    4. len(qty) > 0
    Answer

    A. qty.isdigit()

    isdigit() is True only when every character is a digit, so int() will not crash.

  17. Medium. raw = " aSHA reddy ". Print the name cleaned up: no extra spaces, and a capital first letter on each word.

    Your code should print exactly:

    Asha Reddy
    Answer

    strip() removes the spaces and title() fixes the capitals. You can chain them: raw.strip().title().

  18. Medium. word = "education". Use a loop to count the vowels (a, e, i, o, u) and print the count.

    Your code should print exactly:

    5
    Answer

    A loop visits one character at a time. ch in "aeiou" checks if it is a vowel.

  19. Challenge. s = "Python". What happens with s[10] and with s[2:10]?

    1. s[10] gives an IndexError, s[2:10] gives 'thon'
    2. Both give an IndexError
    3. Both give ''
    4. s[10] gives '' and s[2:10] gives an error
    Answer

    A. s[10] gives an IndexError, s[2:10] gives 'thon'

    One index must exist, or you get an IndexError. A slice is forgiving: it just stops at the end of the string.

  20. Challenge. This code should print the list of words, but it prints something strange. Which line should replace line 2?

    It should print:

    ['learn', 'python', 'every', 'day']

    Replace line 2 with:

    1. words = text.split()
    2. words = text.split(",")
    3. words = text.join()
    4. words = split(text)
    Answer

    A. words = text.split()

    Without brackets, text.split is the method itself, not its result. Add () to run it.

  21. Challenge. This code should print found, because "FUN" is in the text. Which line should replace line 2?

    It should print:

    found

    Replace line 2 with:

    1. if "fun" in text.lower():
    2. if "fun".upper() in text.lower():
    3. if text.lower() in "fun":
    4. if "Fun" in text:
    Answer

    A. if "fun" in text.lower():

    in cares about capitals. Make the text small with lower() first, then search for the small word.

  22. Challenge. What does this print?

    1. raman COMPANY.IN
    2. raman@ COMPANY.IN
    3. raman @COMPANY.IN
    4. ramanCOMPANY.IN
    Answer

    A. raman COMPANY.IN

    find() gives the position of @ (5). [:at] stops before it and [at + 1:] starts just after it.

  23. Challenge. What does this print?

    1. data_analyst
    2. _data_analyst_
    3. __data_analyst__
    4. Data_Analyst
    Answer

    A. data_analyst

    Chained methods run left to right. strip() goes first, so only the middle space becomes _.

  24. Challenge. text = "data is fun". Reverse each word but keep the words in the same order.

    Your code should print exactly:

    atad si nuf
    Answer

    Loop over text.split(), reverse each word with [::-1], and add it to a result string. strip() removes the last extra space.

  25. Challenge. What does this print?

    1. True
    2. False
    3. level
    4. An error
    Answer

    A. True

    lower() makes it level, and level reversed is still level, so they are equal: a palindrome.
