The while loop

A while loop keeps running its block as long as its condition is True. Before every round, Python checks the condition again. When it becomes False, the loop stops.

Every while loop needs three parts: a starting value (no = 1), a condition (no <= 5), and an update (no += 1). The update makes the condition False in the end.

Trap! The infinite loop

Forget the update and the condition never becomes False, so the loop runs forever. In Jupyter, press the square Stop button (or Kernel > Interrupt Kernel). In Colab, click the stop icon on the cell.

for or while?

UseWhenExample
forYou know what to loop over, or how many timesEvery item in a list, numbers 1 to 100
whileYou loop until something happens, and you do not know whenKeep asking until the user types a valid number; keep saving until you reach a target

while True with break

A very common pattern: start a loop that would run forever (while True) and leave it with break when you are done. This is how menus, games and input checks work.

Animated explainer: while True and break, step by step

  1. count starts at 1.
  2. while True means the condition is always True. Only break can get us out.
  3. Print 1.
  4. count becomes 2.
  5. Is 2 > 3? No. So no break. Back to the top.
  6. Print 2.
  7. count becomes 3.
  8. Is 3 > 3? No. Back to the top.
  9. Print 3.
  10. count becomes 4.
  11. Is 4 > 3? Yes.
  12. break exits the loop immediately.
  13. Python continues with the first line after the loop.

break, continue and pass

StatementWhat it doesThink of it as
breakExits the loop completely, right now"I'm done, leave the loop"
continueSkips the rest of this round and starts the next round"Skip this one, carry on"
passDoes nothing at all"Placeholder, nothing to do here"

Animated explainer: break vs continue vs pass on the numbers 1 to 9

  1. break: when i reaches 6, the whole loop stops. 6, 7, 8 and 9 are never visited (grey).
  2. continue: even numbers (yellow) skip the print, but the loop keeps going to the next number.
  3. pass: does nothing. Number 3 is still printed, because pass does not skip anything.
Trap! break only leaves the innermost loop

In nested loops, break exits only the loop it is directly inside. The outer loop carries on.

Predict the output

  1. 1 2
  2. 1 2 4 5
  3. 1 2 3 4 5
  4. 0 1 2 4
Answer

1 2 4 5. When n is 3, continue skips the print. The loop goes on to 4 and 5. Notice n += 1 comes before continue. If it came after, the loop would get stuck at 3 forever.

Slides: break, continue and pass

  1. Three small words that steer any loop.

  2. break: stop the loop now

  3. continue: skip this round only

  4. pass: do nothing (yet)

  5. Nested loops: break leaves one level

  6. Rule of thumb

    • Found what you need? break
    • This item is bad but others may be fine? continue
    • Python needs a line here but you have nothing yet? pass

while-else

Like for-else, a while loop can have an else block that runs when the condition becomes False normally, but not after a break.

Key takeaways

  • while condition: repeats while the condition is True. Always update something so it can end.
  • while True: + break is the standard pattern for menus and input checks.
  • break leaves the loop. continue skips to the next round. pass does nothing.
  • break exits only the innermost loop.
  • Use for when you know what to loop over. Use while when you loop until something happens.

Flashcards

Three parts every while loop needs
A starting value, a condition, and an update inside the loop that eventually makes the condition False.
What is an infinite loop and how do you stop one in Jupyter?
A loop whose condition never becomes False. Press the Stop button or Kernel > Interrupt Kernel.
The while True pattern
break vs continue
break leaves the loop. continue skips the rest of this round and moves to the next round.
What does pass do?
Nothing. It is a placeholder.
Does break exit all nested loops?
No. Only the innermost loop it is in.
When should you use while instead of for?
When you repeat until something happens and you do not know how many rounds that takes.
