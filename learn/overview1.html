Part 1 overview: the Python basics

All of Part 1 on one page: how Python runs, variables and data types, printing, and operators. Read the tables, run the examples, then test yourself with the mixed quiz.

The whole Part in 5 lines

  1. Python runs your code from top to bottom, one line at a time. print() shows results and # starts a comment.
  2. A variable is a name that points at a value. = stores a value. == asks if two values are equal.
  3. The five basic types are int, float, str, bool and None. input() always gives you a str.
  4. f-strings build clean output: f"Total: {total:,.2f}".
  5. / always gives a float, // gives whole groups and % gives the remainder. and, or and not combine conditions.

Key definitions

Every word you need from Part 1, each with a tiny example. If one feels shaky, tap the chapter link on its card.

Program

A list of instructions. Python runs them from the top line to the bottom line.

Comment

A note for humans. Python ignores everything after # on that line.

Indentation

The 4 spaces at the start of a line. After a line that ends in :, indented lines belong to that block.

Variable

A name that points at a value. Create it with =, then use the name anywhere below.

Data type

The kind of value: whole number, decimal, text, True/False or nothing. type() tells you which.

Boolean (bool)

Only two values: True and False. Every comparison gives one of them.

None

A special value meaning "no value yet". It is not 0 and not an empty string.

Type casting

Converting a value to another type with the type's name: int(), float(), str(), bool().

Escape character

A backslash code inside a string: \n new line, \t tab, \\ one backslash.

f-string

A string with an f in front. Anything inside { } is worked out and dropped in.

Operator and operand

An operator is the symbol that does the work (+, >, and). The values it works on are the operands.

Precedence

The order operators run in: brackets, **, then * / // %, then + -, then comparisons, then not, and, or.

Try it yourself

Each task mixes ideas from more than one chapter of this Part. Type in the box and press Run. Every comparison table above also has an Edit and run this example button, so you can change the numbers and see what happens.

  1. A shop sells 3 shirts at ₹499.50 each. Add 18% tax and print Total: ₹1,768.23 using an f-string with a thousands comma and 2 decimals.

    Hint

    Work out price * qty * 1.18, then use {total:,.2f} inside the f-string.

    Solution

    * does the maths, 1.18 adds 18%, and :,.2f adds the comma and rounds the display to 2 decimals.

  2. minutes = 135. Print 2 h 15 min using // and %.

    Hint

    Hours are the full groups of 60. Minutes are what is left over.

    Solution

    // counts the full hours and % gives the leftover minutes.

  3. n = 17. In one line, store "even" or "odd" in a variable called kind, then print 17 is odd.

    Hint

    Use the ternary a if cond else b with n % 2 == 0 as the condition.

    Solution

    n % 2 is 1 for odd numbers, so the condition is False and the else value is picked.

  4. The text qty = "12" came from input(). Convert it, then print Packs of 5: 2, loose: 2.

    Hint

    Convert with int() first. Then use // and % with 5.

    Solution

    Text from input() must be converted before maths. Then // gives full packs and % gives the loose items.

    3. <class 'int'>

    Answer

    1. 3 1
    2. 3.5 1
    3. 3 0.5
    4. 4 1
    Answer

    3 1. 2 goes into 7 three whole times (//) with 1 left over (%).

    1. -3
    2. -4
    3. -3.5
    4. 3
    Answer

    -4. // always rounds down. -3.5 rounded down is -4.

  4. What does this print?

    1. 50
    2. 400
    3. 146
    4. 110
    Answer

    50. ** first: 4 ** 2 = 16. Then *: 3 * 16 = 48. Then +: 2 + 48 = 50.

  5. What does this print?

    1. Hi there
    2. Hi-there
    3. Hi-there-
    4. Hithere
    Answer

    Hi-there. sep goes between the items, and only between them.

  6. What does this print?

    1. True
    2. False
    3. An error
    4. 0.3
    Answer

    False. Decimals are stored in binary and are not exact. 0.1 + 0.2 is 0.30000000000000004.

  7. What does this print?

    1. 1234.50
    2. 1,234.50
    3. 1,234.5
    4. 1.234,50

  8. What happens here?

    1. It prints 30
    2. It prints 255
    3. A TypeError
    4. It prints "255"
    Answer

    A TypeError. You cannot add text and a number. Convert first: int("25") + 5.

    2. 2nd_place
    3. my-name
    4. class
    Answer

    2. 4 4

    4. 4 3

    2. True False

Flashcards

Name the five basic data types
int (whole numbers), float (decimals), str (text), bool (True/False) and None (no value).
/ vs // vs %
/ always gives a float (7 / 2 = 3.5). // gives whole groups, rounded down (7 // 2 = 3). % gives the remainder (7 % 2 = 1).
= vs ==
= stores a value in a name. == asks whether two values are equal and gives True or False.
When do you use is?
Only to check for None: if x is None:. Use == for everything else.
What type does input() give you?
Always str, even if the user types a number.
int(3.9) vs round(3.9)
int() cuts the decimals: 3. round() goes to the nearest: 4.
What is round(2.5)?
2. A .5 rounds to the nearest even number, so round(3.5) is 4.
Format a number with commas and 2 decimals
Use :,.2f inside an f-string.
sep= vs end= in print()
sep goes between the items (default a space). end goes after the last item (default a new line).
and / or / not in one line each
and: both must be True. or: at least one must be True. not: flips True and False.
Order of operations
Brackets, **, * / // %, + -, comparisons, not, and, or.
What does a colon plus indentation mean?
The colon opens a block. The indented lines below it belong to that block.
