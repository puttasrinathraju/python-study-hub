13.1 Big Test: Comprehensions & choosing

25 questions on Comprehensions and choosing the right collection only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    [3, 6, 9, 12]

    The comprehension runs n * 3 for n = 1, 2, 3 and 4, and collects the answers in a list.

  2. Basic. prices = [100, 250, 80]. Use a list comprehension to make a new list with each price doubled, and print it.

    Your code should print exactly:

    [200, 500, 160]
    Answer

    [expression for item in list]: the expression is worked out once for every item.

  3. Basic. ages = [12, 25, 17, 40, 15]. Use a list comprehension to keep only the adults (18 or more), and print the list.

    Your code should print exactly:

    [25, 40]
    Answer

    An if at the end is a filter: it decides which items get in.

  4. Basic. cities = [" delhi", "PUNE ", "goa"]. Clean them with strip() and title() in a list comprehension, and print the list.

    Your code should print exactly:

    ['Delhi', 'Pune', 'Goa']
    Answer

    Any expression works in a comprehension, including chained string methods.

  5. Basic. Print the sum of the squares of 1 to 10, using a generator expression inside sum().

    Your code should print exactly:

    385
    Answer

    A generator expression has no square brackets. sum() takes its values one at a time without building a list.

  6. Basic. This code should replace negative numbers with 0 and print [0, 7, 0], but it crashes. Fix it.

    It should print:

    [0, 7, 0]
    Answer

    A filter if (at the end) cannot have an else. To change values, put x if ... else ... at the front, before for.

  7. Basic. Type exactly what this code prints.

    Answer
    ['low', 'high', 'high']

    The ternary at the front picks a value for every item, so the list always has 3 items.

  8. Basic. This code should print [1, 4, 9], but it crashes. Fix it.

    It should print:

    [1, 4, 9]
    Answer

    The comprehension opens with [, so it must close with ].

  9. Medium. emails = ["A@x.in", "a@x.in", "b@x.in"]. Use a set comprehension with lower() to get the different emails, and print them sorted.

    Your code should print exactly:

    ['a@x.in', 'b@x.in']
    Answer

    Curly brackets make a set comprehension: values that become equal after lower() are kept once.

  10. Medium. words = ["tea", "coffee", "juice"]. Make a dictionary of each word and its length with a dictionary comprehension, and print it.

    Your code should print exactly:

    {'tea': 3, 'coffee': 6, 'juice': 5}
    Answer

    A dictionary comprehension has key: value before the for.

  11. Medium. Type exactly what this code prints.

    Answer
    [(0, 'x'), (0, 'y'), (1, 'x'), (1, 'y')]

    With two fors, the first one is the outer loop: for each i, the inner loop runs through x and y.

  12. Medium. weeks = [[3, 5], [2], [4, 1, 6]]. Flatten it into one list with a nested comprehension, and print it.

    Your code should print exactly:

    [3, 5, 2, 4, 1, 6]
    Answer

    Read it like two nested loops: for each week, for each number in that week.

  13. Medium. This code should change only the first row and print [[9, 0, 0], [0, 0, 0]]. Fix it.

    It should print:

    [[9, 0, 0], [0, 0, 0]]
    Answer

    [row] * 2 repeats the same inner list twice, so both rows change together. A comprehension makes a new row each time.

  14. Medium. marks = [45, 82, 30, 67]. Print a list with "P" or "F" for each mark (35 or more passes). Then print a second list with only the passing marks.

    Your code should print exactly:

    ['P', 'P', 'F', 'P']
[45, 82, 67]
    Answer

    Transform: the ternary goes at the front and every item gets a value. Filter: the if goes at the end and some items are dropped.

  15. Medium. Type exactly what this code prints.

    Answer
    [2, 3] 2

    The set keeps the different lengths (2 and 3). sum(1 for ... if ...) counts the matching items.

  16. Medium. visits = [101, 102, 101, 103]. Store the unique visitor IDs in the right collection, and the fixed location 17.38, 78.48 in the right collection. Print the number of unique IDs and the two types, with one print().

    Your code should print exactly:

    3 <class 'set'> <class 'tuple'>
    Answer

    Unique values belong in a set. A fixed pair that never changes belongs in a tuple.

  17. Medium. stock = {"pen": 0, "ink": 4, "pad": 0, "gel": 9}. Use a dictionary comprehension to keep only the items that are in stock (more than 0), and print it.

    Your code should print exactly:

    {'ink': 4, 'gel': 9}
    Answer

    Loop over items() to get both key and value, and filter with if at the end.

  18. Medium. This code should print Hyderabad, but it crashes. Fix it.

    It should print:

    Hyderabad
    Answer

    A list can change, so it is not hashable and cannot be a key. A tuple is immutable and works as a key.

  19. Challenge. matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]. Make a list of the even numbers in the matrix with one nested comprehension, and print it.

    Your code should print exactly:

    [2, 4, 6, 8]
    Answer

    Both fors come first (outer, then inner), and the filter goes at the very end.

  20. Challenge. sales = {"Mon": 1200, "Tue": 800, "Wed": 1500}. With one print(), show the total (a generator expression over values()) and a dictionary of the days above 1000 (a dictionary comprehension).

    Your code should print exactly:

    3500 {'Mon': 1200, 'Wed': 1500}
    Answer

    A generator expression feeds sum() directly, and the dictionary comprehension filters the days in one line.

  21. Challenge. raw = ["12", "NA", "7", "", "30"]. Use one list comprehension to keep only the entries that are made of digits (isdigit()) and turn them into ints. Print the list and its sum.

    Your code should print exactly:

    [12, 7, 30] 49
    Answer

    The filter runs first, so int() only sees text that really is a number. An empty string is not isdigit().

  22. Challenge. Type exactly what this code prints.

    Answer
    [1, 2, 3] (1, 2)

    += changes a list in place, so a sees it too. A tuple cannot change, so u += (3,) makes a new tuple and t stays the same.

  23. Challenge. m = [[1, 2, 3], [4, 5, 6]]. Transpose it (rows become columns) with a nested comprehension, and print the result.

    Your code should print exactly:

    [[1, 4], [2, 5], [3, 6]]
    Answer

    The outer comprehension builds one new row per column index i; the inner one takes item i from every old row.

  24. Challenge. This code should print the different words, sorted: ['data', 'python']. Fix it.

    It should print:

    ['data', 'python']
    Answer

    A set has no index. sorted() turns it into a sorted list that you can print or index.

  25. Challenge. names = ["Asha", "ravi", "Anil", "neha"]. Make a dictionary of each name in title case and its length, only for names that start with "a" in any case. Print it.

    Your code should print exactly:

    {'Asha': 4, 'Anil': 4}
    Answer

    Make the check case-proof with lower(), then build key: value with title() for the key.
