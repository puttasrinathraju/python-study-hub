4.1 Big Test: Operators

25 questions on Operators only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    3.4 3 2

    / gives the exact answer as a float. // keeps only the whole part, and % gives the remainder: 17 is 3 fives and 2 left over.

  2. Basic. A teacher has students = 47 and makes groups of 6. Print the number of full groups and the number of students left over, with one print().

    Your code should print exactly:

    7 5
    Answer

    // counts the full groups (7) and % gives what is left (5).

  3. Basic. Use ** to print 2 to the power 10, and then the square root of 144, with one print().

    Your code should print exactly:

    1024 12.0
    Answer

    ** means power. A power of 0.5 is the square root, and it comes out as a float: 12.0.

  4. Basic. a = 45 and b = 60. Print whether a is less than b, and whether they are equal, with one print().

    Your code should print exactly:

    True False
    Answer

    Comparisons give True or False. Use == (two signs) to test if two values are equal.

  5. Basic. This code should print True, but it crashes. Fix it.

    It should print:

    True
    Answer

    One = stores a value. Two == compare. Inside print() you want the comparison.

  6. Basic. balance = 5000. Add a salary of 1500 using +=, then pay 2000 rent using -=. Print the balance.

    Your code should print exactly:

    4500
    Answer

    x += 5 is short for x = x + 5, and -= works the same way for taking away.

  7. Basic. Type exactly what this code prints.

    Answer
    False True False

    and needs both sides True. or needs at least one. not flips the value.

  8. Basic. job = "Data Analyst". Print whether "Analyst" is in it, and whether "analyst" is in it, with one print().

    Your code should print exactly:

    True False
    Answer

    in checks if a piece of text is inside another. Capital letters matter, so "analyst" is not found.

  9. Medium. Type exactly what this code prints.

    Answer
    8 10.0 -9

    - and + (and / and *) are equal, so Python goes left to right. ** runs before the minus sign, so -3 ** 2 is -(3 ** 2).

  10. Medium. A video is total = 500 seconds long. Print it as 8 min 20 sec using // and %.

    Your code should print exactly:

    8 min 20 sec
    Answer

    total // 60 gives the whole minutes and total % 60 gives the seconds left over.

  11. Medium. n = 4738. Print its last digit, and whether n is even, with one print().

    Your code should print exactly:

    8 True
    Answer

    % 10 gives the last digit. A number is even when n % 2 is 0.

  12. Medium. This code should print the average of the two marks, 85.0, but it prints 125.0. Fix it.

    It should print:

    85.0
    Answer

    / runs before +, so only b was divided. Brackets make the addition happen first.

  13. Medium. Type exactly what this code prints.

    Answer
    3

    Follow it step by step: 10, then 15, then 30, then 30 // 4 is 7, then 7 % 4 is 3.

  14. Medium. temp = 37.8. Normal body temperature is from 36.1 to 37.2. Print whether temp is normal, using ONE chained comparison.

    Your code should print exactly:

    False
    Answer

    A chained comparison like a <= x <= b checks both limits at once. 37.8 is above 37.2, so it is False.

  15. Medium. marks = 47. The pass mark is 35. Use the ternary operator to print Pass or Fail.

    Your code should print exactly:

    Pass
    Answer

    A if condition else B gives A when the condition is True, and B when it is False.

  16. Medium. Type exactly what this code prints.

    Answer
    True False False

    Text compares letter by letter, and capital letters come before small ones. 7 and 7.0 are equal in value, so != is False.

  17. Medium. discount = None means no discount was set yet. Print whether discount is None, using is. Then set discount = 0 and print the same check again.

    Your code should print exactly:

    True
False
    Answer

    Use is to check for None. Zero is a real value, so 0 is None is False.

  18. Medium. This code should print Even, but it crashes. Fix it.

    It should print:

    Even
    Answer

    The ternary operator always needs both parts: A if condition else B. The else was missing.

  19. Challenge. A server ran for total = 200000 seconds. Print it as 2 d 7 h 33 m 20 s (days, hours, minutes, seconds). A day has 86400 seconds and an hour has 3600.

    Your code should print exactly:

    2 d 7 h 33 m 20 s
    Answer

    Take out the biggest unit with //, then use % to keep what is left for the next unit. % and // are equal, so total % 86400 // 3600 runs left to right.

  20. Challenge. A loan is approved if the salary is at least 30000 AND the credit score is above 700, OR the person has a guarantor. With salary = 28000, score = 760 and guarantor = True, print whether the loan is approved.

    Your code should print exactly:

    True
    Answer

    The salary check fails, so the and part is False. But or guarantor is True, so the loan is approved. Brackets make the grouping clear.

  21. Challenge. n = 472. Use // and % to print the sum of its three digits.

    Your code should print exactly:

    13
    Answer

    n // 100 is the first digit (4), n // 10 % 10 is the middle one (7) and n % 10 is the last one (2).

  22. Challenge. You invest amount = 10000 and it grows by 10% a year. Use *= to grow it once for each of 3 years. Then print it rounded to 2 decimal places.

    Your code should print exactly:

    13310.0
    Answer

    Growing by 10% means multiplying by 1.1. Floats can show tiny errors, so round(..., 2) gives a clean 13310.0.

  23. Challenge. email = "ravi.k@gmail.com". Print True if it has an @, has a ., and has no space. Use in, not in and and.

    Your code should print exactly:

    True
    Answer

    Each membership test gives True or False. and joins them: all three must be True.

  24. Challenge. This code should print False, but it crashes when x is 0. Fix it by changing the order, not the numbers.

    It should print:

    False
    Answer

    and stops as soon as one side is False. Put the safe check x != 0 first, and the division never runs when x is 0.

  25. Challenge. This code should take 30 away from the stock and print 90, but it prints -30. Fix it.

    It should print:

    90
    Answer

    =- is really = -30: it stores minus 30. The take-away operator is -=, with the minus first.
