27.1 Big Test: Matplotlib charts

25 questions on Matplotlib charts: line, bar, histogram, scatter, pie and box only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Draw a line chart of the weekly sales [230, 260, 245, 310] for the weeks ["W1", "W2", "W3", "W4"] with round markers, and the title Weekly sales.

    Your code should print exactly:

    Answer
    plt.plot(x, y, marker="o") joins the points in order and puts a dot on each.
  2. Basic. This should be a bar chart comparing the three shops, but it draws a line. Fix it.
    It should print:
    Answer
    Categories are compared with bars: plt.bar(names, values). A line suggests an order in time that shops do not have.
  3. Basic. Type exactly what this code prints.
    Answer
    4 2
    plt.bar returns one bar per value. The third bar (index 2) is 2 tall.
  4. Basic. waits = [3, 5, 6, 8, 9, 10, 12, 13, 15, 21] are minutes customers waited. Draw a histogram with 4 bins and the x label Minutes.
    Your code should print exactly:
    Answer
    bins=4 cuts the range from 3 to 21 into 4 equal parts.
  5. Basic. This chart should have a legend with Tea and Coffee, but no legend appears. Fix the two plot lines.
    It should print:
    Answer
    A legend lists the label= of each series. Without labels there is nothing to list, and Matplotlib warns you.
  6. Basic. Draw a pie chart of the expenses [45, 30, 25] labelled ["Rent", "Food", "Travel"], with the percent and 1 decimal on every slice.
    Your code should print exactly:
    Answer
    autopct="%1.1f%%" writes each share with 1 decimal and a % sign.
  7. Basic. Type exactly what this code prints.
    Answer
    [1.0, 2.0, 3.0]
    3 equal bins from 1 to 3: one 1, two 2s, three 3s.
  8. Basic. Draw a scatter plot of hours = [1, 2, 3, 4, 5, 6] (x) against marks = [35, 48, 55, 61, 72, 80] (y), with both axis labels.
    Your code should print exactly:
    Answer
    One dot per student; the dots climb, so more study goes with higher marks.
  9. Medium. rooms = {"Deluxe": 42, "Suite": 9, "Standard": 65, "Family": 23}. Draw horizontal bars sorted from smallest to largest (so the biggest is at the top), with an x label.
    Your code should print exactly:
    Answer
    barh draws the first item at the bottom, so sorting from small to large puts the biggest on top.
  10. Medium. Plot the monthly rainfall of two cities for ["Jun", "Jul", "Aug"]: Mumbai [500, 840, 590] with a solid line and Chennai [50, 90, 120] with a dashed line. Add a legend.
    Your code should print exactly:
    Answer
    Two plot calls draw two lines; the label= values fill the legend.
  11. Medium. This code should draw a histogram of the marks with 5 bins, but it stops with a TypeError. Fix it.
    It should print:
    Answer
    plt.bar needs categories and heights. To count raw numbers into ranges, use plt.hist(values, bins=5).
  12. Medium. Draw grouped bars for the regions ["North", "South", "East"]: 2023 sales [40, 55, 30] and 2024 sales [48, 60, 35]. Shift them by 0.2 with width 0.4, put the region names under the groups and add a legend.
    Your code should print exactly:
    Answer
    Shifting each series half a bar left or right puts them side by side; plt.xticks(x, regions) names the groups.
  13. Medium. Type exactly what this code prints.
    Answer
    3
    Three x/y pairs in one plot() call draw three lines.
  14. Medium. Draw stacked bars for ["Q1", "Q2", "Q3"]: online sales [30, 42, 51] with shop sales [25, 22, 28] on top of them. Add a legend.
    Your code should print exactly:
    Answer
    bottom=online starts each shop bar where the online bar ends.
  15. Medium. Draw one box plot for each of three batches, a = [55, 60, 62, 65, 70, 90], b = [40, 45, 52, 58, 61] and c = [70, 72, 75, 78, 80, 82], with the names Batch A, Batch B, Batch C under the boxes.
    Your code should print exactly:
    Answer
    Give boxplot a list of groups; the boxes stand at x = 1, 2, 3, which xticks names.
  16. Medium. This pie chart should show each share as a percent, like 40.0%, but the labels show plain numbers. Fix the format.
    It should print:
    Answer
    %% prints a real % sign after the number.
  17. Medium. Draw a scatter of price = [100, 150, 200, 250, 300] (x) against units = [90, 70, 52, 40, 25] (y), coloured by rating = [4.5, 4.2, 3.9, 3.5, 3.1] with cmap="viridis", and add a colour bar labelled Rating.
    Your code should print exactly:
    Answer
    c= colours each dot by a third value and plt.colorbar() explains the colours.
  18. Medium. Draw a bar chart of ["Mon", "Tue"] and [12, 18], save it as days.png with dpi=120, show it, and then print whether the file exists (use os.path.exists).
    Your code should print exactly:
    True
    Answer
    Save first, then show: show() finishes the chart.
  19. Challenge. From sales_data.csv, draw a bar chart of the average satisfaction score per region, highest first, with a title and a y label.
    Your code should print exactly:
    Answer
    Group, sort, then draw the sorted Series: its index gives the names and its values the heights.
  20. Challenge. From sales_data.csv, draw the number of Clothing orders in each month as a line with markers, with the short month names on the x-axis and a title.
    Your code should print exactly:
    Answer
    Filter first, then group by month and count with size().
  21. Challenge. Type exactly what this code prints.
    Answer
    [4.0, 6.0, 8.0]
    These are the three lines of a box plot: Q1 (25%), the median and Q3 (75%). The IQR is 8 - 4 = 4.
  22. Challenge. This code should save a picture of the chart. It saves a file, but the file is an empty white picture, so it prints False. Fix the order.
    It should print:
    True
    Answer
    show() finishes the chart, so a later savefig() saves a new empty figure. Save first.
  23. Challenge. From sales_data.csv, draw a pie of the number of orders per region with percents (1 decimal), starting at the top (startangle=90), and pull the South slice out by 0.1. The regions come out A to Z: East, North, South, West.
    Your code should print exactly:
    Answer
    explode takes one value per slice, in the same order as the data.
  24. Challenge. Type exactly what this code prints.
    Answer
    [8.0, 3.0]
    figsize is (width, height) in inches.
  25. Challenge. Daily footfall for a week is [320, 280, 300, 410, 520, 760, 690] (Mon to Sun). Draw it as a line with markers, and add a red dot on the busiest day with plt.scatter. Add a title.
    Your code should print exactly:
    Answer
    Two chart types on one axes: the line shows the trend and one scatter dot calls out the peak.
