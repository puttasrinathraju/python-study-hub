22.1 Big Test: NumPy extras

25 questions on NumPy extras: iterate, split, search, random and ufuncs only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    3
7

    Looping over a 2D array gives one row at a time, and each row is itself an array.

  2. Basic. Split np.arange(1, 10) into 3 equal parts with np.split, and print each part on its own line.

    Your code should print exactly:

    [1 2 3]
[4 5 6]
[7 8 9]
    Answer

    np.split(a, 3) cuts the array into 3 equal pieces. 9 values make 3 pieces of 3.

  3. Basic. a = np.array([4, 7, 4, 9, 4]). Print the positions of every 4, using np.where.

    Your code should print exactly:

    [0 2 4]
    Answer

    np.where(condition) gives a tuple with one array of positions per dimension. [0] takes the positions.

  4. Basic. a = np.array([10, 20, 30]) and b = np.array([3, 4, 5]). Print np.add(a, b) and np.mod(a, b) with one print().

    Your code should print exactly:

    [13 24 35] [1 0 0]
    Answer

    ufuncs work value by value, like + and % on arrays.

  5. Basic. sales = np.array([120, 80, 150]). Print the running total with np.cumsum.

    Your code should print exactly:

    [120 200 350]
    Answer

    cumsum adds up as it goes: each value is the total so far.

  6. Basic. This code should split 7 numbers into 3 parts (3, 2 and 2 values), but it crashes. Fix it.

    It should print:

    [0 1 2]
[3 4]
[5 6]
    Answer

    np.split needs parts of exactly equal size. np.array_split allows unequal parts.

  7. Basic. Type exactly what this code prints.

    Answer
    [0. 2. 2. 4.]

    NumPy rounds halves to the nearest even number, like Python's round(): 0, 2, 2, 4.

  8. Basic. This code should print how many 3s there are: 2. Fix it.

    It should print:

    2
    Answer

    np.where returns a tuple (one item per dimension), so its length is 1. Count the positions inside it with [0].

  9. Medium. m = np.array([[10, 20], [30, 40]]). Print each position and its value with np.ndenumerate, one per line.

    Your code should print exactly:

    (0, 0) 10
(0, 1) 20
(1, 0) 30
(1, 1) 40
    Answer

    ndenumerate is enumerate for arrays: it gives the (row, column) position with each value.

  10. Medium. Price slabs start at slabs = np.array([100, 250, 400, 900]). For the new prices [50, 300, 1000], print the positions where they would be inserted to keep the order, using np.searchsorted.

    Your code should print exactly:

    [0 2 4]
    Answer

    searchsorted finds where each value fits in a sorted array: before 100, between 250 and 400, and after 900.

  11. Medium. Type exactly what this code prints.

    Answer
    1 6 500

    randint(1, 7) gives 1 to 6 (7 is not included). With 500 rolls, both 1 and 6 surely appear.

  12. Medium. a = np.array([1, 2, 3, 4, 5]). Make a shuffled copy with np.random.permutation. Print whether the sorted copy equals a (use np.array_equal), then print a itself.

    Your code should print exactly:

    True
[1 2 3 4 5]
    Answer

    permutation returns a new shuffled array and leaves a alone. Checking the sorted copy avoids printing random values.

  13. Medium. readings = np.array([100, 120, 90, 130]). Print the day-to-day changes with np.diff, then the biggest rise.

    Your code should print exactly:

    [ 20 -30  40]
40
    Answer

    np.diff subtracts each value from the next one, so the result has one value fewer.

  14. Medium. This code should print the greatest common divisor of 12 and 18, 6. Fix it.

    It should print:

    6
    Answer

    lcm is the lowest common multiple (36). The greatest common divisor is gcd.

  15. Medium. Type exactly what this code prints.

    Answer
    [3, 3, 3, 2]

    11 values into 4 parts: the first parts get one extra value each, so 3, 3, 3 and 2.

  16. Medium. After np.random.seed(3), make 100000 values from a normal distribution with mean 500 and standard deviation 50. Print the mean and the standard deviation, both rounded to whole numbers.

    Your code should print exactly:

    500 50
    Answer

    With many values, the sample mean and spread come very close to the settings, so the rounded results are stable.

  17. Medium. a = np.array([1, 2, 3, 4]) and b = np.array([3, 4, 5]). Print the values in both, the values only in a, and all values, using np.intersect1d, np.setdiff1d and np.union1d.

    Your code should print exactly:

    [3 4] [1 2] [1 2 3 4 5]
    Answer

    These are set operations for arrays, and the results come back sorted.

  18. Medium. This code should print every value on one line: 1 2 3 4. Fix the loop.

    It should print:

    1 2 3 4
    Answer

    A plain loop over a 2D array gives rows. np.nditer visits every single value.

  19. Challenge. days = np.arange(1, 15) * 100 holds 14 days of sales. Split it into 2 weeks with np.split, and print a list of the two weekly totals as plain ints.

    Your code should print exactly:

    [2800, 7700]
    Answer

    Split first, then summarise each part. int() turns NumPy numbers into plain Python ints for a clean list.

  20. Challenge. After np.random.seed(3), simulate 100000 days of bookings with np.random.binomial(n=20, p=0.25, size=100000). Print the mean rounded to a whole number, whether every value is 0 or more, and whether every value is 20 or less.

    Your code should print exactly:

    5 True True
    Answer

    A binomial count is between 0 and n, and its mean is n × p = 5. Check properties, not exact random values.

  21. Challenge. rates = np.array([1200, 3400, 1200, 5600, 3400]). Print the positions of the rate 3400, then how many rates are below 2000.

    Your code should print exactly:

    [1 4]
2
    Answer

    np.where finds positions; a mask finds the matching values, and len() counts them.

  22. Challenge. Type exactly what this code prints.

    Answer
    [-2.  2.] [-1.  3.] [-1.  2.]

    floor always goes down, ceil always goes up, and trunc just cuts off the decimals (towards 0).

  23. Challenge. After np.random.seed(1), pick 10000 days with np.random.choice(["late", "on time"], p=[0.2, 0.8], size=10000). Print the share of on-time days, rounded to 1 decimal.

    Your code should print exactly:

    0.8
    Answer

    days == "on time" is an array of True/False, and its mean is the share of True values: about 0.8.

  24. Challenge. np.searchsorted should say where 300 fits among these prices in sorted order: 2. Fix it.

    It should print:

    2
    Answer

    searchsorted only works on a sorted array. Sort the prices first.

  25. Challenge. Write a function slab(amount) that returns "High" for 1000 or more and "Low" otherwise. Turn it into a ufunc with np.frompyfunc(slab, 1, 1) and print the result for np.array([500, 1500, 1000]).

    Your code should print exactly:

    ['Low' 'High' 'High']
    Answer

    frompyfunc wraps your own Python function so it runs on every value of an array.
