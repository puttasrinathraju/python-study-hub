3.1 Big Test: Printing & f-strings

25 questions on Printing and formatting output only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Use ONE print() with sep to print 30-10-2026. Give it the three numbers 30, 10 and 2026.

    Your code should print exactly:

    30-10-2026
    Answer

    sep sets what goes between the values. The default is one space, and sep="-" puts a dash there instead.

  2. Basic. Type exactly what this code prints.

    Answer
    Loading...
Done

    end="" stops the first print() from starting a new line, so ... is printed right after Loading. The next print() ends normally.

  3. Basic. Print exactly: It's a holiday

    Your code should print exactly:

    It's a holiday
    Answer

    Wrap the text in double quotes, and the apostrophe inside is just a character. ('It\'s a holiday' also works.)

  4. Basic. first = "Sachin" and last = "Tendulkar". Use + to print the full name with one space in the middle.

    Your code should print exactly:

    Sachin Tendulkar
    Answer

    + glues text together with nothing in between, so add the space yourself: " ".

  5. Basic. Print a line of 25 = signs. Use *, do not type them all.

    Your code should print exactly:

    =========================
    Answer

    Text times a number repeats the text: "=" * 25 gives 25 signs. Great for report lines.

  6. Basic. This code should print Rooms booked: 12, but it crashes. Fix it.

    It should print:

    Rooms booked: 12
    Answer

    + cannot join text and a number. Turn the number into text with str() first (or use an f-string).

  7. Basic. name = "Kiran" and city = "Vizag". Use an f-string to print Kiran lives in Vizag.

    Your code should print exactly:

    Kiran lives in Vizag
    Answer

    Put f before the quote, then each variable in { }. Python fills in the values.

  8. Basic. Type exactly what this code prints.

    Answer
    Line 1
Line 2

    \n inside text means new line, so the text is printed on two lines.

  9. Medium. price = 1234.5. Print Price: 1234.50 (always 2 decimal places) using an f-string.

    Your code should print exactly:

    Price: 1234.50
    Answer

    :.2f after the variable means a float with exactly 2 decimal places.

  10. Medium. population = 12345678. Print Population: 12,345,678 using an f-string.

    Your code should print exactly:

    Population: 12,345,678
    Answer

    :, adds a comma between every group of three digits. It makes big numbers easy to read.

  11. Medium. Type exactly what this code prints.

    Answer
    45.7% 007

    .1% multiplies by 100, keeps 1 decimal and adds %. 03d pads a whole number with zeros to 3 digits.

  12. Medium. This code should print the file path C:\new\table.csv, but the output is broken. Fix it.

    It should print:

    C:\new\table.csv
    Answer

    \n and \t are escape characters (new line and tab). Put r before the quote to switch them off, or write each backslash twice: \\.

  13. Medium. This code should print She said "Hi" to me, but it crashes. Fix it.

    It should print:

    She said "Hi" to me
    Answer

    The double quote before Hi ends the text too early. Wrap the whole text in single quotes, or write \" for each quote inside.

  14. Medium. Use TWO print() calls to print Total: 450 on ONE line. The first prints Total: and must not end the line. The second prints the number 450.

    Your code should print exactly:

    Total: 450
    Answer

    end=" " ends the first print with a space instead of a new line, so the second print continues on the same line.

  15. Medium. Type exactly what this code prints.

    Answer
    ababab!
-----

    * runs first: "ab" three times is ababab, then + adds the !.

  16. Medium. This code should print Hello Ravi, but it prints Hello {name}. Fix it.

    It should print:

    Hello Ravi
    Answer

    Without the f before the quote, {name} is plain text. The f switches the slots on.

  17. Medium. qty = 3 and price = 45. Use one f-string to print 3 x 45 = 135. Python must work out the 135.

    Your code should print exactly:

    3 x 45 = 135
    Answer

    A slot { } can hold maths, not just a name. Python works out qty * price and puts the answer in the text.

  18. Medium. items = 4 and total = 760. Use the f-string debug trick (a = inside the slot) to print items=4 total=760.

    Your code should print exactly:

    items=4 total=760
    Answer

    {items=} prints the name, an = and the value. It is a quick way to check variables while you debug.

  19. Challenge. units = 1250 and price = 89.9. Print the revenue as Revenue: ₹112,375.00 (commas and 2 decimals).

    Your code should print exactly:

    Revenue: ₹112,375.00
    Answer

    :,.2f combines two specs: commas between thousands and exactly 2 decimals. The ₹ is just text before the slot.

  20. Challenge. Print this price list, one line per item. Each item name is left-aligned in 15 characters, and each price is right-aligned in 8 characters with 2 decimals.
    Items: Masala Dosa 60, Filter Coffee 25.5, Idli 40.

    Your code should print exactly:

    Masala Dosa       60.00
Filter Coffee     25.50
Idli              40.00
    Answer

    <15 pads the name with spaces on the right up to 15 characters. >8.2f pads the price on the left up to 8 characters, so the decimal points line up.

  21. Challenge. Type exactly what this code prints.

    Answer
    x--y|z

    sep="--" goes between x and y. end="|" replaces the new line, so z is printed right after the |.

  22. Challenge. This code should print Marks: 92.5, but it prints something strange. Fix it.

    It should print:

    Marks: 92.5
    Answer

    Without the f, .1 means 1 significant digit, so Python writes 9e+01. .1f means 1 decimal place.

  23. Challenge. Print a banner of three lines: 20 * signs, then MONTHLY REPORT centred in 20 characters, then 20 * signs again.

    Your code should print exactly:

    ********************
   MONTHLY REPORT   
********************
    Answer

    "*" * 20 repeats the star. ^20 centres the title in 20 characters: 3 spaces on each side of the 14 letters.

  24. Challenge. invoice_no = 42, qty = 3 and price = 450. Print INV-0042 | Qty: 3 | Amount: ₹1,350.00.

    Your code should print exactly:

    INV-0042 | Qty: 3 | Amount: ₹1,350.00
    Answer

    04d pads the number with zeros to 4 digits. The amount slot does the maths and then formats it with :,.2f.

  25. Challenge. item = "Tea", qty = 2 and rate = 15. With ONE print() and one f-string, print three lines: Item: Tea, Qty: 2 and Total: ₹30.00. Use \n for the new lines.

    Your code should print exactly:

    Item: Tea
Qty: 2
Total: ₹30.00
    Answer

    \n works inside f-strings too. One print() can make a whole multi-line receipt.
