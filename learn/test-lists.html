9.1 Big Test: Lists

25 questions on Lists only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    green pink
['green', 'blue']

    Indexes start at 0, and -1 is the last item. A slice [1:3] gives a new list with items 1 and 2.

  2. Basic. Make a list cities with "Delhi", "Pune" and "Goa". Print the list and its length with one print().

    Your code should print exactly:

    ['Delhi', 'Pune', 'Goa'] 3
    Answer

    Square brackets make a list, and len() counts its items.

  3. Basic. cart = ["rice", "dal"]. Add "oil" at the end and "salt" at the start. Print the cart.

    Your code should print exactly:

    ['salt', 'rice', 'dal', 'oil']
    Answer

    append() adds to the end. insert(0, x) puts x at position 0, the front.

  4. Basic. stock = ["pen", "ink", "pad", "ink"]. Remove the first "ink" with remove(), then remove the last item with pop(). Print the list.

    Your code should print exactly:

    ['pen', 'pad']
    Answer

    remove(x) deletes the first match only. pop() with no index removes the last item.

  5. Basic. sales = [450, 120, 780, 340]. Print the total, the smallest and the largest value with one print().

    Your code should print exactly:

    1690 120 780
    Answer

    sum(), min() and max() work on a whole list at once, no loop needed.

  6. Basic. This code should print ['apple', 'banana', 'cherry'], but it crashes. Fix it.

    It should print:

    ['apple', 'banana', 'cherry']
    Answer

    Lists have no add() method (that one belongs to sets). Use append() to add to the end of a list.

  7. Basic. Type exactly what this code prints.

    Answer
    1 2 False

    index() gives the position of the first match (1). count() counts all matches. in gives True or False.

  8. Basic. This code should print the last mark, 72, but it crashes. Fix it.

    It should print:

    72
    Answer

    A list of 3 items has indexes 0, 1 and 2, so index 3 is out of range. [-1] always gives the last item.

  9. Medium. prices = [499, 120, 999, 250, 75]. Print the 2 cheapest prices, using sorted() and a slice.

    Your code should print exactly:

    [75, 120]
    Answer

    sorted() gives a new list from smallest to largest, and [:2] keeps the first two.

  10. Medium. This code should print [1, 2, 3], but it prints None. Fix it.

    It should print:

    [1, 2, 3]
    Answer

    sort() changes the list in place and returns None. Do not store its result. (Or use nums = sorted(nums).)

  11. Medium. Type exactly what this code prints.

    Answer
    [1, 2, 3, 4] [1, 2, 3]

    b = a makes a second name for the same list, so changing b changes a. copy() makes a separate list.

  12. Medium. names = ["asha", "ravi", "neha"]. Print each name in capitals with its number: 1. ASHA, 2. RAVI, 3. NEHA.

    Your code should print exactly:

    1. ASHA
2. RAVI
3. NEHA
    Answer

    enumerate(..., start=1) gives the number and the item. upper() makes the capitals.

  13. Medium. sales = [[120, 80], [200, 150], [90, 60]] (one row per day, one column per shop). Print the sales of shop 2 on day 3, and the total of day 2, with one print().

    Your code should print exactly:

    60 350
    Answer

    The first index picks the row (day 3 is index 2) and the second picks the column (shop 2 is index 1). sales[1] is the whole day 2 row.

  14. Medium. temps = [31, 35, 29, 38, 33]. Use a list comprehension to keep only the temperatures above 32, and print the new list.

    Your code should print exactly:

    [35, 38, 33]
    Answer

    [t for t in temps if t > 32] is a loop and a filter in one line.

  15. Medium. Type exactly what this code prints.

    Answer
    [1, 2, 3, 1, 2, 3] 3

    + joins two lists into a new one. * 2 repeats the list. b itself still has 3 items.

  16. Medium. emails = ["a@x.com", "b@x.com", "a@x.com", "c@x.com", "b@x.com"]. Remove the duplicates but keep the first-seen order, using a loop and a new list. Print it.

    Your code should print exactly:

    ['a@x.com', 'b@x.com', 'c@x.com']
    Answer

    Add an item only if it is not in the new list yet. Unlike set(), this keeps the original order.

  17. Medium. This code should remove every even number and print [5], but it prints [4, 5]. Fix it.

    It should print:

    [5]
    Answer

    Removing items while looping over the same list makes the loop skip items. Loop over a copy, nums[:], and remove from the original.

  18. Medium. marks = [45, 82, 67, 90, 38]. Print the average rounded to 1 decimal place, and whether all marks are 35 or more (use all()), with one print().

    Your code should print exactly:

    64.4 True
    Answer

    Average = sum() ÷ len(). all() is True only if the check is True for every item.

  19. Challenge. words = ["kiwi", "banana", "fig", "apple"]. Print the words sorted by length, shortest first.

    Your code should print exactly:

    ['fig', 'kiwi', 'apple', 'banana']
    Answer

    key=len tells sorted() to compare the lengths instead of the words themselves.

  20. Challenge. readings = [12.5, -1, 13.2, -1, 12.9], where -1 means a missing reading. Build a clean list without the -1 values, then print the average of the clean readings rounded to 2 decimals.

    Your code should print exactly:

    12.87
    Answer

    Clean first, then calculate: the average must divide by the number of real readings (3), not 5.

  21. Challenge. marks = [["Asha", 78], ["Ravi", 92], ["Neha", 85]]. Use a loop to find and print the name with the highest mark.

    Your code should print exactly:

    Ravi
    Answer

    Each row is a small list: row[0] is the name and row[1] the mark. Keep the best row seen so far.

  22. Challenge. This code should keep a backup of the old list and print [10, 20, 30]. Fix it.

    It should print:

    [10, 20, 30]
    Answer

    backup = original is not a copy: both names point to one list. copy() (or [:]) makes a real copy.

  23. Challenge. nums = [1, 2, 3, 4, 5, 6]. Replace the middle two items (3 and 4) with 30 and 40 using ONE slice assignment. Then print the list reversed with a slice.

    Your code should print exactly:

    [6, 5, 40, 30, 2, 1]
    Answer

    A slice on the left of = replaces that part of the list. [::-1] reads the list backwards.

  24. Challenge. Type exactly what this code prints.

    Answer
    [7, 9] 8 5

    sorted(nums)[-2:] is the two biggest values. The range is 9 − 1 = 8, and 21 // 4 = 5.

  25. Challenge. queue = ["T1", "T2", "T3", "T4"]. Serve tickets from the front with pop(0) until only 2 are left, printing Served T1 and so on. Then print the queue.

    Your code should print exactly:

    Served T1
Served T2
['T3', 'T4']
    Answer

    pop(0) removes the first item and gives it back, so you can print it. The loop stops when 2 are left.
