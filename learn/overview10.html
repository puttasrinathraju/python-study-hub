Part 10 overview: Seaborn

Both Seaborn chapters on one page: which chart answers which question, axes-level and figure-level functions side by side, the options you use everywhere, Matplotlib vs Seaborn in one picture, and the mix-ups that cost marks (countplot vs barplot, hue= vs col=, regplot vs lmplot).

The whole Part in 5 lines

  1. Seaborn takes the table and the column names: sns.chart(data=df, x="a", y="b", hue="g"), and it does the grouping, counting and averaging.
  2. One column's shape: histplot, kdeplot, ecdfplot. Categories: countplot counts, barplot and pointplot average, boxplot, violinplot, stripplot and swarmplot show spread.
  3. Relationships: scatterplot (hue, size, style), lineplot (mean + band), regplot (fitted line) and residplot to check it.
  4. Many columns: heatmap for any correlation or pivot table, clustermap to group similar rows, pairplot for every pair, jointplot for one pair with margins.
  5. Axes-level functions draw one chart and take ax=; figure-level ones (displot, catplot, relplot, lmplot) make panels with col= and return a grid g.

Matplotlib vs Seaborn

Seaborn is built on Matplotlib, so they work together. The big difference: Matplotlib draws the numbers you give it; Seaborn takes the whole table and does the maths for you.

Diagram: One question, two ways: average order value per region. Left: Matplotlib after a groupby. Right: one sns.barplot line on the raw table, with error bars and labels for free. (groupby sorts A to Z; Seaborn keeps the file's order.)

Key definitions

Seaborn

A library of statistical charts built on Matplotlib. Give it a DataFrame and column names; import it as sns.

hue

An argument that colours the data by one more column and adds a legend.

Axes-level function

Draws one chart on one axes and returns it; accepts ax=. histplot, boxplot, scatterplot, heatmap ...

Figure-level function

Builds a whole figure, with panels from col= and row=, and returns a grid. displot, catplot, relplot, lmplot ...

KDE

Kernel density estimate: a smooth curve of a column's shape. bw_adjust= sets the smoothing.

ECDF

A line that climbs from 0 to 1: the share of rows at or below each value.

Estimator

The summary a chart shows per group: the mean by default in barplot, pointplot and lineplot.

Confidence interval

The range where the true average probably lies (95% by default): the error bar and the band.

Violin plot

A box plot plus the shape of the data on both sides; split=True shows two groups in one violin.

Palette

A list of colours. palette= colours the hue= groups; "colorblind" is safe for everyone.

Regression line

The straight line (or curve with order=2) that fits a scatter best; regplot draws it with a 95% band.

Residual

Real value minus the line's value. A pattern in the residuals means the line has the wrong shape.

Heatmap

A grid of coloured cells, one per value of a table; annot=True writes the numbers.

FacetGrid

A grid of panels, one per value of col= / row=; g.map(...) draws a chart in each.

Pair plot

A scatter for every pair of number columns, and each column's shape on the diagonal.

    Hint

    sns.boxplot(data=sales, x="Region", y="Satisfaction_Score", order=[...]).

    Hint

    table = sales.pivot_table(values="Quantity", index="Category", columns="Region", aggfunc="sum"), then sns.heatmap(table, annot=True, fmt="d").

    16 cells; the South sells the most items in most categories.

    Solution

    The four lines lie close together: every region makes about the same profit per rupee.

Mixed quiz

  1. Which function counts how many rows each category has?

    1. sns.barplot
    2. sns.countplot
    3. sns.histplot
    4. sns.pointplot
    Answer

    sns.countplot. countplot counts; barplot averages a y= column.

  2. What does this print?

    1. [3, 1]
    2. [1, 3]
    3. [4]
    4. [2, 2]
    Answer

    [3, 1]. Bars come in the order the values first appear: a (3), then b (1).

  3. You want one histogram per region, side by side. Which call?

    1. sns.histplot(data=df, x="v", hue="Region")
    2. sns.displot(data=df, x="v", col="Region")
    3. sns.countplot(data=df, x="Region")
    4. sns.heatmap(df)
    Answer

    sns.displot(data=df, x="v", col="Region"). Panels need a figure-level function with col=.

  4. By default, what does the black line on each bar of sns.barplot show?

    1. The smallest and largest value
    2. A 95% confidence interval of the mean
    3. One standard deviation
    4. The median
    Answer

    A 95% confidence interval of the mean. Change it with errorbar="sd", or remove it with errorbar=None.

  5. Which chart shows each group's spread and its full shape?

    1. countplot
    2. violinplot
    3. pointplot
    4. lineplot
    Answer

    violinplot. A violin adds the shape on both sides of a mini box plot.

  6. sns.lineplot(data=df, x="month", y="sales") with many rows per month draws what?

    1. Every row joined
    2. The mean per month with a 95% band
    3. The total per month
    4. A bar per month
    Answer

    The mean per month with a 95% band. lineplot averages repeated x values; estimator="sum" gives totals.

  7. A residual plot shows a curve. What should you try?

    1. regplot(..., order=2)
    2. A pie chart
    3. errorbar=None
    4. hue=
    Answer

    regplot(..., order=2). A pattern means a straight line is the wrong shape; fit a curve.

  8. For a correlation heatmap, which settings fit best?

    1. cmap="Blues"
    2. cmap="coolwarm", center=0
    3. palette="pastel"
    4. kind="hex"
    Answer

    cmap="coolwarm", center=0. Correlations run from -1 to 1: a diverging scale centred on 0.

  9. What does this print?

    1. (2, 2)
    2. (4,)
    3. (1, 4)
    4. 4
    Answer

    (2, 2). Two values of row and two of col: a 2 × 2 grid of panels.

  10. Which call puts a Seaborn chart into axes[1] of a Matplotlib grid?

    1. sns.catplot(..., ax=axes[1])
    2. sns.boxplot(..., ax=axes[1])
    3. sns.lmplot(..., ax=axes[1])
    4. sns.pairplot(..., ax=axes[1])
    Answer

    sns.boxplot(..., ax=axes[1]). Only axes-level functions accept ax=.

  11. Seaborn warns about palette="pastel" in a barplot without hue=. The fix?

    1. Remove data=
    2. Add hue= (same column as x=) and legend=False
    3. Use ci=95
    4. Use sns.set_context
    Answer

    Add hue= (same column as x=) and legend=False. Since Seaborn 0.13 a palette colours the hue= groups.

  12. You call plt.bar(sales["Region"], sales["Sales"]) on 500 raw orders to show the average per region. What goes wrong?

    1. Nothing: plt.bar averages each region
    2. plt.bar does not average: it draws one bar per row, on top of each other
    3. plt.bar needs hue=
    4. It raises an error
    Answer

    plt.bar does not average: it draws one bar per row, on top of each other. Matplotlib draws exactly the numbers it gets. Work out the averages with groupby(...).mean() first, or let sns.barplot do it.

Flashcards

Seaborn's pattern
sns.chart(data=df, x="a", y="b", hue="g")
hue vs col
hue: colours in one chart. col: separate panels (figure-level).
Axes-level vs figure-level
One chart + ax= / a whole figure of panels that returns a grid g.
histplot options
bins=, kde=True, stat="percent", multiple="stack"
countplot vs barplot
Rows per category / the mean of y with a 95% interval.
Error bars
errorbar=("ci", 95), "sd", None; regplot uses ci=.
Box vs violin
Five numbers and outliers / the full shape; split=True with hue.
catplot
All category charts with kind=; the default is strip.
Regression
regplot (one line), lmplot (per group / panels), residplot (check).
Heatmap
sns.heatmap(table, annot=True, fmt=".2f", cmap="coolwarm", center=0)
Grids
FacetGrid + map, pairplot (every pair), jointplot (one pair + margins).
Look
set_theme(style=), palette= with hue, despine(), set_context("talk").
Save
Axes-level: plt.savefig(). Figure-level: g.savefig().
plt or sns?
Explore and compare groups: sns. Exact custom layout: plt. Report charts: Seaborn draws, then plt / ax finishes.
