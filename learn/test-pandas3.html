25.1 Big Test: Select & change

25 questions on Selecting, filtering and changing data only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Print the type and rate of the rows with the labels 1 to 3 (both included), using loc.

    Your code should print exactly:

           type  rate
1     Suite  7200
2  Standard  2100
3    Deluxe  3800
    Answer

    With loc, the end label 3 is included.

  2. Basic. Print the first 2 rows and the first 3 columns of rooms, using iloc.

    Your code should print exactly:

       room    type  rate
0   101  Deluxe  3500
1   102   Suite  7200
    Answer

    iloc slices work like lists: the end position is left out.

  3. Basic. Type exactly what this code prints.

    Answer
    Suite 3500

    iloc[-1] is the last row (a Suite) and iloc[0] the first (rate 3500).

  4. Basic. Print the rows of rooms whose rate is above ₹3,000.

    Your code should print exactly:

       room    type  rate  nights  rating
0   101  Deluxe  3500       2     4.5
1   102   Suite  7200       1     4.8
3   104  Deluxe  3800       3     4.1
5   106   Suite  6900       2     4.9
    Answer

    The condition makes a True/False mask; rooms[mask] keeps the True rows.

  5. Basic. Add a column bill = rate × nights and print the room and bill columns.

    Your code should print exactly:

       room   bill
0   101   7000
1   102   7200
2   103   8400
3   104  11400
4   105  11500
5   106  13800
    Answer

    Maths between two columns works row by row.

  6. Basic. This code should keep the Deluxe rooms with 3 or more nights, but it stops with a ValueError. Fix it.

    It should print:

    [104, 105]
    Answer

    Python's and cannot combine two masks. Use &.

  7. Basic. Type exactly what this code prints.

    Answer
    ['Q', 'R', 'P']

    Smallest first: 3 (Q), 5 (R), 8 (P).

  8. Basic. Print how many rooms there are of each type, with value_counts().

    Your code should print exactly:

    type
Deluxe      3
Suite       2
Standard    1
Name: count, dtype: int64
    Answer

    value_counts() counts each value and puts the most common first: 3 Deluxe, 2 Suites, 1 Standard.

  9. Medium. This code should print the rate of room 104 (3800), but it raises a KeyError. Fix it so loc can find room 104.

    It should print:

    3800
    Answer

    The labels are 0 to 5, not the room numbers. set_index("room") makes the room numbers the labels that loc uses.

  10. Medium. Print the room numbers of the Suites or the rooms rated below 4.0, as a list.

    Your code should print exactly:

    [102, 103, 105, 106]
    Answer

    | keeps a row when either condition is True.

  11. Medium. Using query(), print the room numbers with a rate under the variable budget = 4000 and a rating of 4 or more, as a list.

    Your code should print exactly:

    [101, 104]
    Answer

    @budget uses the Python variable inside the query text.

  12. Medium. This code should label each rating as Good (4 or more) or OK, but it stops with a TypeError. Fix the apply line.

    It should print:

    ['Good', 'Good', 'OK', 'Good', 'OK', 'Good']
    Answer

    Pass the function itself, without brackets. label() calls it with no value.

  13. Medium. Type exactly what this code prints.

    Answer
    ['Short', 'Short', 'Long', 'Long', 'Long', 'Short']

    The lambda runs once for each value: nights 2, 1, 4, 3, 5, 2.

  14. Medium. Add a column gst with np.where: 18% of the rate for rates above ₹7,000, otherwise 12%. Print the rate and gst columns.

    Your code should print exactly:

       rate     gst
0  3500   420.0
1  7200  1296.0
2  2100   252.0
3  3800   456.0
4  2300   276.0
5  6900   828.0
    Answer

    np.where picks, row by row, from two calculated columns.

  15. Medium. Type exactly what this code prints.

    Answer
    3 2

    loc keeps labels 2, 3 and 4; iloc keeps positions 2 and 3.

  16. Medium. Print the room and rate of the 3 most expensive rooms, highest first.

    Your code should print exactly:

       room  rate
1   102  7200
5   106  6900
3   104  3800
    Answer

    Sort largest first, then take the top 3 with head(3).

  17. Medium. This code should print the room number of the best-rated room (106), but it prints the rating. Fix it.

    It should print:

    106
    Answer

    max() gives the value 4.9; idxmax() gives its index label, which loc needs.

  18. Medium. Read sales_data.csv and print how many different categories there are, then the share of orders from each category with value_counts(normalize=True) rounded to 2 decimals.

    Your code should print exactly:

    4
Category
Clothing       0.31
Groceries      0.24
Electronics    0.23
Furniture      0.21
Name: proportion, dtype: float64
    Answer

    nunique() counts the different values; normalize=True gives shares that add up to 1.

  19. Challenge. Mark the rooms that need attention: set a new column flag to "Check" with loc for ratings below 4.0, and "OK" for the rest. Print the room numbers flagged "Check" as a list.

    Your code should print exactly:

    [103, 105]
    Answer

    loc[condition, "col"] = value sets values only in the matching rows.

  20. Challenge. Write def discount(row) that gives 10% off the bill (rate × nights) for 4 or more nights and nothing otherwise, and returns the amount to pay. Add it as pay with apply(..., axis=1) and print the room and pay columns.

    Your code should print exactly:

       room      pay
0   101   7000.0
1   102   7200.0
2   103   7560.0
3   104  11400.0
4   105  10350.0
5   106  13800.0
    Answer

    With axis=1 the function gets a whole row, so it can use two columns at once.

  21. Challenge. Sort the rooms by type A to Z, and inside each type by rating, highest first. Print the type, room and rating columns.

    Your code should print exactly:

           type  room  rating
0    Deluxe   101     4.5
3    Deluxe   104     4.1
4    Deluxe   105     3.6
2  Standard   103     3.9
5     Suite   106     4.9
1     Suite   102     4.8
    Answer

    Give a list of columns and a matching list of directions.

  22. Challenge. Type exactly what this code prints.

    Answer
    [101, 103, 105] 3

    between includes both ends: rates 3500, 2100 and 2300 qualify.

  23. Challenge. This code should print the last 2 room numbers, [105, 106], but it prints []. Fix the slice.

    It should print:

    [105, 106]
    Answer

    A slice from -2 to 0 is empty, because 0 comes before -2. Leave the end out to go to the last row.

  24. Challenge. Read sales_data.csv. Using query(), keep the West orders with a profit above 1000, then print how many there are and their total sales.

    Your code should print exactly:

    13 93834
    Answer

    Filter once, then use len() and sum() on the result.

  25. Challenge. Read sales_data.csv. Print the Date, Category and Profit of the order with the biggest loss (the smallest profit).

    Your code should print exactly:

    Date         2024-12-23
Category    Electronics
Profit             -252
Name: 491, dtype: object
    Answer

    idxmin() finds where the smallest profit is; loc shows the columns you choose.
