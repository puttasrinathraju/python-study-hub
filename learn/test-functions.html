14.1 Big Test: Functions basics

25 questions on Functions: the basics only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Defining a function runs nothing. The body runs only when the function is called, here twice, after Start.

  2. Basic. Write a function show_banner() that prints === SALES ===. Call it twice.

    Your code should print exactly:

    === SALES ===
=== SALES ===
    Answer

    def name(): defines the function; name() calls it. You can call it as many times as you like.

  3. Basic. Write greet(name) that prints Namaste, <name>!. Call it with "Asha" and then with "Ravi".

    Your code should print exactly:

    Namaste, Asha!
Namaste, Ravi!
    Answer

    name is the parameter. Each call passes a different argument, and the same code uses it.

  4. Basic. Write square(n) that returns n * n. Then print square(7) + 1.

    Your code should print exactly:

    50
    Answer

    return hands the result back to the caller, so you can use it in more maths: 49 + 1.

  5. Basic. Write apply_gst(price, rate=18) that returns the price plus rate%. Print apply_gst(1000) and apply_gst(1000, 5) with one print().

    Your code should print exactly:

    1180.0 1050.0
    Answer

    When you leave out rate, it uses its default, 18. Passing 5 replaces the default.

  6. Basic. This code should print hi, but it crashes. Fix it.

    It should print:

    hi
    Answer

    Python runs from top to bottom, so a function must be defined before it is called.

  7. Basic. Type exactly what this code prints.

    Answer
    8
None

    double() prints 8 but has no return, so it gives back None, and result is None.

  8. Basic. This code should print Hello Guest, but it crashes. Fix it by giving name a default value.

    It should print:

    Hello Guest
    Answer

    A call must give every parameter that has no default. name="Guest" makes the argument optional.

  9. Medium. Write is_eligible(age) that returns True when age is 18 or more, using one return line. Print is_eligible(17) and is_eligible(18) with one print().

    Your code should print exactly:

    False True
    Answer

    A comparison already gives True or False, so you can return it directly, without if.

  10. Medium. Write min_max(nums) that returns the smallest and the largest number. For [12, 3, 41, 7], unpack the result and print Min: 3 Max: 41.

    Your code should print exactly:

    Min: 3 Max: 41
    Answer

    return a, b sends back a tuple, which the caller unpacks into two names.

  11. Medium. Type exactly what this code prints.

    Answer
    Asha from Pune
Ravi from Goa

    The first call uses the default city. Keyword arguments can come in any order, because each one is matched by name.

  12. Medium. This function should add up all the prices and print 60, but it prints 10. Fix it.

    It should print:

    60
    Answer

    return ends the function at once. Inside the loop it returns after the first price. Move it out of the loop.

  13. Medium. Write grade(marks) that returns "A" for 90 or more, "B" for 75 or more, "C" for 50 or more, and "F" below that. Print the grades of [95, 80, 40] as a list, using a comprehension.

    Your code should print exactly:

    ['A', 'B', 'F']
    Answer

    Your own functions work anywhere a built-in does, including inside a comprehension.

  14. Medium. Write area(length, width) with the docstring Return the area of a rectangle. Print area(4, 5), then print the docstring with area.__doc__.

    Your code should print exactly:

    20
Return the area of a rectangle.
    Answer

    A docstring is the first string inside the function. Python keeps it in __doc__, and help() shows it.

  15. Medium. Type exactly what this code prints.

    Answer
    (7, 12) <class 'tuple'>

    Two values after return are packed into one tuple.

  16. Medium. This code should print 118.0, but it crashes. Fix the function line.

    It should print:

    118.0
    Answer

    Parameters with defaults must come after the ones without. Put amount first.

  17. Medium. Write count_above(values, limit) that returns how many values are above limit. Print count_above([45, 82, 67, 90, 38], 60).

    Your code should print exactly:

    3
    Answer

    A function can take a whole list as one argument, plus a second value to compare with.

  18. Medium. Write clean_name(text) that returns the text with the spaces at the ends removed, in title case. Use it in a list comprehension on [" asha ", "RAVI"] and print the list.

    Your code should print exactly:

    ['Asha', 'Ravi']
    Answer

    Write the cleaning steps once in a function, then reuse them for every name.

  19. Challenge. Write is_prime(n) that returns True or False (numbers below 2 are not prime). Use it in a list comprehension to print the primes below 20.

    Your code should print exactly:

    [2, 3, 5, 7, 11, 13, 17, 19]
    Answer

    return False leaves as soon as a divisor is found. Only if the loop finishes is the number prime.

  20. Challenge. Write summary(marks) that returns the average (rounded to 1 decimal), the highest, the lowest and how many passed (35 or more). For [45, 82, 67, 90, 38], unpack it and print Avg 64.4 | High 90 | Low 38 | Passed 5.

    Your code should print exactly:

    Avg 64.4 | High 90 | Low 38 | Passed 5
    Answer

    One function can return a whole report as a tuple, and the caller unpacks it into four clear names.

  21. Challenge. Write price_after(price, discount=0, gst=18): take off discount% first, then add gst%, and round to 2 decimals. Print price_after(1000), price_after(1000, discount=10) and price_after(1000, gst=5, discount=20) with one print().

    Your code should print exactly:

    1180.0 1062.0 840.0
    Answer

    Keyword arguments let you change any default you want, in any order, and leave the others as they are.

  22. Challenge. Type exactly what this code prints.

    Answer
    big medium None

    For 2, neither if is true and the function reaches its end without a return, so it gives None.

  23. Challenge. This code should print False, but it prints False and then None. Fix it.

    It should print:

    False
    Answer

    Printing inside the function is not the same as returning. The caller only gets what you return.

  24. Challenge. Write to_celsius(f) that returns (f - 32) * 5 / 9 rounded to 1 decimal, and report(temps) that uses it to return a list of Celsius values. Print report([98.6, 32, 212]).

    Your code should print exactly:

    [37.0, 0.0, 100.0]
    Answer

    Small functions can call each other: report() reuses to_celsius() for every value.

  25. Challenge. Write percent(part, whole) that returns part / whole * 100 rounded to 1 decimal. Call it with keyword arguments in the other order, percent(whole=200, part=50), and print the result.

    Your code should print exactly:

    25.0
    Answer

    With keyword arguments the order does not matter: each value goes to the parameter with that name.
