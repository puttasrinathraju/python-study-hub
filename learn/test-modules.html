18.1 Big Test: Modules & libraries

25 questions on Modules and libraries only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    10 9 7.0

    ceil always rounds up, floor always rounds down, and sqrt always gives a float.

  2. Basic. A van carries 12 boxes per trip. Use math.ceil to print how many trips are needed for 50 boxes.

    Your code should print exactly:

    5
    Answer

    50 / 12 is about 4.17, and a part trip is still a trip, so round up: 5.

  3. Basic. Import sqrt and pi from math with one from ... import line. Print sqrt(81) and pi rounded to 2 decimals, with one print().

    Your code should print exactly:

    9.0 3.14
    Answer

    from math import sqrt, pi lets you use the names without the math. in front.

  4. Basic. Import statistics as st. Print the mean and the median of [12, 15, 20, 14, 16] with one print().

    Your code should print exactly:

    15.4 15
    Answer

    The mean adds and divides (15.4). The median is the middle value after sorting (15).

  5. Basic. Use datetime to make the date 25 October 2026 and print it as 25/10/2026 with strftime.

    Your code should print exactly:

    25/10/2026
    Answer

    %d, %m and %Y are the day, month and 4-digit year.

  6. Basic. This code should print 4.0, but it crashes. Fix the print line.

    It should print:

    4.0
    Answer

    import math brings in the module, so its functions need the math. prefix.

  7. Basic. Type exactly what this code prints.

    Answer
    3 [('a', 3)]

    Counter counts each item. most_common(1) gives a list with the top (item, count) pair.

  8. Basic. This code should print 4, but it crashes. Fix the print line.

    It should print:

    4
    Answer

    With as st, the module is known only by its short name st.

  9. Medium. A guest checks in on 30 October 2026 for 4 nights. Use date and timedelta to print the checkout day like Tuesday, 03 November 2026 ("%A, %d %B %Y").

    Your code should print exactly:

    Tuesday, 03 November 2026
    Answer

    Adding a timedelta moves the date forward, across month ends too.

  10. Medium. Print the number of days from 15 August 2026 to 2 October 2026 by subtracting two dates.

    Your code should print exactly:

    48
    Answer

    Subtracting dates gives a timedelta, and .days is the number of days in it.

  11. Medium. Type exactly what this code prints.

    Answer
    True True

    The same seed gives the same "random" numbers, so a and b are equal. randint(1, 100) includes both ends.

  12. Medium. text = "Order 12 shipped, order 7 pending, order 105 cancelled". Use re.findall to get every number, and print them as a list of ints.

    Your code should print exactly:

    [12, 7, 105]
    Answer

    \d+ means one or more digits. findall returns the matches as text, so convert them.

  13. Medium. Group words = ["apple", "avocado", "banana", "cherry", "blueberry"] by their first letter with defaultdict(list), and print dict(groups).

    Your code should print exactly:

    {'a': ['apple', 'avocado'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}
    Answer

    A defaultdict(list) makes an empty list the first time a key is used, so you can append straight away.

  14. Medium. This code should print 2026, but it crashes. Fix the format.

    It should print:

    2026
    Answer

    strptime needs a format that matches the text exactly: day, slash, month, slash, year.

  15. Medium. Type exactly what this code prints.

    Answer
    8.0 8 24

    math.pow always gives a float, while ** keeps whole numbers whole. 4! = 24.

  16. Medium. Shuffle a copy of [1, 2, 3, 4, 5] with random.shuffle. Print the sorted shuffled list, and whether it still has the same items as the original.

    Your code should print exactly:

    [1, 2, 3, 4, 5] True
    Answer

    shuffle() changes the order in place but keeps every item. Sorting proves it without printing a random order.

  17. Medium. Write main() that prints Report ready, and call it only under if __name__ == "__main__":.

    Your code should print exactly:

    Report ready
    Answer

    When you run a file directly, __name__ is "__main__". When it is imported, the block does not run.

  18. Medium. Use dir() to print whether "sqrt" and "mean" are names inside the math module, with one print().

    Your code should print exactly:

    True False
    Answer

    dir(module) lists everything a module has. mean lives in statistics, not in math.

  19. Challenge. From hotel_bookings.csv (use csv.DictReader), print the mean amount rounded to 2 decimals and the median amount. Clean the amounts first: remove ₹ and ,, and skip empty ones. Then use Counter on the room types (cleaned with strip().title()) to print the most common room type and its count.

    Your code should print exactly:

    5870 5200.0
Deluxe 19
    Answer

    Modules work together: csv reads, statistics summarises, and Counter counts the cleaned categories.

  20. Challenge. From hotel_bookings.csv, count the bookings per weekday of check_in. Most dates look like 2026-08-26, but some look like 19/08/2026: try "%Y-%m-%d" with strptime, and on ValueError use "%d/%m/%Y". Name the day with strftime("%A"). Print the weekday with the most bookings and its count.

    Your code should print exactly:

    Monday 10
    Answer

    Turn the text into a real date first (two formats, so try the common one), then into a weekday name, then count.

  21. Challenge. text = "Invoices: INV-2041, INV-0007 and INV-1300 were paid; inv-99 was not." Use re.findall(r"INV-\d{4}", text) to get the 4-digit invoice codes. Print the list, then the total of their numbers.

    Your code should print exactly:

    ['INV-2041', 'INV-0007', 'INV-1300']
3348
    Answer

    \d{4} means exactly 4 digits, and the pattern is case-sensitive, so inv-99 is left out.

  22. Challenge. Type exactly what this code prints.

    Answer
    25 Oct 2026 6

    %b is the short month name. weekday() counts Monday as 0, so Sunday is 6.

  23. Challenge. This code should print ('red', 2), the most common colour. Fix it.

    It should print:

    ('red', 2)
    Answer

    most_common(1) is a list with ONE pair, at index 0. Index 1 does not exist.

  24. Challenge. After random.seed(1), roll a dice 1000 times with random.randint(1, 6). Print whether every roll was from 1 to 6, and whether all 6 faces appeared (use a set).

    Your code should print exactly:

    True True
    Answer

    Check properties of random data instead of exact values: the range, and that every face shows up.

  25. Challenge. This code should print 3.0, but it crashes. Fix the import.

    It should print:

    3.0
    Answer

    Module names are case-sensitive: the module is math in small letters.
