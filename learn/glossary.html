Python glossary

114 key words, A to Z, each with a tiny example.

Abstraction

Hiding complicated details behind simple methods. You call df.groupby() without knowing the code inside it.

From Classes and objects (OOP)

Accumulator

A variable that builds up a result over the rounds of a loop, like a running total.

From For loops and range()

Alias

A short nickname given when importing: import numpy as np. Stick to the standard ones.

From Modules and libraries

Aliasing

b = a does not copy. Both names point at the same list, so a change shows up in both.

From Lists

argmax

The position of the largest value. argmin gives the position of the smallest.

From NumPy operations for analysis

*args

Collects any number of extra positional arguments into a tuple.

From Functions: advanced tools

Argument

The actual value you pass when you call the function.

From Functions: the basics

Array (ndarray)

NumPy's container: a grid of values that all share one type. It prints without commas.

From NumPy basics: arrays

Attribute

A piece of data stored on an object, read with a dot and no brackets: s.name.

From Classes and objects (OOP)

axis

The direction a calculation runs in. axis=0 goes down the rows, axis=1 goes across the columns.

From NumPy operations for analysis

Block

The indented lines after a colon. They run together, as one unit.

From If, elif and else

Boolean (bool)

Only two values: True and False. Every comparison gives one of them.

From Variables and data types

Boolean mask

An array of True/False made by a condition. Put it in square brackets to keep only the True values.

From NumPy operations for analysis

Branch

One possible path in an if / elif / else chain. Only the first True branch runs.

From If, elif and else

Broadcasting

NumPy stretches a single number, a row or a column to match a bigger array.

From NumPy operations for analysis

Class

A blueprint that describes what data each object has and what it can do.

From Classes and objects (OOP)

Class and object

A class is a blueprint. An object is one thing built from it, with its own data and methods.

From the chapter

Class attribute

Data written directly in the class body. It is shared by every object of that class.

From Classes and objects (OOP)

Collection

One variable that holds many values. Python's built-in ones are str, list, tuple, set and dict.

From Lists

Comment

A note for humans. Python ignores everything after # on that line.

From Meet Python

Comprehension

A loop that builds a new collection in one line: [expression for item in items if condition].

From Comprehensions and choosing the right collection

Condition

Any expression that gives True or False. if and while both start with one.

From If, elif and else

Copy

A separate array with its own memory, made with .copy().

From NumPy operations for analysis

CSV

Comma-separated values: a plain-text table with one row per line. Excel and every data tool can read it.

From File handling

Data type

The kind of value: whole number, decimal, text, True/False or nothing. type() tells you which.

From Variables and data types

Decorator

A function that wraps another function to add behaviour. Put @name above the def.

From Functions: advanced tools

Default parameter

A parameter with a value already filled in. The caller can leave it out.

From Functions: the basics

Defining vs calling

def only stores the function. Nothing inside runs until you call it with brackets.

From Functions: the basics

Dictionary

A collection of key: value pairs. You look values up by their key, and keys are unique.

From Dictionaries

Dimension (ndim)

How many directions the array has: 1D is a row, 2D is a table, 3D is a stack of tables.

From NumPy basics: arrays

Distribution

The pattern of which values are likely and which are rare. Normal is a bell curve around the average. Poisson counts events in a time window.

From NumPy extras: iterate, split, search, random and ufuncs

dtype

The one data type every value shares, such as float64. Whole numbers usually show as int64 in Jupyter (older NumPy on Windows shows int32), and as int32 in this browser runner. Both are fine.

From NumPy basics: arrays

else and finally

else runs only when try had no error. finally runs every time, error or not.

From Errors and exceptions

Encapsulation

Keeping data inside the object and changing it only through methods that check the rules. __name hides an attribute.

From Classes and objects (OOP)

enumerate()

Gives you the position and the item together on each round.

From For loops and range()

Escape character

A backslash code inside a string: \n new line, \t tab, \\ one backslash.

From Printing and formatting output

Exception

An error that happens while the code runs, on a line that is valid but fails with this data.

From Errors and exceptions

f-string

A string with an f in front. Anything inside { } is worked out and dropped in.

From Printing and formatting output

File

Data saved outside your program, opened with with open(name, mode) as f:.

From the chapter

File mode

The second argument of open(). It decides whether you read, overwrite, add to or create the file.

From File handling

Function

A named, reusable block of code. It can take inputs and give back a result.

From Functions: the basics

Generator

A function that uses yield. It produces values one at a time, pausing between them.

From Functions: advanced tools

Hashable

A value that can be a dict key or a set item. In practice: immutable values like int, str and tuple.

From Comprehensions and choosing the right collection

Immutable

Cannot be changed. Methods hand back a new value, so store the result.

From Comprehensions and choosing the right collection

Indentation

The 4 spaces at the start of a line. After a line that ends in :, indented lines belong to that block.

From Meet Python

Index

An item's position. It starts at 0. Negative indexes count from the end, so -1 is the last item.

From Strings in depth

Infinite loop

A while loop whose condition never becomes False. In the runner, press Stop to end it.

From While loops, break and continue

Inheritance

A child class gets everything from a parent class and can add or change parts: class Child(Parent):.

From Classes and objects (OOP)

__init__ (constructor)

A special method that runs automatically every time a new object is created. It sets up the attributes.

From Classes and objects (OOP)

Instance attribute

Data that belongs to one object, set with self.x = …. Every object has its own copy.

From Classes and objects (OOP)

Iterable

Anything a for loop can walk through: a string, list, tuple, set, dict or range().

From For loops and range()

Iterator

An object that hands out items one at a time with next(). Every for loop uses one behind the scenes.

From Functions: advanced tools

JSON

A text format for nested data: dicts and lists. It is how most web APIs send data.

From File handling

Keyword argument

An argument passed by name. The order no longer matters.

From Functions: the basics

**kwargs

Collects any number of extra keyword arguments into a dict.

From Functions: advanced tools

lambda

A tiny function with no name and one expression. Mostly used for key= in sorted(), max() and min().

From Functions: advanced tools

LEGB rule

The order Python searches for a name: Local, Enclosing function, Global, Built-in.

From Functions: advanced tools

Library

A collection of modules and packages for one purpose, like NumPy for maths or pandas for tables.

From Modules and libraries

List

An ordered, mutable collection of any values. Duplicates are allowed.

From Lists

Loop

Repeats a block: for once per item, while until a condition becomes False.

From the chapter

Loop and iteration

A loop repeats a block. One round of the loop is called an iteration.

From For loops and range()

Loop else

An else after a for or while. It runs only when the loop finished without break.

From While loops, break and continue

Magic (dunder) method

A method with double underscores, like __str__. Python calls it for you when you use print(), ==, len() or +.

From Classes and objects (OOP)

Method

A function that belongs to a value. Call it with a dot: value.method().

From Strings in depth

Method overriding

A child class writes its own version of a method that the parent already has. The child's version wins.

From Classes and objects (OOP)

Module

One .py file of Python code that you can import and reuse.

From Modules and libraries

Mutable

Can be changed in place after it is created: lists, sets and dicts.

From Comprehensions and choosing the right collection

Nested loop

A loop inside a loop. The inner loop runs completely for every round of the outer loop.

From For loops and range()

None

A special value meaning "no value yet". It is not 0 and not an empty string.

From Variables and data types

np.where

Picks a value from two options for every element, based on a condition.

From NumPy operations for analysis

NumPy

Python's library for fast maths on large sets of numbers. pandas is built on top of it.

From NumPy basics: arrays

NumPy array

A grid of values of one type that does maths on every value at once.

From the chapter

Object (instance)

One thing made from a class. Each object is separate, even when made from the same class.

From Classes and objects (OOP)

Object-oriented programming

A way of organising code around objects that bundle data and the actions on that data together.

From Classes and objects (OOP)

Operator

A symbol that does work on values: maths, comparisons, logic.

From the chapter

Operator and operand

An operator is the symbol that does the work (+, >, and). The values it works on are the operands.

From Operators

Package

A folder of related modules. You reach the modules inside with a dot, like urllib.parse.

From Modules and libraries

Parameter

A name in the def line. It is a placeholder that receives a value when the function is called.

From Functions: the basics

pickle

Saves almost any Python object to a binary file and loads it back exactly. Open with "wb" and "rb".

From File handling

pip

Python's installer for libraries that are not built in. In a notebook use %pip install name.

From Modules and libraries

Polymorphism

Different classes share a method name, so one piece of code can work with all of them.

From Classes and objects (OOP)

Precedence

The order operators run in: brackets, **, then * / // %, then + -, then comparisons, then not, and, or.

From Operators

Program

A list of instructions. Python runs them from the top line to the bottom line.

From Meet Python

@property

Turns a method into something you read like an attribute, with no brackets.

From Classes and objects (OOP)

raise

Stops the code with an error you choose, and a clear message.

From Errors and exceptions

Random seed

A starting number for the random generator. The same seed gives the same "random" numbers every run, so anyone can repeat your results.

From NumPy extras: iterate, split, search, random and ufuncs

range()

Makes a run of whole numbers: range(start, stop, step). Stop is never included.

From For loops and range()

Recursion

A function that calls itself. It needs a base case that stops the calls.

From Functions: advanced tools

reshape

Gives the same values a new shape. The total count must stay the same. -1 means "work it out".

From NumPy basics: arrays

Return value

What return hands back. You can store it and keep calculating with it.

From Functions: the basics

Scope

Where a name can be seen. A name created inside a function is local to it.

From Functions: advanced tools

self

The object a method is working on. Python passes it in for you, so it is always the first parameter.

From Classes and objects (OOP)

Sequence

An ordered collection you can index and slice: strings, lists, tuples and range().

From Strings in depth

Set

An unordered collection of unique items. Duplicates disappear automatically.

From Sets

shape

The size in each direction, as a tuple. For a table it is (rows, columns).

From NumPy basics: arrays

size

The total number of values in the array: rows × columns.

From NumPy basics: arrays

Slice

A piece cut out with [start:stop:step]. Start is included, stop is not.

From Strings in depth

String

An ordered, immutable sequence of characters. In other words: text.

From Strings in depth

super()

Calls the parent class's version of a method, most often super().__init__(...) inside the child's __init__.

From Classes and objects (OOP)

Syntax error

The code breaks Python's grammar, so nothing runs. A missing bracket, quote or colon is the usual cause.

From Errors and exceptions

Ternary expression

A one-line if/else that picks one of two values.

From If, elif and else

Traceback

The error report Python prints. The last line names the error type and gives the message. The lines above show where it happened.

From Errors and exceptions

Truthy and falsy

Every value counts as True or False in an if. Empty and zero values are falsy.

From If, elif and else

try / except

Run risky code in try. If a named error happens, Python jumps to the matching except instead of crashing.

From Errors and exceptions

Tuple

An ordered, immutable collection. Think of it as a fixed record whose values belong together.

From Tuples

Type casting

Converting a value to another type with the type's name: int(), float(), str(), bool().

From Variables and data types

ufunc

A universal function: a NumPy function that works on every value of an array at once, in fast compiled code. a + b is really np.add(a, b).

From NumPy extras: iterate, split, search, random and ufuncs

Unpacking

Spreading the items of a collection into separate names. * collects the extras into a list.

From Tuples

Upcasting

When you mix types, NumPy converts everything to the type that can hold them all. One string makes the whole array text.

From NumPy basics: arrays

Variable

A name that points at a value. Create it with =, then use the name anywhere below.

From Variables and data types

Vectorisation

Maths on the whole array at once, with no loop. It is short to write and very fast.

From NumPy operations for analysis

View

A slice that shares memory with the original array. Changing the view changes the original.

From NumPy operations for analysis

with statement

Opens a file and closes it automatically when the block ends, even if an error happens.

From File handling

zip()

Walks two (or more) lists side by side, pairing their items.
