Printing and formatting output

Make your output clear and tidy: print several values, control spaces and new lines, and format numbers like money and percentages.

In this chapter you will learn

  • Print several values with print(), and control sep and end
  • Use single, double and triple quotes, and escape characters like \n
  • Join text with + and repeat it with *
  • Use f-strings to put variables into text
  • Format numbers: 2 decimals, commas, percentages, padding

print() with several values

Put commas between values and print() shows them all on one line, with one space between each. This example is from your course notebook. Compare the two lines carefully.

Trap!

The first line has double spaces and a space before the comma. That is because print() adds its own space between items, on top of the spaces already inside the quotes. The f-string on the second line gives you exact control. This is why f-strings are the preferred way.

sep and end

sep sets what goes between items (default: a space). end sets what goes after the last item (default: a new line).

Easy tip

end=" " is handy in loops when you want results on one line, like 1 2 3 4 5. You will use it in the loops chapters.

Quotes and escape characters

Text can go in single quotes '...' or double quotes "...". They work the same. Pick the one that lets you use the other kind inside. Triple quotes """...""" let text run over several lines.

An escape character is a backslash \ followed by another character. It lets you put special characters inside text.

Raw strings for Windows paths

Put r before the quotes and Python ignores escape characters. This is great for Windows file paths: r"C:\new\data.csv". Without the r, the \n in \new would become a new line.

Joining and repeating text

+ joins (concatenates) two pieces of text. * repeats text. Your course billing system uses "-" * 50 to draw a line.

Trap! You cannot + text and a number

Python will not guess whether you want maths or joining. Convert the number with str(), or better, use an f-string.

f-strings: the best way to format

Put the letter f before the opening quote. Then anything inside curly brackets { } is worked out and dropped into the text. You can put variables, maths, or even method calls inside the brackets.

Animated explainer: How an f-string fills in its slots

  1. An f-string is a template with slots. The f before the quote switches the slots on.
  2. Python finds the first slot, {name}, and replaces it with the value of name.
  3. The second slot has a format spec after the colon. , adds thousands commas and .2f means exactly 2 decimal places.
  4. All slots are filled. The result is a normal string, ready to print or save.

Format specs: the part after the colon

SpecExampleResultUse it for

Why analysts care

Reports live or die by formatting. f"{revenue:,.2f}" turns 1823456.789 into 1,823,456.79, which a manager can actually read.

Key takeaways

  • print(a, b) puts one space between items. Change it with sep. Change the line ending with end.
  • Use \n for a new line, \t for a tab, \\ for a backslash.
  • + joins text, * repeats it. You cannot + text and a number.
  • f-strings: f"Total: {total}". Format with :.2f, :,, :.1%.
  • Use / for percentages, never //.

Flashcards

What do sep and end do in print()?
sep is put between items (default a space). end is put after the last item (default a new line).
How do you write an f-string?
Put f before the quote and variables in curly brackets.
Format a number with 2 decimal places
f"{x:.2f}", for example 3.14159 becomes 3.14
Add thousands commas to a number
f"{x:,}", for example 1500000 becomes 1,500,000
Show 0.256 as a percentage
f"{0.256:.1%}" gives 25.6%
Name 3 escape characters
\n new line, \t tab, \\ backslash. Also \' and \" for quotes.
Why does print("a", "b") show a b?
print() puts one space (the default sep) between items.
What is a raw string?
A string with r in front, like r"C:\new". Backslashes are kept as they are. Great for Windows paths.
