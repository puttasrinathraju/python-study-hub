7.1 Big Test: While loops & break

25 questions on While loops, break and continue only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    10
20
30

    The loop runs while n <= 3: for n = 1, 2 and 3. Each round prints n × 10, then adds 1.

  2. Basic. Use a while loop to print 5, 4, 3, 2, 1 on separate lines, then Lift off!.

    Your code should print exactly:

    5
4
3
2
1
Lift off!
    Answer

    Start at 5, print, then take 1 away each round. When count reaches 0 the condition is False and the loop stops.

  3. Basic. amount = 1000 grows by 10% each year. Use a while loop to count the years until it reaches at least 2000, and print the number of years.

    Your code should print exactly:

    8
    Answer

    You do not know the number of rounds in advance, so while fits better than for. It keeps going while the amount is still below 2000.

  4. Basic. This code should print 1 2 3 4 5, but it stops at 4. Fix it.

    It should print:

    1 2 3 4 5
    Answer

    With n < 5 the loop stops when n is 5. Use <= to include 5.

  5. Basic. Print the numbers 1 to 10 on one line, but skip every multiple of 3 using continue.

    Your code should print exactly:

    1 2 4 5 7 8 10
    Answer

    continue jumps straight to the next round, so the print() is skipped for 3, 6 and 9.

  6. Basic. Type exactly what this code prints.

    Answer
    1 2 3 stop

    break leaves the loop the moment i is 4, before 4 is printed. Then the line after the loop runs.

  7. Basic. Start with n = 1. In a while True loop, double n each round, and break as soon as it is more than 100. Then print n.

    Your code should print exactly:

    128
    Answer

    while True repeats until a break. The values go 2, 4, 8, ... 64, 128, and 128 is the first one above 100.

  8. Basic. This code should print 1 2 4 5 (skipping only 3), but it stops early. Fix it.

    It should print:

    1 2 4 5
    Answer

    break ends the whole loop. continue only skips the current round, which is what we need.

  9. Medium. n = 907215. Count its digits with a while loop that keeps doing n //= 10, and print the count.

    Your code should print exactly:

    6
    Answer

    Each //= 10 removes the last digit. Count the rounds until nothing is left.

  10. Medium. Type exactly what this code prints.

    Answer
    1 5

    x goes 50, 25, 12, 6, 3, 1. That is 5 halvings, and the loop stops when x is 1.

  11. Medium. n = 29. Check if it is prime: try divisors d from 2 while d * d <= n. If one divides n, print 29 is not prime and break. Use while-else to print 29 is prime when no divisor was found.

    Your code should print exactly:

    29 is prime
    Answer

    The else of a while loop runs only when the loop ends without break, which here means no divisor was found.

  12. Medium. This code should print 1, 2 and 3 on separate lines, but it prints only 1. Fix it.

    It should print:

    1
2
3
    Answer

    The last break ends the loop after the first round. The if n > 3: break at the top is enough.

  13. Medium. Add up the odd numbers from 1 to 20 and print the total. Use continue to skip the even ones.

    Your code should print exactly:

    100
    Answer

    continue skips the += for even numbers, so only 1, 3, 5, ..., 19 are added.

  14. Medium. Type exactly what this code prints.

    Answer
    1 1
1 2
2 1
2 2

    break leaves only the inner loop. The outer loop carries on with the next i.

  15. Medium. stock = 23. Orders of 5 units keep coming. In a while True loop: if the stock is below 5, print Stopped: only 3 left (with the real number) and break. Otherwise take 5 away and print Shipped 5, left 18 (with the real number).

    Your code should print exactly:

    Shipped 5, left 18
Shipped 5, left 13
Shipped 5, left 8
Shipped 5, left 3
Stopped: only 3 left
    Answer

    Check the stop condition first in each round, then do the work. The loop ships 4 times: 18, 13, 8, 3.

  16. Medium. Count down from 3 with a while loop, printing each number. Add a while-else that prints Countdown finished when the loop ends normally.

    Your code should print exactly:

    3
2
1
Countdown finished
    Answer

    There is no break, so the loop ends normally and the else runs once.

  17. Medium. A bill has prices = [250, 120, 80] and qtys = [2, 1, 5]. Use a while loop with a position i (0, 1, 2) to add price × quantity to a total. Print Total: ₹1020.

    Your code should print exactly:

    Total: ₹1020
    Answer

    This is the course billing loop without input(): one round per product, adding its price × quantity to the running total.

  18. Medium. This code should print Card blocked only once, after all 3 tries. Fix it.

    It should print:

    Card blocked
    Answer

    The else should belong to the while, not the if. Move it left so it lines up with while.

  19. Challenge. Start with n = 6. While n is not 1: if it is even, halve it with //, otherwise make it 3 * n + 1. Count the steps and print the count.

    Your code should print exactly:

    8
    Answer

    The values go 6, 3, 10, 5, 16, 8, 4, 2, 1. That is 8 steps.

  20. Challenge. n = 4705. Reverse its digits with a while loop, using % 10 and // 10, and print the reversed number.

    Your code should print exactly:

    5074
    Answer

    Each round takes the last digit with % 10 and adds it to the end of reverse. The result is 5074.

  21. Challenge. Find the smallest number greater than 1000 that divides exactly by both 7 and 13. Use while True and break, then print it.

    Your code should print exactly:

    1001
    Answer

    Move to the next number first, then test it. The first one that passes both checks is 1001.

  22. Challenge. Loop over 1 to 30. Skip the numbers that are not multiples of 3, skip the multiples of 5 too, and stop completely at 25. Print the kept numbers on one line.

    Your code should print exactly:

    3 6 9 12 18 21 24
    Answer

    Check the stop first, then the skips. 15 is skipped (a multiple of 5), and the loop stops before 27 and 30.

  23. Challenge. This code should print only the odd numbers 1 3 5. Fix it.

    It should print:

    1 3 5
    Answer

    pass does nothing, so the print() still runs. continue skips the rest of the round.

  24. Challenge. Type exactly what this code prints.

    Answer
    break at 4

    n goes 10, 7, 4. At 4 the break runs, so the else is skipped.

  25. Challenge. A loan of loan = 10000 gets 2% interest added each month, and then 2000 is paid. Count the months until the loan is 0 or less. Print the months and the final loan rounded to 2 decimals, with one print().

    Your code should print exactly:

    6 -1354.62
    Answer

    The number of months is unknown in advance, so use while. The final loan is negative: that is the overpayment in the last month.
