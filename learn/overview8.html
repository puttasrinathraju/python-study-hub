Part 8 overview: Pandas

All four Pandas chapters on one page: the health check for a new file, the cleaning tools, the ways to ask questions, groups and joins, and the mix-ups that cost the most marks (loc vs iloc, map vs replace, agg vs transform, merge vs concat).

The whole Part in 5 lines

  1. A DataFrame is a table and a Series is one column. Load files with pd.read_csv() / pd.read_excel(), and always look first: head(), info(), describe(), isna().sum().
  2. Clean a copy: drop_duplicates(), dropna() or fillna(), .str tools for text, map / replace with a dictionary, astype() for types and pd.to_datetime() for dates.
  3. loc picks by label (end included), iloc by position (end left out). Filter with df[mask], joining conditions with &, |, ~ and brackets, or write query().
  4. New columns: maths on columns, np.where() for yes/no, apply() for your own rule. Sort with sort_values() and find the top row with idxmax() + loc.
  5. groupby + agg summarise groups, transform puts the answer on every row, pivot_table builds a grid, merge joins side by side and concat stacks.

Key definitions

Pandas

The Python library for tables of data: load, clean, select, group and join them.

DataFrame

A table: named columns, and rows labelled by the index.

Series

One column of a DataFrame: values with index labels.

Index

The row labels on the left. 0, 1, 2 ... unless you choose them.

NaN

"Not a number": an empty cell. isna() finds it; it makes a number column decimal.

object (dtype)

The type Pandas shows for text columns, and for numbers stored as text.

Duplicate

A row that repeats an earlier one. duplicated() marks it, drop_duplicates() removes it.

fillna

Fills the gaps with a value you choose: 0, the mean, the median or the mode.

.str accessor

Runs a string method on every value of a text column.

NaT

"Not a time": a missing date, made by pd.to_datetime(..., errors="coerce").

loc

Picks rows and columns by label and name. A slice includes its end.

iloc

Picks rows and columns by position. A slice leaves out its end.

Boolean mask (Pandas)

A True/False Series made by a condition. df[mask] keeps the True rows.

apply

Runs your own function on every value, or on every row with axis=1.

groupby

Splits rows into groups, summarises each group, combines the answers.

transform

A group's answer placed on every row of that group.

Pivot table

A grid of summaries: rows from one column, columns from another.

merge

Joins two tables side by side where a key column matches, like SQL JOIN.

concat

Stacks tables on top of each other, like SQL UNION ALL.

Correlation

How two number columns move together, from -1 (opposite) to 1 (together).

Don't mix these up

Don't mix up: Series vs DataFrame

SeriesDataFrame
What it isOne columnA whole table
Made withpd.Series([...])pd.DataFrame({...})
You get it fromdf["pay"]df[["pay"]] or df[["name", "pay"]]
Printsvalues, then Name: and dtype:a table with column names on top

Rule of thumb: One pair of brackets: a column (Series). A list inside the brackets: a table (DataFrame).

Don't mix up: loc vs iloc

lociloc
Picks bylabels and namespositions
[0:2] gives3 rows (end included)2 rows (end left out)
Takes a conditionYesNo

Rule of thumb: Know the name? loc. Know the position? iloc.

Don't mix up: dropna vs fillna

dropna()fillna(value)
The gap's rowRemovedKept, with a value in the gap
Rows afterwardsFewerThe same
Use it whenFew gaps, or the row is useless without the valueThe row matters and a fair guess exists

Rule of thumb: Losing rows changes your totals. Fill when the row still matters.

Don't mix up: ffill vs bfill

ffill()bfill()
Copiesthe last value abovethe next value below
A gap at the startStays NaNFilled
A gap at the endFilledStays NaN

Rule of thumb: Forward fill looks back; backward fill looks ahead.

Don't mix up: map vs replace

map({...})replace({...})
Values in the dictionaryChangedChanged
Values not in itBecome NaNStay as they are
Best forTranslating every valueFixing a few values

Rule of thumb: Fixing some values? replace. Translating all of them? map.

Don't mix up: and / or vs & / |

and / or& / |
Works onOne True/FalseA whole column of True/False
Inside df[...]ValueErrorWorks, with brackets
Inside query("...")WorksWorks too

Rule of thumb: On columns: &, |, ~ and brackets around every condition.

Don't mix up: apply vs np.where

apply(func)np.where(cond, a, b)
HandlesAny rule, with if / elif / elseOne yes/no rule
SpeedSlower: calls your function for every rowFast: the whole column at once
Several columnsdf.apply(func, axis=1)Conditions on several columns with &

Rule of thumb: Two choices? np.where. Three or more? apply with a def.

Don't mix up: max vs idxmax

max()idxmax()
GivesThe biggest valueIts index label
Use it toReport the top numberFind the whole top row with loc

Rule of thumb: Who has it? idxmax + loc.

Don't mix up: agg vs transform

groupby().agg()groupby().transform()
Rows in the answerOne per groupOne per original row
IndexThe group namesThe original index
Use it forA reportA new column on every row

Rule of thumb: A short report? agg. Compare each row with its group? transform.

Don't mix up: merge vs concat

pd.merge(a, b, on=...)pd.concat([a, b])
DirectionSide by sideOn top
Matches byA key columnPosition (it just stacks)
SQLJOINUNION ALL

Rule of thumb: New columns? merge. More rows? concat.

Don't mix up: inner vs left vs outer

how=KeepsUnmatched cells
"inner"Keys in both tablesNone: those rows are dropped
"left"Every row of the left tableNaN in the right table's columns
"outer"Every row of bothNaN on both sides

Rule of thumb: Never lose a row of your main table? left. After any merge, check the row count.

Try it yourself

Pandas takes about 10 to 20 seconds to load the first time you press Run. After that it is quick. These tasks mix all four chapters.

  1. Read employees.csv, remove the duplicate row, fill the missing salaries with the median and print the average salary of each department after tidying the names (strip, title case, then replace It and Hr with IT and HR).

    Hint

    drop_duplicates(), fillna(median), .str.strip().str.title().replace({...}), then groupby.

    Solution

    Clean first, then group: messy names would have split one department into several groups.

  2. Read sales_data.csv. Keep the orders with a profit above ₹1,000 and print how many of them each region has.

    Hint

    A mask, then value_counts() or groupby(...).size().

    Solution

    groupby(...).size() sorts by region name, so the order never depends on ties.

  3. Read sales_data.csv. Add a column Month (the month name of each date) and print the total sales of October and November together.

    Hint

    pd.to_datetime, .dt.month_name(), then isin(["October", "November"]).

    Solution

    Diwali season: these two months bring in more than a third of the year's sales.

  4. Read student_scores.csv (first column as the index). Print the average maths score for each TestPrep value, rounded to 1 decimal, and the number of students with no TestPrep value.

    Hint

    groupby("TestPrep")["MathScore"].mean().round(1), and isna().sum().

    Solution

    groupby leaves out the rows where the group value is missing, so check how many there are.

Mixed quiz

  1. What does this print?

    1. (3, 3)
    2. 3
    3. (3,)
    4. 9
    Answer

    (3, 3). shape is (rows, columns).

  2. Which line gives a Series?

    1. df["pay"]
    2. df[["pay"]]
    3. df[["name", "pay"]]
    4. df.head()
    Answer

    df["pay"]. One pair of brackets with one name gives a Series.

  3. info() shows salary 38 non-null in a table of 41 rows. What does that mean?

    1. 38 duplicates
    2. 3 salaries are missing
    3. 38 different salaries
    4. The column is text
    Answer

    3 salaries are missing. Non-null means filled. 41 − 38 = 3 gaps.

  4. What does this print?

    1. [10.0, 20.0, 30.0]
    2. [10.0, 0.0, 30.0]
    3. [10.0, 30.0]
    4. [10.0, nan, 30.0]
    Answer

    [10.0, 20.0, 30.0]. The mean of 10 and 30 is 20, which fills the gap.

  5. What does this print?

    1. ['IT', nan]
    2. ['IT', 'Sales']
    3. ['It', 'Sales']
    4. A KeyError
    Answer

    ['IT', nan]. map turns values not in the dictionary into NaN.

  6. Why add dayfirst=True to pd.to_datetime()?

    1. To sort by day
    2. So 03/04/2025 means 3 April, not March 4
    3. To remove the time
    4. To make NaT
    Answer

    So 03/04/2025 means 3 April, not March 4. Indian dates put the day first.

  7. What does this print?

    1. 3 2
    2. 2 2
    3. 3 3
    4. 2 3
    Answer

    3 2. loc includes the end label; iloc leaves out the end position.

  8. Which filter is correct?

    1. df[df["a"] > 1 and df["b"] < 5]
    2. df[(df["a"] > 1) & (df["b"] < 5)]
    3. df[df["a"] > 1 & df["b"] < 5]
    4. df.loc("a" > 1)
    Answer

    df[(df["a"] > 1) & (df["b"] < 5)]. Use & with brackets around each condition.

  9. What does this print?

    1. ['Low', 'High']
    2. ['High', 'Low']
    3. [False, True]
    4. ['Low', 'Low']
    Answer

    ['Low', 'High']. The lambda labels 45000 as Low and 72000 as High.

  10. You need the name of the person with the highest pay. Which line?

    1. df["pay"].max()
    2. df.loc[df["pay"].idxmax(), "name"]
    3. df["name"].max()
    4. df.sort_values("pay")["name"]
    Answer

    df.loc[df["pay"].idxmax(), "name"]. idxmax finds where the top value is; loc gives the name.

  11. What does this print?

    1. [58000.0, 45000.0]
    2. [45000.0, 65000.0]
    3. [65000.0, 45000.0]
    4. [45000.0, 58000.0, 72000.0]
    Answer

    [45000.0, 65000.0]. Groups come out sorted: HR (45000), then IT ((72000 + 58000) / 2 = 65000).

  12. Which one returns one value for every row?

    1. groupby("g")["v"].mean()
    2. groupby("g")["v"].agg("sum")
    3. groupby("g")["v"].transform("sum")
    4. pivot_table(...)
    Answer

    groupby("g")["v"].transform("sum"). transform keeps the original rows.

  13. What does this print?

    1. 3
    2. 2
    3. 4
    4. 1
    Answer

    3. A left join keeps all 3 rows of df.

  14. You have January and February sales files with the same columns. How do you combine them?

    1. pd.merge(jan, feb, on="id")
    2. pd.concat([jan, feb], ignore_index=True)
    3. jan + feb
    4. jan.join(feb)
    Answer

    pd.concat([jan, feb], ignore_index=True). Same columns, more rows: concat.

  15. What does this print?

    1. ['Low', 'High', 'High']
    2. ['Low', 'Low', 'High']
    3. ['High', 'High', 'High']
    4. ['Low', 'High', nan]
    Answer

    ['Low', 'Low', 'High']. Each range includes its right edge: 50 is Low.

  16. A correlation of 0.95 between ad spend and sales means:

    1. Ads cause sales
    2. They rise together very strongly
    3. There is no link
    4. Sales fall when ads rise
    Answer

    They rise together very strongly. Near 1: they move together. It does not prove that one causes the other.

Fill gaps fairly
Numbers: fillna(s.median()). Categories: fillna(s.mode()[0]). Over time: ffill().

map vs replace
map: every value (others NaN). replace: only the ones you list.
loc vs iloc
loc: labels, end included. iloc: positions, end left out.
Two conditions
df[(c1) & (c2)]; or df.query("a > 1 and b < 5")
apply vs np.where
apply: any rule, slower. np.where: one yes/no rule, fast.
The top row
df.loc[df["col"].idxmax()]
agg vs transform
agg: one row per group. transform: every row gets its group's answer.
Named aggregation
df.groupby("g").agg(total=("v", "sum"), n=("v", "count"))
merge vs concat
merge: side by side on a key. concat: stacked on top.
Find unmatched rows after a left merge
m[m["right_col"].isna()]
Numbers into bands
pd.cut(s, bins=[...], labels=[...]); group with observed=True.
