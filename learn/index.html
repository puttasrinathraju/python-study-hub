What Python is, variables, printing and operators.

Part 2: Decisions and loops

Make your code choose and repeat.

  1. 5. If, elif and else – Teach your program to make decisions: run some code only when a condition is True, and choose between several paths.
  2. 6. For loops and range() – Repeat code for every item in a list, every letter in a word, or every number in a range. This is where Python starts saving you real time.
  3. 7. While loops, break and continue – Repeat code for as long as a condition stays True, and take control of any loop with break, continue and pass.

Part 3: Collections

Strings, lists, tuples, sets and dictionaries.

  1. 8. Strings in depth – Text is everywhere in data: names, cities, emails, product codes. Learn to pick out parts of a string, clean it up and check what it contains.
  2. 9. Lists – The list is Python's most used collection: an ordered, changeable row of items. Learn to add, remove, sort and copy, and avoid the copying trap that catches everyone.
  3. 10. Tuples – A tuple is a list that cannot be changed. Learn when that is exactly what you want, and master packing and unpacking.
  4. 11. Sets – A set is a bag of unique items with no order. It removes duplicates for free and compares groups in one line: who is in both lists, who is missing, who is new.
  5. 12. Dictionaries – A dictionary stores data as key: value pairs, so you find things by name instead of by position. It is the shape of most real data: a customer record, a product, a row from a database.
  6. 13. Comprehensions and choosing the right collection – Write loops that build lists in one clear line, then step back and compare strings, lists, tuples, sets and dictionaries so you always pick the right one.
  7. Part 3 overview – The five collections side by side: what each one is, when to use it, and the methods people confuse. Start with the big table, then work through the "don't mix these up" pairs.

Part 4: Functions

Write code once, use it everywhere.

  1. 14. Functions: the basics – A function is a named, reusable block of code. Write it once, call it whenever you need it. This is how you stop copying and pasting code.
  2. 15. Functions: advanced tools – The tools that make functions flexible: any number of arguments, scope rules, lambda, recursion, generators and decorators. Several of these are classic interview questions.
  3. Part 4 overview – Both function chapters on one page: how to define and call a function, every way to pass inputs, scope, and the advanced tools. The pairs people confuse most are in the "don't mix these up" tables.

Part 5: Real-world Python

Errors, files and modules.

  1. 16. Errors and exceptions – Errors are not failures, they are messages. Learn to read them in seconds, and use try/except so bad input does not crash your program.
  2. 17. File handling – Save results to files and load data back in. Plain text, CSV, JSON and pickle: the four ways you will move data in and out of Python.
  3. 18. Modules and libraries – Python comes with a huge toolbox, and thousands more tools can be installed in one line. Learn how to import them, and get to know the modules analysts use most.
  4. Part 5 overview – The tools that make Python useful in real work, side by side: handling errors, reading and writing files, and importing modules. Use the tables to pick the right error, file mode, format or import style.

Classes, objects and inheritance.

  1. 19. Classes and objects (OOP) – Object-oriented programming bundles data and the functions that work on it into one unit. It is how the PDF's inventory system is built, and how libraries like pandas are designed.

Part 7: NumPy

Fast number crunching for data analysis.
