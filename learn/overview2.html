Part 2 overview: decisions and loops

Everything from Part 2 side by side: how code chooses with if, and how it repeats with for and while. The tables below show exactly where beginners mix these up.

The whole Part in 5 lines

  1. if runs a block only when its condition is True. In an if / elif / else chain only the first True branch runs.
  2. Falsy values are 0, 0.0, "", [], (), {}, set(), None and False. Everything else counts as True.
  3. for takes one item per round from a sequence. range(start, stop, step) never includes stop.
  4. while repeats while its condition stays True, so something inside must change. while True plus break is the menu pattern.
  5. break leaves the loop, continue skips to the next round and pass does nothing. A loop's else runs only when no break happened.

Key definitions

Condition

Any expression that gives True or False. if and while both start with one.

Block

The indented lines after a colon. They run together, as one unit.

Branch

One possible path in an if / elif / else chain. Only the first True branch runs.

Truthy and falsy

Every value counts as True or False in an if. Empty and zero values are falsy.

Ternary expression

A one-line if/else that picks one of two values.

Loop and iteration

A loop repeats a block. One round of the loop is called an iteration.

Iterable

Anything a for loop can walk through: a string, list, tuple, set, dict or range().

range()

Makes a run of whole numbers: range(start, stop, step). Stop is never included.

Accumulator

A variable that builds up a result over the rounds of a loop, like a running total.

enumerate()

Gives you the position and the item together on each round.

zip()

Walks two (or more) lists side by side, pairing their items.

Nested loop

A loop inside a loop. The inner loop runs completely for every round of the outer loop.

Infinite loop

A while loop whose condition never becomes False. In the runner, press Stop to end it.

Loop else

An else after a for or while. It runs only when the loop finished without break.

Try it yourself

These tasks combine if with both kinds of loop. Every comparison table above also has an Edit and run this example button.

  1. Print the numbers 1 to 15 on one line. Print Fizz for multiples of 3, Buzz for multiples of 5 and FizzBuzz for multiples of both.

    Hint

    Check the strictest case (n % 15 == 0) first, then 3, then 5. Use end=" ".

    Solution

    If you checked % 3 first, 15 would print Fizz and never reach FizzBuzz, because only the first True branch runs.

  2. Add up the even numbers from 1 to 50. Use continue to skip the odd ones. Print 650.

    Hint

    Start total = 0, loop over range(1, 51), and continue when n % 2 == 1.

    Solution

    continue jumps straight to the next round, so odd numbers never reach total += n.

  3. You have ₹1000 and pay ₹180 a month. Use a while loop to count the full months you can pay. Print 5 months, ₹100 left.

    Hint

    Loop while balance >= 180. Inside, subtract 180 and add 1 to months.

    Solution

    You do not know the number of rounds in advance, so while fits. balance changes every round, so the loop ends.

  4. scores = [72, 55, 38, 90]. Find the first score below 40 and print First fail: 38 at position 3. If there is none, print Everyone passed.

    Hint

    Use enumerate(scores, start=1), break when you find it, and a for … else for the "none" case.

    Solution

    break stops at the first match, and the loop's else only runs when no break happened.

Mixed quiz

  1. What does this print?

    1. A
    2. C
    3. A and C
    4. F
    Answer

    C. Only the first True branch runs. 85 >= 50 is True, so the chain stops there. Put the strictest check first.

  2. What does this print?

    1. [2, 5, 8]
    2. [2, 5, 8, 11]
    3. [3, 6, 9]
    4. [2, 4, 6, 8]
    Answer

    [2, 5, 8]. Start at 2 and jump by 3: 2, 5, 8. The next one, 11, is past the stop.

  3. What does this print?

    1. 7
    2. 12
    3. 4
    4. 3
    Answer

    12. The inner loop runs all 4 rounds for each of the 3 outer rounds: 3 × 4 = 12.

  4. What does this print?

    1. 1 2
    2. 1 2 4 5
    3. 1 2 3 4 5
    4. 3
    Answer

    1 2 4 5. continue skips only the round where n is 3. The loop carries on.

  5. What does this print?

    1. 1 2
    2. 1 2 4 5
    3. 1 2 3
    4. 3 4 5
    Answer

    1 2. break leaves the loop completely when n reaches 3.

  6. Which of these values is truthy?

    1. 0
    2. ""
    3. "0"
    4. []
    Answer

    "0". "0" is a non-empty string, so it counts as True. Only empty or zero values are falsy.

  7. What does this print?

    1. no
    2. yes
    3. An error
    4. Nothing
    Answer

    yes. Python reads (x == 1) or 2. The 2 on its own is truthy, so the condition is always True. Write x in (1, 2).

  8. What does this print?

    1. 1
    2. 0
    3. -2
    4. 10
    Answer

    -2. 10, 7, 4, 1, then -2. Only at -2 is n > 0 False, so the loop stops there.

  9. What does this print?

    1. Nothing
    2. done
    3. 4
    4. An error
    Answer

    done. 4 is never found, so break never runs and the loop's else block runs.

  10. What does this print?

    1. [(0, 'a'), (1, 'b')]
    2. [(1, 'a'), (2, 'b')]
    3. ['a', 'b']
    4. [0, 1]
    Answer

    [(0, 'a'), (1, 'b')]. enumerate() pairs each item with its position, starting at 0 unless you pass start=.

  11. Which loop fits "keep asking until the user types a valid number"?

    1. for i in range(10):
    2. while True: with a break when the input is valid
    3. A nested for loop
    4. An if / elif chain
    Answer

    while True: with a break when the input is valid. You do not know how many tries it will take, so loop forever and break once the input is good.

  12. What does this print?

    1. 0 0; 1 0; 2 0;
    2. 0 0;
    3. 0 0; 0 1; 0 2;
    4. 0 0; 1 1; 2 2;
    Answer

    0 0; 1 0; 2 0;. break only leaves the inner loop. The outer loop still runs all three rounds.

Flashcards

In an if / elif / else chain, how many branches run?
Only one: the first whose condition is True. If none is True, the else runs.
List the falsy values
0, 0.0, "", [], (), {}, set(), None and False. Everything else is truthy.
What numbers does range(1, 11) give?
1 to 10. The stop value is never included.
for or while?
for when you know the items or the count. while when you repeat until something happens.
break vs continue vs pass
break leaves the loop. continue skips to the next round. pass does nothing.
When does a loop's else run?
Only when the loop finished without hitting break. Handy for "not found" messages.
Why is if x == 1 or 2: a bug?
It means (x == 1) or 2, and 2 is always truthy. Write if x in (1, 2):.
What does enumerate(items, start=1) give each round?
A pair: the position (from 1) and the item.
What does zip(a, b) do?
Pairs the items of two lists by position and stops at the shorter one.
How do you stop a while loop from running forever?
Change something inside the loop so the condition can become False, or use break.
The running-total pattern
Start at 0, add each item.
How many times does the inner loop body run?
Outer rounds × inner rounds. range(3) inside range(4) runs 12 times.
