Part 5 overview: errors, files and modules

The tools that make Python useful in real work, side by side: handling errors, reading and writing files, and importing modules. Use the tables to pick the right error, file mode, format or import style.

The whole Part in 5 lines

  1. A syntax error stops your code before it runs. An exception happens while it runs. Read a traceback from the bottom line up.
  2. try: holds the risky code, except SomeError: says what to do instead, else: runs if nothing failed and finally: always runs. raise creates your own error.
  3. open(name, mode): "r" read, "w" overwrite, "a" append, "x" create new. Use with open(...) as f: so the file always closes.
  4. Pick the format by the data: plain text for lines, CSV for tables, JSON for nested data, pickle for your own Python objects.
  5. A module is one .py file, a package is a folder of modules and a library is a collection of them. Import with import math, import numpy as np or from math import sqrt.

Key definitions

Syntax error

The code breaks Python's grammar, so nothing runs. A missing bracket, quote or colon is the usual cause.

Exception

An error that happens while the code runs, on a line that is valid but fails with this data.

Traceback

The error report Python prints. The last line names the error type and gives the message. The lines above show where it happened.

try / except

Run risky code in try. If a named error happens, Python jumps to the matching except instead of crashing.

else and finally

else runs only when try had no error. finally runs every time, error or not.

raise

Stops the code with an error you choose, and a clear message.

File mode

The second argument of open(). It decides whether you read, overwrite, add to or create the file.

with statement

Opens a file and closes it automatically when the block ends, even if an error happens.

CSV

Comma-separated values: a plain-text table with one row per line. Excel and every data tool can read it.

JSON

A text format for nested data: dicts and lists. It is how most web APIs send data.

pickle

Saves almost any Python object to a binary file and loads it back exactly. Open with "wb" and "rb".

Module

One .py file of Python code that you can import and reuse.

Package

A folder of related modules. You reach the modules inside with a dot, like urllib.parse.

Library

A collection of modules and packages for one purpose, like NumPy for maths or pandas for tables.

Alias

A short nickname given when importing: import numpy as np. Stick to the standard ones.

pip

Python's installer for libraries that are not built in. In a notebook use %pip install name.

Don't mix these up

Don't mix up: Syntax error vs exception

Syntax errorException
WhenBefore any line runsWhile the code is running
CauseBroken grammar: a missing colon, bracket or quoteA valid line fails with this data
Exampleif x > 1 (no colon)int("abc")

Rule of thumb: Syntax errors are typing mistakes. Exceptions are things that go wrong with real data.

Don't mix up: except vs else vs finally

exceptelsefinally
Runs whenThe try block raised that errorThe try block raised no errorAlways
Use it forPlan BThe next step that needs the try to have workedClean-up: closing, saving, a log line

Rule of thumb: Keep the try block short: only the line that can fail. Put the follow-up in else.

Don't mix up: raise vs except

raiseexcept
DoesCreates an error and stopsCatches an error and carries on
Who writes itThe person who spots the problem (often inside a function)The person who knows what to do about it (often the caller)
Exampleraise ValueError("age cannot be negative")except ValueError as e:

Rule of thumb: Raise early with a clear message. Catch where you can actually fix it.

Don't mix up: except ValueError vs except Exception

except ValueError:except Exception:
CatchesOnly that error typeAlmost every error
RiskOther errors still show up (good)Hides real bugs, like a typo that causes a NameError
Order when you use bothFirstLast, as a safety net

Rule of thumb: Name the error you expect. Use except Exception only as the last line of defence, and print the error.

Try it yourself

These tasks use real files inside the runner's own folder, so you can write and read them safely. Every comparison table above also has an Edit and run this example button.

  1. Write safe_int(text) that returns the number, or None when the text is not a number. Then print [safe_int(t) for t in ["12", "x", "7"]].

    Hint

    try: return int(text) and except ValueError: return None.

    Solution

    The bad value does not crash the list. It just becomes None, which you can count or filter out later.

  2. Write three students to marks.csv with csv.writer, read the file back with csv.DictReader, and print the average mark: 80.0.

    Hint

    Write a header row first. DictReader gives text, so convert each mark with int().

    Solution

    Everything read from a CSV is text, so the marks need int() before you can do maths.

  3. Save settings = {"city": "Pune", "dark_mode": True} to settings.json, load it back, and print Pune True.

    Hint

    json.dump(settings, f) with "w", then json.load(f) with "r".

    Solution

    JSON turns Python's True into true in the file and back into True when you load it.

  4. Count the words in text = "the cat and the hat and the bat" and print the two most common: [('the', 3), ('and', 2)].

    Hint

    from collections import Counter, then Counter(text.split()).most_common(2).

    Solution

    The standard library already has a tool for counting. Importing it beats writing the loop yourself.

  5. How many days are there from 27 October 2024 to 25 December 2024? Print 59.

    Hint

    from datetime import date, then subtract one date from the other and read .days.

    Solution

    Subtracting two dates gives a timedelta, and .days reads the number of days in it.

Mixed quiz

  1. Which kind of error stops the code before any line runs?

    1. ValueError
    2. SyntaxError
    3. KeyError
    4. ZeroDivisionError
    Answer

    SyntaxError. Python checks the grammar of the whole file first. A syntax error means nothing runs at all.

  2. What happens here?

    1. It prints 3
    2. It prints 3.5
    3. A ValueError
    4. A TypeError
    Answer

    A ValueError. int() cannot read text with a decimal point. Use int(float("3.5")) or float("3.5").

  3. What does this print?

    1. ['try', 'except', 'finally']
    2. ['try', 'else', 'finally']
    3. ['try', 'except', 'else', 'finally']
    4. ['except', 'finally']
    Answer

    ['try', 'except', 'finally']. An error happened, so except runs and else is skipped. finally always runs.

  4. What does mode "w" do to a file that already exists?

    1. Adds to the end
    2. Wipes it, then writes
    3. Raises FileExistsError
    4. Opens it read-only
    Answer

    Wipes it, then writes. "w" empties the file the moment it opens. Use "a" to add to it.

  5. Why should you open files with with open(...) as f:?

    1. It reads faster
    2. It closes the file automatically, even if there is an error
    3. It is the only way to write
    4. It makes a backup
    Answer

    It closes the file automatically, even if there is an error. The with block closes the file for you when it ends.

  6. What does this print?

    1. {'a': (1, 2)}
    2. {"a": [1, 2]}
    3. {"a": (1, 2)}
    4. An error
    Answer

    {"a": [1, 2]}. JSON has no tuples, so the tuple becomes a list. JSON also always uses double quotes.

  7. Which mode do you need for pickle.dump(obj, f)?

    1. "w"
    2. "wb"
    3. "a"
    4. "r"
    Answer

    "wb". pickle writes bytes, so the file needs binary mode: "wb" to write and "rb" to read.

  8. What does this print?

    1. 7
    2. 7.0
    3. math.sqrt(49)
    4. An error
    Answer

    7.0. from math import sqrt lets you call sqrt directly. It always returns a float.

  9. What does this print?

    1. missing b
    2. missing 'b'
    3. missing KeyError
    4. Nothing
    Answer

    missing 'b'. A KeyError's message is the missing key, shown with quotes.

  10. You use both except ValueError: and except Exception:. Which should come first?

    1. except Exception:
    2. except ValueError:
    3. The order does not matter
    4. You cannot use both
    Answer

    except ValueError:. Python uses the first matching except. Exception matches almost everything, so it must come last.

  11. What does this print?

    1. 9 Mar 2024
    2. 09 Mar 2024
    3. 2024-03-09
    4. 09/03/2024
    Answer

    09 Mar 2024. %d is the day with a leading zero, %b the short month name and %Y the four-digit year.

  12. What is a package?

    1. One .py file
    2. A folder of related modules
    3. A single function
    4. A file you install with open()
    Answer

    A folder of related modules. A module is one file. A package is a folder of modules, reached with dots like urllib.parse.

Flashcards

Syntax error vs exception
A syntax error is broken grammar and nothing runs. An exception happens while the code runs, and try / except can catch it.
How do you read a traceback?
From the bottom. The last line gives the error type and message. The line above it shows where it happened.
except vs else vs finally
except: an error happened. else: no error happened. finally: always runs.
What does raise do?
Stops the program with an error you choose.
TypeError vs ValueError
TypeError: wrong type ("5" + 5). ValueError: right type, bad value (int("abc")).
"w" vs "a" vs "x"
w wipes and writes. a adds to the end. x creates a new file and fails if it already exists.
Why use with open(...) as f:?
The file closes automatically when the block ends, even after an error.
read() vs readlines() vs for line in f
read() gives one string. readlines() gives a list of lines. for line in f gives one line per round and saves memory.
CSV vs JSON vs pickle
CSV for tables, JSON for nested data you may share, pickle for saving your own Python objects.
Which file modes does pickle need?
Binary: "wb" to save and "rb" to load.
Module vs package vs library
Module: one .py file. Package: a folder of modules. Library: a collection for one purpose, like NumPy.
Three ways to import
import math, from math import sqrt, import numpy as np.
strftime vs strptime
strftime formats a date as text. strptime parses text into a date.
