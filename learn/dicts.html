Dictionaries

A dictionary stores data as key: value pairs, so you find things by name instead of by position. It is the shape of most real data: a customer record, a product, a row from a database.

What is a dictionary?

A dictionary (dict) is a collection of key: value pairs inside curly brackets. You look up a value by its key. It works like a real dictionary: you look up a word to find its meaning, or a name in your phone to find the number.

keys(), values(), items() and looping

Easy tip

keys(), values() and items() are live views. If you add a key later, a view you saved earlier shows it too. Wrap in list() if you need a fixed snapshot: list(person.keys()).

Predict the output

  1. {'a': 11, 'b': 2, 'c': 10}
  2. {'a': 10, 'b': 2, 'c': 10}
  3. KeyError: 'c'
  4. {'a': 11, 'b': 2}
Answer

{'a': 11, 'b': 2, 'c': 10}. get("a", 0) finds 1, so a becomes 11. get("c", 0) finds nothing and returns 0, so c becomes 10. This get(key, 0) + 1 trick is the heart of counting.

Nested dictionaries

Values can be dictionaries or lists themselves. This is how real records look, and it is exactly how JSON data from websites and APIs is shaped. Read nested data one bracket at a time.

Animated explainer: Following a path into nested data

  1. From your course notebook: a list of students. Each student is a dict, and marks is another dict, and maths is a list of two test scores.
  2. data[0]: data is a list, so use a position. Item 0 is Raman's dictionary.
  3. ["marks"]: that is a dict, so use a key. We get the marks dictionary.
  4. ["maths"]: another key. We get a list of two scores.
  5. [-1]: the last item of that list. The answer is 98. Each bracket goes one level deeper.

Why analysts care

Pattern 3 is exactly what a pivot table or SQL's GROUP BY does. In pandas it is one line: df.groupby("category")["amount"].sum(). Now you know what is happening underneath.

Why dictionaries are fast

To check 9999 in some_list, Python looks at every item one by one. To check 9999 in some_dict, Python uses the key's hash to jump straight to the right place, like using the index at the back of a book. With 10,000 items the PDF's timing test shows the dictionary is many times faster, and the gap grows with size.

Trap! Keys must be immutable

A list can change, so it cannot be a key. Use a tuple instead.

Key takeaways

  • A dict maps unique, immutable keys to values: {"name": "Raman"}.
  • d[k] raises KeyError when missing. d.get(k, default) is safe.
  • d[k] = v adds or updates. Remove with pop(), del or popitem().
  • Loop with for k, v in d.items():. in checks keys only.
  • Count with d[k] = d.get(k, 0) + 1. Group with lists as values. Nested data: one bracket per level.

Flashcards

What is a dictionary?
A collection of key: value pairs, like {"name": "Raman", "age": 16}. You look values up by key.
Rules for dictionary keys
Keys must be unique and immutable (str, int, tuple). Values can be anything.
d["x"] vs d.get("x")
d["x"] raises KeyError if x is missing. d.get("x") returns None (or your default).
How do you add or update a key?
d["key"] = value. Adds if new, updates if it exists.
Three ways to delete from a dict
d.pop(k) (returns the value), del d[k], d.popitem() (last pair). d.clear() empties it.
Best way to loop over a dict
What does in check on a dict?
Only the keys. Use x in d.values() to search values.
The counting pattern
How do you read nested data like data[0]["marks"]["maths"][-1]?
One bracket per level, left to right: list position, then key, then key, then list position.
Dict comprehension example
{x: x ** 2 for x in range(5)} gives {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
Why are dicts fast for lookups?
They use a hash to jump straight to the key, instead of checking items one by one like a list.
