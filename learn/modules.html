Module, package, library

A module is simply a .py file full of Python code (functions, variables, classes) that you can import and use. A package is a folder of related modules. A library is a collection of modules and packages for one purpose. People often use "module" and "library" loosely for the same thing, and that is fine.

math.ceil is perfect for "how many do I need" questions. 23 guests, 4 per table: math.ceil(23 / 4) is 6 tables. Plain division gives 5.75 and // gives 5, which leaves 3 guests standing.

random

Trap! randint includes the end

random.randint(1, 10) can return 10. But range(1, 10) stops at 9, and NumPy's np.random.randint(1, 10) also stops at 9. The standard-library randint is the odd one out.

Why analysts care

Analysts use random.seed() (and NumPy's version) so that a random sample or a train/test split is the same every time the notebook runs. Otherwise your numbers change on every run and nobody can check your work.

re: finding patterns in text

A regular expression (regex) is a mini-language for describing text patterns, like "one or more digits" or "something that looks like an email". The re module searches for them.

PatternMatches
\dOne digit 0 to 9
\wA letter, digit or underscore
\sA space, tab or new line
+One or more of the thing before it
*Zero or more
?Zero or one (optional)
[A-Z]One capital letter
[.,]A dot or a comma
^ / $Start / end of the text
{3}Exactly 3 of the thing before it
Easy tip

Always write regex patterns as raw strings with r"...", so backslashes like \d reach the regex engine untouched. Regex is a deep topic. Learn the patterns above and look up the rest when you need it.

Virtual environments, in one paragraph

Different projects can need different versions of the same library. A virtual environment is a private folder of libraries for one project. Create it with python -m venv myenv. Switch it on with myenv\Scripts\activate on Windows. Then pip install only affects that project. Colab and Anaconda handle this for you, so you can skip it while learning.

Key takeaways

  • A module is a .py file. A package is a folder of modules. A library is a collection for one purpose.
  • import math, import numpy as np, from math import sqrt. Avoid import *.
  • random.randint(a, b) includes b. Use random.seed() for repeatable results.
  • datetime: strftime formats a date as text, strptime parses text into a date, timedelta adds days.
  • Counter counts, statistics gives mean/median/stdev, re finds patterns.
  • Install with pip install name (or %pip install in a notebook).

Flashcards

Module vs package vs library
Module: one .py file. Package: a folder of modules. Library: a collection of modules/packages for one purpose.
Four ways to import
import math, import numpy as np, from math import sqrt, from math import * (avoid the last one).
math.floor vs math.ceil
floor rounds down (5.8 to 5). ceil rounds up (5.2 to 6).
Does random.randint(1, 10) include 10?
Yes. Both ends are included (unlike range and NumPy's randint).
Why use random.seed()?
To make random results repeatable, so your analysis gives the same numbers on every run.
strftime vs strptime
strftime formats a date into text. strptime parses text into a date.
How do you add 10 days to a date?
d + timedelta(days=10) (from datetime import timedelta).
How do you count items quickly?
Counter(items) from collections. .most_common(3) gives the top 3.
What does re.findall(r"\d+", text) return?
A list of every run of digits in the text, as strings.
What does if __name__ == "__main__": do?
Runs the code below it only when the file is run directly, not when it is imported.
How do you install a library?
pip install numpy in a terminal, or %pip install numpy in a notebook cell.
