Grouping, pivot tables and joining tables

Summarise and combine tables like an analyst. Group rows and summarise each group, add group results to every row, build pivot tables, put numbers into bands, join tables on a key and stack them, and measure how columns move together.

In this chapter you will learn

  • Summarise groups with groupby() and agg() (lists, dictionaries, named aggregation, your own functions)
  • Put group results on every row with transform() and assign()
  • Build Excel-style tables with pivot_table() and bands with pd.cut()
  • Join tables with merge() (inner, left, right, outer) and stack them with concat()
  • Measure relationships with corr() and summarise parts with describe()

groupby: split, apply, combine

"What is the average salary in each department?" is a groupby question. Pandas splits the rows into groups, applies a summary to each group, and combines the answers into one result. It is a Pivot Table in Excel, or GROUP BY in SQL.

Easy tip

The cells below do not repeat these lines, to keep them short. Try it copies them in for you, so every example still runs.

Animated explainer: Split, apply, combine

  1. Six staff from three departments. We want the average salary per department.
  2. Split: Pandas puts the rows into groups by dept: IT (rows 0, 2, 5), HR (row 1) and Sales (rows 3, 4).
  3. Apply: it works out mean() for each group separately.
  4. Combine: one row per group, with the group names as the index, sorted A to Z.

Predict the output

  1. [6, 5]
  2. [5, 6]
  3. [2, 5, 4]
  4. [11]
Answer

[6, 5]. Group a has 2 + 4 = 6 and group b has 5. The groups come out sorted, so a is first.

Think of it like this

Read emp.groupby("dept")["salary"].mean() as a sentence: "group the staff by department, take the salary, and find the mean".

agg: many summaries at once

agg() runs several summaries in one go. Give it a list for one column, or a dictionary to choose different summaries for different columns.

Named aggregation gives the result columns your own names: new_name=("column", "summary"). The course notebook uses it to build a clean report.

SummaryName in aggGives
Count of values"count"how many (not missing)
Total"sum"the sum
Average"mean" / "median"the mean / the middle value
Smallest / largest"min" / "max"the extremes
Spread"std"standard deviation
Different values"nunique"how many different ones
Your owna function or lambdaanything you can compute

transform and assign

agg() gives one row per group. transform() gives a value for every row: each person gets their own group's result. That is how you compare each row with its group.

Don't mix up: agg() vs transform()

groupby().agg("mean")groupby().transform("mean")
Rows in the resultOne per group (3)One per original row (8)
IndexThe group namesThe original index
Use it forA summary reportA new column that compares each row with its group

Rule of thumb: Want a short report? agg. Want to add a column to every row? transform.

assign() adds several new columns in one step and returns a new table. Each name=value becomes a column.

The top row in each group

groupby(...)[col].idxmax() gives the index label of the top row in each group. Loop over the result with .items() and look each label up with loc.

Pivot tables

pivot_table() builds an Excel-style pivot in one line: values = what to summarise, index = the rows, columns = the columns, aggfunc = how. fill_value=0 puts 0 in empty cells.

Easy tip

A pivot table is a groupby by two columns, laid out as a grid. emp.groupby(["dept", "city"])["salary"].mean() holds the same numbers, as one long column.

pd.cut: numbers into groups

pd.cut() puts numbers into ranges (bins), like age groups or price bands. Give it the edges and a label for each range. By default each range includes its right edge.

Easy tip

The column made by pd.cut is a category column. When you group by it, add observed=True, or Pandas prints a warning about empty groups.

Predict the output

  1. ['A', 'A', 'B']
  2. ['A', 'B', 'B']
  3. ['A', 'B', 'C']
  4. ['B', 'B', 'B']
Answer

['A', 'A', 'B']. Each range includes its right edge: 20 falls in (0, 20], so it is A.

merge: joining two tables

pd.merge(left, right, on="key", how=...) joins two tables side by side wherever the key matches: the same idea as SQL JOIN or Power Query's Merge Queries. how decides what happens to rows without a match.

Animated explainer: inner, left, right and outer joins

  1. Two tables share the column dept. Sales has no head; Finance has no staff.
  2. how="inner": only the departments in both tables. Ravi (Sales) and Finance are left out.
  3. how="left": every row of the left table. Ravi stays, with NaN for the head he does not have.
  4. how="right": every row of the right table. Finance stays, with no name.
  5. how="outer": everything from both, with NaN wherever there is no match.
how=KeepsLike SQL
"inner" (default)Only keys found in both tablesINNER JOIN
"left"Every row of the left tableLEFT JOIN
"right"Every row of the right tableRIGHT JOIN
"outer"Every row of both tablesFULL OUTER JOIN
Trap!

If the key is not unique in both tables, every match is paired with every other match, and the result can have far more rows than you expect. Check the row count after every merge.

concat: stacking tables

pd.concat([df1, df2]) puts tables on top of each other: the same columns, more rows, like SQL UNION ALL or Append Queries. Add ignore_index=True to number the rows 0, 1, 2 ... again.

Don't mix up: merge() vs concat()

pd.merge(a, b, on=...)pd.concat([a, b])
DirectionSide by side (more columns)On top (more rows)
Matches rows byA key columnNothing: it just stacks (axis=1 matches the index)
SQLJOINUNION ALL
Use it forAdding details from another tableJoining months or files with the same columns

Rule of thumb: New columns from another table? merge. More rows of the same kind? concat.

describe and corr

describe() summarises number columns (Chapter 23), and you can run it on a filtered or grouped part too. Correlation (corr()) measures how two number columns move together, from -1 to 1.

corrMeansExample
near 1They rise togetherSales and profit
near 0No straight-line linkAge and satisfaction
near -1One rises as the other fallsPrice and units sold
Trap!

Correlation is not cause. Ice-cream sales and sunburn rise together because of the sun, not because one causes the other.

Practice

  1. Print the total salary of each city in emp.

    Hint

    emp.groupby("city")["salary"].sum().

    Solution

    One row per city, sorted A to Z.

  2. For each department, print the number of staff and the average score, using named aggregation with the names staff and avg_score.

    Hint

    emp.groupby("dept").agg(staff=("name", "count"), avg_score=("score", "mean")).

    Solution

    Named aggregation gives the columns clear names straight away.

  3. Add a column best_in_dept with the highest score of each person's department (use transform). Print name, dept, score and best_in_dept for the first 4 rows.

    Hint

    emp.groupby("dept")["score"].transform("max").

    Solution

    transform keeps the original 8 rows, so the result fits as a new column.

  4. Join emp with heads so that every employee stays. Print the names of the staff whose department has no head.

    Hint

    pd.merge(emp, heads, on="dept", how="left"), then filter with isna().

    Solution

    A left join keeps every employee; NaN in head shows the ones with no match (Sales).

  5. Stack q1 = pd.DataFrame({"store": ["A", "B"], "sales": [100, 80]}) and q2 = pd.DataFrame({"store": ["A", "B"], "sales": [120, 95]}) with new row numbers, then print the total sales per store.

    Hint

    pd.concat([q1, q2], ignore_index=True), then groupby("store")["sales"].sum().

    Solution

    Stack first, then summarise: the most common way to combine monthly or quarterly files.

Practice with real data: sales by group

Back to sales_data.csv. These are the questions a manager asks every month.

  1. For each Category, print the total sales, the average profit (rounded to 0 decimals) and the number of orders, with the names total, avg_profit and orders.

    Hint

    Named aggregation, then .round(0) on the result.

    Solution

    Electronics brings the most money from fewer orders than Clothing.

  2. Make a pivot table of total Sales with Region down the side and Category across the top. Print it.

    Hint

    sales.pivot_table(values="Sales", index="Region", columns="Category", aggfunc="sum").

    Solution

    Each cell is the total for one region and one category.

  3. Print the total sales of each month, and the month with the most sales.

    Hint

    sales.groupby(sales["Date"].dt.to_period("M"))["Sales"].sum(), then .idxmax().

    Solution

    October and November are the festival season (Diwali), so sales jump.

  4. Put customers into age groups 18-30, 31-45 and 46-65 with pd.cut (edges 17, 30, 45, 65). Print the average satisfaction score of each group, rounded to 2 decimals.

    Hint

    pd.cut(sales["Customer_Age"], bins=[17, 30, 45, 65], labels=[...]), then groupby(..., observed=True).

    Solution

    The groups are very close: age does not change satisfaction much in this data.

  5. The company has targets: targets = pd.DataFrame({"Region": ["North", "South", "East", "West"], "Target": [400000, 450000, 300000, 380000]}). Merge the total sales per region with the targets and print each region's sales, target and a column Met (True or False).

    Hint

    Make actual = sales.groupby("Region")["Sales"].sum().reset_index(), merge on Region, then compare.

    Solution

    reset_index() turns the groups into a Region column, so merge can use it as the key.

Key takeaways

  • df.groupby("g")["v"].mean() splits, applies and combines: one answer per group, sorted by the group name.
  • agg() runs several summaries; named aggregation new=("col", "sum") gives clean column names.
  • transform() puts each group's answer on every row; assign() adds several columns at once.
  • pivot_table(values, index, columns, aggfunc, fill_value=0) makes a grid; pd.cut() turns numbers into bands.
  • merge(on=, how=) joins side by side (check unmatched rows with isna()); concat() stacks; corr() runs from -1 to 1.

    2. 8

    3. df.groupby("d").rename(total="sum")
    4. df.agg(total, staff)

    2. 2

    2. 3
    3. 4
    4. 2

    2. m[m["right_col"].isna()]
    3. m.duplicated()
    4. m.notna()

    m[m["right_col"].isna()]. Unmatched rows have NaN in the columns that came from the right table.

  7. What does pd.concat([a, b], ignore_index=True) do?

    1. Joins a and b side by side on a key
    2. Stacks b under a and numbers the rows 0, 1, 2 ... again
    3. Removes the index column
    4. Keeps only matching rows
    Answer

    Stacks b under a and numbers the rows 0, 1, 2 ... again. concat stacks; ignore_index=True renumbers the rows.

  8. What does this print?

    1. ['Low', 'High', 'High']
    2. ['Low', 'Low', 'High']
    3. ['High', 'High', 'High']

  9. A correlation of -0.9 between price and units sold means:

    1. No link
    2. When price goes up, units sold go down, strongly
    3. Price causes units sold
    4. Both go up together
    Answer

    When price goes up, units sold go down, strongly. Near -1: one rises as the other falls. Correlation still does not prove cause.

  10. What does fill_value=0 do in pivot_table()?

    1. Removes empty rows
    2. Puts 0 in cells with no data

    4. Starts the index at 0
