28.1 Big Test: Layouts & style

    Answer

  4. Basic. Make 1 row of 2 charts: a line of [4, 6, 5, 8] on the left and a bar chart of ["A", "B"] and [3, 5] on the right. Give each chart a title.
    Your code should print exactly:
    Answer

  5. Basic. Draw a line of [3, 5, 4, 6] with fig, ax = plt.subplots() and hide the top and right spines.

    Answer
    Each of the four border lines is a spine you can hide.

    Your code should print exactly:
