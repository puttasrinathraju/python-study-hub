Project 5.1 (Beginner): Clean a sales file

Read a messy CSV file, skip the bad rows without crashing, and save a clean copy.

Lakshmi runs a tiffin centre in Chennai. Her billing app exports each day's sales as a CSV file, but the cashier sometimes types junk: a word instead of a quantity, an empty price, a minus sign, or a row with a value missing.

Write a program that asks for the file name, reads it with the csv module, skips every bad row without crashing, prints a short summary, and saves the good rows to a new file, clean_sales.csv, with the revenue of each row.

What you will practise

  • Open and read a CSV file with csv.DictReader
  • Use try / except to skip bad rows instead of crashing
  • Handle a missing file with FileNotFoundError
  • Write a new CSV file with csv.writer

You may use: everything from Parts 1-4, open() and with, csv, try / except / else, raise.
Do not use yet: classes (Part 6), NumPy (Part 7).

Your tasks

  1. Ask Sales file: with input() and remove the spaces around the name.
  2. Open the file and read it with csv.DictReader. The columns are item,qty,price. (Blank lines are skipped by the reader and not counted.) If the file does not exist, print File not found: <name> and stop.
  3. For each row: clean the item name (strip() and title()), convert qty with int() and price with float(). A row is bad if the item is empty, a conversion fails, a value is missing, or qty or price is below 0. Count bad rows and skip them.
  4. Hint for missing values: a missing value is None, and int(None) raises TypeError, so catch (ValueError, TypeError).
  5. For good rows, work out revenue = qty × price, add up the units and the revenue, and add the revenue to that item's total (the same item can appear on several rows).
  6. Write clean_sales.csv with the header item,qty,revenue and one line per good row, revenue with 2 decimals (like Masala Dosa,15,1800.00).
  7. Print Rows read, Bad rows skipped, then Units sold, Revenue and Best seller (the item with the highest total revenue; the first one if tied). If there were no good rows, print No valid sales instead of those three lines.
  8. Finally print Saved clean_sales.csv.

Lines your output must contain

Rows read: <count>
Bad rows skipped: <count>
Units sold: <count>
Revenue: ₹<amount>
Best seller: <Item> (₹<amount>)
No valid sales
Saved clean_sales.csv
File not found: <name>
--- clean_sales.csv must contain ---
item,qty,revenue
<Item>,<qty>,<revenue with 2 decimals>

Money has ₹, commas and 2 decimals (:,.2f). In the clean file, the revenue has 2 decimals and no ₹ or commas. The checker reads clean_sales.csv after your program ends.

Edge cases to think about

  • A word instead of a number, an empty value, or a missing value at the end of a row.
  • A negative quantity or price: that row is bad too.
  • The same item on several rows: add them up for the best seller.
  • Item names in different capitals or with spaces.
  • A file name that does not exist.
  • A file with only the header: no sales, but still write the clean file with its header.

Project 5.2 (Intermediate): Hotel bookings report

Turn a messy bookings export into a clean management report.

A 3-star hotel exports its bookings from MakeMyTrip, Goibibo, Booking.com and walk-ins into one CSV file. The export is messy, like real data always is: statuses in different capitals (confirmed, CONFIRMED), channel names with spaces, room types in mixed case, amounts like ₹5,200 or empty, dates written two ways (2026-08-26 and 19/08/2026), and a few rows with no nights at all.

The manager wants a one-screen report: bookings by status, confirmed revenue, average stay, revenue per room type, the best channel and the busiest month. The course file hotel_bookings.csv is ready in the Python runner, and the tests also use smaller files.

What you will practise

  • Clean every column before using it
  • Parse dates in two formats with try / except
  • Fill in a missing value from other columns
  • Group, count and rank with dictionaries

You may use: everything from Parts 1-4, csv, datetime, try / except, collections, statistics.
Do not use yet: classes (Part 6), NumPy (Part 7).

Your tasks

  1. Ask Bookings file: , strip the name, and read the file with csv.DictReader. If it does not exist, print File not found: <name> and stop.
  2. Clean each row: status and room_type with strip().title() (so No-show becomes No-Show), channel with strip().lower(), and amount without ₹, commas and spaces.
  3. A row is skipped if nights is not a whole number, or check_in is neither %Y-%m-%d nor %d/%m/%Y. If the amount is empty, use nights × rate. If the amount is still not a whole number, skip the row.
  4. Print Bookings (good rows) and Skipped rows. If there are no good rows, print No bookings and stop.
  5. Print Status: Confirmed <n>, Cancelled <n>, No-Show <n> (always all three).
  6. For confirmed bookings only: print Confirmed revenue, Average stay (2 decimals), one line per room type ranked by revenue (1. Deluxe: ₹78,400 (12 bookings), ties A to Z), and Top channel (most revenue; ties A to Z). If there are no confirmed bookings, print No confirmed bookings instead.
  7. For all good rows, print the busiest check-in month: Busiest month: September 2026 (19 bookings) (ties: the earlier month). Use strftime("%B %Y").
  8. Keep it tidy: a small function to parse dates and one to clean amounts are a good idea.

Lines your output must contain

Bookings: <count>
Skipped rows: <count>
Status: Confirmed <n>, Cancelled <n>, No-Show <n>
Confirmed revenue: ₹<amount>
Average stay: <number> nights
<rank>. <Room type>: ₹<amount> (<n> bookings)
Top channel: <channel> (₹<amount>)
Busiest month: <Month Year> (<n> bookings)
No bookings
No confirmed bookings
File not found: <name>

Amounts are whole rupees with commas (:,). The average stay has 2 decimals. Channel names are printed in small letters. Always write bookings (plural).

  • Two date formats, and a date that is neither: skip that row.
  • An empty amount: use nights × rate.

Project 5.3 (Challenging): Monthly budget report

Combine a JSON budget and a CSV of expenses into a monthly report file.

A small business tracks its expenses in a CSV file and keeps its monthly budget per category in a JSON file. At the end of each month, the accountant wants a report: how much was spent per category against the budget, which categories went over budget, and the biggest single expense. The report must also be saved as a text file to email.

The data has the usual problems: amounts that are words or negative, dates in the wrong format, categories in different capitals, and categories that have no budget (they go under Other).

What you will practise

  • Read a JSON file and a CSV file and combine them
  • Validate input with datetime.strptime and try / except
  • Filter rows to one month and group by category
  • Write a report file and print it

You may use: everything from Parts 1-4, json, csv, datetime, try / except / else / finally, raise, re, collections.
Do not use yet: classes (Part 6), NumPy (Part 7).

Your tasks

  1. Ask Month (YYYY-MM): , strip it, and check it with datetime.strptime(text, "%Y-%m") (it must also be exactly 7 characters). If it is not valid, print Invalid month: <text> and stop.
  2. Load budget.json (a dictionary like {"Food": 6000, "Travel": 4000}) and read expenses.csv (date,category,amount,note) with csv.DictReader. If a file is missing, print Missing file: <name> (check budget.json first) and stop.
  3. A row is bad if its date is not %Y-%m-%d, its amount is not a number or is 0 or less, or its category is empty. Count the bad rows in the whole file.
  4. Keep the good rows of the chosen month only. Clean the category with strip().title(); if it is not in the budget, it becomes Other.
  5. Build the report lines: Month: October 2026; then, if there are expenses, Expenses: <n> (bad rows: <n>) and Total spent: ₹<amount>; one line per budget category in the JSON order: Food: ₹4,230.50 of ₹6,000.00 (70.5%), adding OVER when spent is more than the budget; Other: ₹2,150.00 (no budget) if needed; Over budget: Travel (or none); and Biggest expense: ₹3,200.00 on 05 Oct (Travel) (the first one if tied).
  6. If the month has no expenses, the report is Month: ... and No expenses in October 2026.
  7. Print the report lines, write the same lines to report_<month>.txt (like report_2026-10.txt), and finally print Saved report_<month>.txt.
  8. Use functions for the separate jobs (loading, validating, building the report) and handle every error without crashing.

Lines your output must contain

Month: <Month Year>
Expenses: <n> (bad rows: <n>)
Total spent: ₹<amount>
<Category>: ₹<spent> of ₹<budget> (<percent>%)  (+ " OVER")
Other: ₹<amount> (no budget)
Over budget: <categories> or none
Biggest expense: ₹<amount> on <dd Mon> (<Category>)
No expenses in <Month Year>
Saved report_<YYYY-MM>.txt
Invalid month: <text>
Missing file: <name>
--- the report file must contain the report lines ---

Money has ₹, commas and 2 decimals. Percent = spent ÷ budget × 100 with 1 decimal. Dates in the biggest-expense line use strftime("%d %b"). The report file holds the same lines as the printed report (from Month: to the end, without the Saved line).
