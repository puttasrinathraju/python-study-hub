Part 7 overview: NumPy

All three NumPy chapters on one page: making arrays, describing them, doing maths on them, splitting and searching them, simulating data, and the classic mix-ups (axis, views and copies, and vs &).

The whole Part in 5 lines

  1. NumPy's array is like a list built for maths: one data type, a fixed size, and maths on every value at once. Start with import numpy as np.
  2. Describe any array with shape (rows, columns), ndim, size and dtype. Simulate realistic data with np.random, and set a seed to repeat the results.
  3. Make arrays with np.array, zeros, ones, full, arange (stop excluded) and linspace (stop included). Change the layout with reshape and cut arrays up with array_split.
  4. axis=0 works down the rows and gives one result per column. axis=1 works across and gives one result per row.
  5. Filter with boolean masks: a[a > 50], combined with &, | and ~, each condition in brackets. Slices are views, so use .copy() for a separate array.

Key definitions

NumPy

Python's library for fast maths on large sets of numbers. pandas is built on top of it.

Array (ndarray)

NumPy's container: a grid of values that all share one type. It prints without commas.

Dimension (ndim)

How many directions the array has: 1D is a row, 2D is a table, 3D is a stack of tables.

shape

The size in each direction, as a tuple. For a table it is (rows, columns).

size

The total number of values in the array: rows × columns.

dtype

The one data type every value shares, such as float64. Whole numbers usually show as int64 in Jupyter (older NumPy on Windows shows int32), and as int32 in this browser runner. Both are fine.

Upcasting

When you mix types, NumPy converts everything to the type that can hold them all. One string makes the whole array text.

reshape

Gives the same values a new shape. The total count must stay the same. -1 means "work it out".

Vectorisation

Maths on the whole array at once, with no loop. It is short to write and very fast.

Broadcasting

NumPy stretches a single number, a row or a column to match a bigger array.

axis

The direction a calculation runs in. axis=0 goes down the rows, axis=1 goes across the columns.

Boolean mask

An array of True/False made by a condition. Put it in square brackets to keep only the True values.

View

A slice that shares memory with the original array. Changing the view changes the original.

Copy

A separate array with its own memory, made with .copy().

np.where

Picks a value from two options for every element, based on a condition.

argmax

The position of the largest value. argmin gives the position of the smallest.

ufunc

A universal function: a NumPy function that works on every value of an array at once, in fast compiled code. a + b is really np.add(a, b).

Random seed

A starting number for the random generator. The same seed gives the same "random" numbers every run, so anyone can repeat your results.

Distribution

The pattern of which values are likely and which are rare. Normal is a bell curve around the average. Poisson counts events in a time window.

Try it yourself

NumPy takes a few seconds to load the first time you press Run. After that it is instant. Every comparison table above also has an Edit and run this example button.

  1. prices = np.array([120, 450, 80, 300]). Apply a 10% discount to every price with one line, no loop, and print the result.

    Hint

    Multiply the whole array by 0.9.

    Solution

    Vectorisation: the maths runs on every value at once, and the result is floats because of 0.9.

  2. marks has 3 students (rows) and 3 subjects (columns). Print each student's average, then the top mark in each subject.

    Hint

    Student averages go across a row: axis=1. Subject tops go down a column: axis=0.

    Solution

    axis=1 squashes the columns (one value per student). axis=0 squashes the rows (one value per subject).

  3. temps = np.array([28, 33, 31, 25, 35, 29, 32]). Print how many days were above 30, then those temperatures.

    Hint

    Make the mask temps > 30. np.sum(mask) counts the True values, and temps[mask] keeps them.

    Solution

    True counts as 1, so summing a mask counts the matches.

  4. Make the numbers 1 to 12 with np.arange, reshape them into 3 rows and 4 columns, and print the second column.

    Hint

    np.arange(1, 13) (13 is excluded), then .reshape(3, 4), then [:, 1].

    Solution

    : takes every row and 1 picks the second column, because counting starts at 0.

  5. rates = np.array([1800, 2600, 4800, 2600, 1800]). Give every rate a band number with np.searchsorted([2000, 3000], rates, side="right"): 0 is under 2000, 1 is 2000 to 2999, 2 is 3000 and up. Print the bands, then how many rates are in each band as a list.

    Hint

    After making bands, count each band with int(np.sum(bands == i)) for i in range(3).

    Solution

    searchsorted turns each value into a band number in one step, with no if/elif chain.

    3. [2, 4, 6]

    2. np.linspace(0, 1, 5)

    4. Neither

    2. [4 6]
    3. 10
    4. [1 2 3 4]

    2. [4 6]
    3. 10
    4. [2 4]

    2. [5 25]

    4. An error
    Answer

    3. It returns an empty array
    4. It returns True

    A ValueError: the truth value of an array is ambiguous. and needs one True/False. On arrays use & and put each condition in brackets.

    4. An error

    4. An error

Flashcards

List vs NumPy array
A list holds mixed types and * 2 repeats it. An array holds one type and * 2 doubles every value. Arrays are much faster for maths.
shape, ndim, size, dtype
shape: size in each direction. ndim: number of dimensions. size: total values. dtype: the data type.
arange vs linspace
arange(start, stop, step) excludes stop. linspace(start, stop, n) includes stop and gives exactly n values.
axis=0 vs axis=1
axis=0 goes down the rows, one result per column. axis=1 goes across, one result per row.
What is broadcasting?
NumPy stretches a number, row or column to match a bigger array, so m + 10 adds 10 to every value.
How do you filter an array?
Put a condition in square brackets.
Combine two conditions on an array
Use & (and), | (or), ~ (not), with brackets around each condition.
View vs copy
A slice is a view that shares memory with the original. .copy() makes a separate array.
max() vs argmax()
max() gives the largest value. argmax() gives its position.
What does reshape(3, -1) mean?
3 rows, and NumPy works out the number of columns.
Mask vs np.where
A mask keeps only the matching values. np.where(cond, x, y) keeps the length and replaces each value.
What happens when you mix types in an array?
Upcasting: everything becomes the type that can hold all of them. One string makes every value a string.
array_split vs split
array_split allows unequal parts (the first ones get the extras). split needs equal parts or raises ValueError.
np.where(cond) vs np.where(cond, x, y)
One argument gives the positions where cond is True. Three arguments give a new array with x or y in every place.
Normal vs Binomial vs Poisson
Normal: a bell curve of measurements. Binomial: successes out of n tries. Poisson: event counts per time window.
What is a ufunc?
A NumPy function that works on every value of an array at once, like np.add, np.around or np.cumsum.
