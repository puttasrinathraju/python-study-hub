The operator families

An operator is a symbol that does something with values. In 10 + 5, the + is the operator and 10 and 5 are the operands. Python groups its operators into 7 families.

Floor division and remainder, explained with sweets

You have 11 sweets and 3 friends. Each friend gets the same number of whole sweets. 11 // 3 tells you how many each friend gets (3). 11 % 3 tells you how many are left over (2).

Diagram: // is how many whole groups. % is what is left over.

% is surprisingly useful. Here are three everyday uses.

Trap! Floor division rounds DOWN, not towards zero

With negative numbers, // goes to the next lower whole number. So -7 // 2 is -4, not -3. And % follows the same rule, so -7 % 3 is 2. If you just want to chop off the decimals, use int(-7 / 2).

Answer

Order of operations (precedence)

When an expression has several operators, Python follows a fixed order, like BODMAS or PEMDAS in school maths. Brackets first, then powers, then multiply and divide, then add and subtract. Operators of the same level run left to right.

Animated explainer: Working out 2 + 3 * 4 ** 2 // 5

  1. Python does not go left to right here. It looks for the operator with the highest priority first.
  2. Powers ** come first. 4 ** 2 is 16.
  3. Next level: *, /, // and %. They are equal, so Python goes left to right. The * comes first.
  4. Then //. 48 // 5 is 9 (5 goes into 48 nine whole times).
  5. Addition comes last. The answer is 11.
  6. Brackets change everything. When in doubt, add brackets. They make your code easier to read too.

Slides: The precedence ladder

  1. Highest priority runs first.

    Read this ladder from the top. When two operators are on the same rung, Python goes left to right. Two exceptions: ** goes right to left, and comparisons chain (1 < x < 10 means 1 < x and x < 10).

  2. Rung 1: Brackets ( )

    Anything in brackets is worked out first.

  3. Rung 2: Power **

    Powers beat a minus sign in front. So -2 ** 2 is -(2 ** 2).

  4. Rung 3: * / // %

    Same rung, so left to right.

  5. Rung 4: + -

  6. Rung 5: comparisons

    == != > < >= <= in is come after all the maths.

  7. Rung 6 to 8: not, then and, then or

    not is applied first, then and, then or.

Comparison operators

Comparisons ask a question and always answer with True or False.

Trap! = vs ==

if x = 5: is a SyntaxError. One = stores a value. Two == compare. Read == aloud as "is equal to".

Logical operators: and, or, not

and needs both. or needs at least one. not flips.

Short-circuit: Python stops early

With and, if the left side is False, the answer is already False, so Python skips the right side. With or, if the left side is True, it skips the right side. You can use this to avoid errors.

These are shortcuts. x += 5 means x = x + 5.

Membership operators: in, not in

in checks whether a value is inside a list, string, tuple, set or dictionary. For a dictionary, in checks the keys, not the values.

Identity operators: is, is not

== asks: do these have the same value? is asks: are these the very same object in memory? Two lists can look identical but be two separate objects.

Diagram: a and c point at the same list. b is a separate list that happens to hold the same values.

Think of it like this

Two people both have a red Activa scooter. == asks "are the scooters the same model and colour?" (yes). is asks "is it the same scooter?" (no, there are two).

Trap! Do not use is to compare numbers or text

Python secretly reuses small numbers (from -5 to 256), so two variables holding 5 are always the same object, but two variables holding 1000 may not be. Results depend on how the code runs. Use == for values. Use is only for None: write if result is None:.

Bitwise operators (just know they exist)

These work on the binary digits of whole numbers. You will rarely use them on plain numbers. But &, | and ~ come back in NumPy and pandas. There they mean and, or and not for whole columns. Wrap each condition in brackets: (a > 1) & (b < 5).

Key takeaways

  • / always gives a float. // gives whole groups. % gives the remainder.
  • // rounds down, so -7 // 2 is -4.
  • Order: brackets, **, * / // %, + -, comparisons, not, and, or. Add brackets when unsure.
  • and needs both True, or needs one, not flips. Python stops early (short-circuit).
  • == compares values. is checks if it is the same object. Use is only with None.

Flashcards

Difference between / and //
/ is true division and always gives a float (7 / 2 = 3.5). // is floor division and gives the whole part (7 // 2 = 3).
What does % give?
The remainder after division. 11 % 3 = 2. Use n % 2 == 0 to test for even numbers.
What is -7 // 2?
-4. Floor division always rounds down, to the lower number.
How do you write a power or a square root?
Power: 2 ** 3 = 8. Square root: 25 ** 0.5 = 5.0.
Order of operations in Python
Brackets, **, then * / // %, then + -, then comparisons, then not, and, or.
What does and return True for?
Only when both sides are True.
What does or return True for?
When at least one side is True.
What does x += 3 mean?
x = x + 3. Add 3 to x and store the result back in x.
== vs is
== checks if values are equal. is checks if both names point at the same object in memory.
What does in do?
Checks membership: "a" in "data" is True, 5 in [1, 2, 3] is False.
