1.1 Big Test: Meet Python

25 questions on Meet Python only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    Price
300
250 + 50

    Text inside quotes prints exactly as written. Without quotes, Python does the maths first and prints the answer.

  2. Basic. Print Welcome to Python on one line and Day 1 of my data journey on the next line.

    Your code should print exactly:

    Welcome to Python
Day 1 of my data journey
    Answer

    Each print() starts a new line. Text goes inside quotes.

  3. Basic. A shop sold 48 pens in the morning and 37 pens in the evening. Print the total. Let Python do the maths.

    Your code should print exactly:

    85
    Answer

    Put the maths inside print() with no quotes, and Python works out 85 for you.

  4. Basic. A cinema hall has 18 rows with 24 seats in each row. Print the total number of seats.

    Your code should print exactly:

    432
    Answer

    In Python, multiply uses *. Python works out 18 * 24 and prints 432.

  5. Basic. This code should print Good morning, but it crashes. Fix it.

    It should print:

    Good morning
    Answer

    Python is case-sensitive. The function is print in small letters. Print is a different name that does not exist, so you get a NameError.

  6. Basic. This code should print Hyderabad, but it crashes. Fix it.

    It should print:

    Hyderabad
    Answer

    Quotes must match. The text starts with ", so it must also end with ". Mixed quotes give a SyntaxError.

  7. Basic. This code prints three lines. Turn the middle line into a comment, so only the first and the last lines print.

    Your code should print exactly:

    Step 1: open the file
Step 3: save the report
    Answer

    Put # at the start of a line and Python skips it. This is a handy way to switch a line off without deleting it.

  8. Basic. Type exactly what this code prints.

    Answer
    Guntur Vizag

    Single quotes and double quotes both make text, and the quotes themselves are not printed. The comma puts one space between the two values.

  9. Medium. Type exactly what this code prints.

    Answer
    B
D

    Python ignores everything after # on a line, even if it looks like code. Only B and D are printed.

  10. Medium. A shop sold 45 boxes with 12 bottles in each box. Use ONE print() with a comma to print Units sold: 540. Let Python work out the 540.

    Your code should print exactly:

    Units sold: 540
    Answer

    A comma inside print() separates two values and puts one space between them: the text, then the answer of the maths.

  11. Medium. Type exactly what this code prints.

    Answer
    Pune 29
Pune 32

    Python runs from top to bottom. Line 4 works out 29 + 3 first, then stores 32 back in temp. The old value is gone.

  12. Medium. Print this line exactly: Total: 3 x 40 = 120. Python must work out the 120. The rest is text.

    Your code should print exactly:

    Total: 3 x 40 = 120
    Answer

    Everything up to = is text, so it goes in quotes. The answer is maths, so it goes after a comma without quotes.

  13. Medium. A train left with 640 passengers. At the first stop 85 got off and 120 got on. Print the number of passengers now, in one line of maths.

    Your code should print exactly:

    675
    Answer

    640 - 85 + 120 is worked out from left to right: 555, then 675.

  14. Medium. The second line prints the wrong bill: 4 coffees at 25 rupees each. Switch that line off with a comment, then add a new line under it that prints the right bill.

    Your code should print exactly:

    Bill for 4 coffees
100
    Answer

    # switches off the wrong line but keeps it for reference. The new line uses * to multiply: 4 times 25 is 100.

  15. Medium. The steps print in the wrong order. Move the lines so the output goes 1. Boil water, 2. Add tea leaves, 3. Serve hot.

    Your code should print exactly:

    1. Boil water
2. Add tea leaves
3. Serve hot
    Answer

    Python always runs lines from top to bottom, so the order of the lines is the order of the output.

  16. Medium. This code should print Pass, but it stops with an IndentationError. Fix it.

    It should print:

    Pass
    Answer

    A line that ends with a colon : starts a block. The line inside the block must be pushed right by 4 spaces.

  17. Medium. This code should print Total: 500, but it stops with a TypeError. Fix it.

    It should print:

    Total: 500
    Answer

    + cannot join text and a number: that is the TypeError. A comma inside print() shows both values, with a space between them.

  18. Medium. A tea stall sold 12 cups on Monday, 15 on Tuesday and 9 on Wednesday, at 40 rupees a cup. Use ONE print() to show the sales of each day: 480 600 360.

    Your code should print exactly:

    480 600 360
    Answer

    One print() can show many values. Python works out each maths part, and the commas put a space between the answers.

  19. Challenge. Print this bill exactly, one line each. Python must work out every number after =:
    Tea x 2 = 30 (15 rupees each)
    Samosa x 3 = 36 (12 rupees each)
    Total = 66 (add the two answers).

    Your code should print exactly:

    Tea x 2 = 30
Samosa x 3 = 36
Total = 66
    Answer

    Each line is text, a comma, then the maths. The text holds the x and = signs, and Python works out the numbers.

  20. Challenge. Start with cash = 2000 and print Cash: 2000. A customer pays 350: add it to cash and print Cash: 2350. Then you pay 500 rent: take it from cash and print Cash: 1850.

    Your code should print exactly:

    Cash: 2000
Cash: 2350
Cash: 1850
    Answer

    cash = cash + 350 works out the right side first, then stores the answer back in cash. Each print() shows the value at that moment.

  21. Challenge. This code has three mistakes: a note that is not a comment, a missing colon, and a capital letter. It should print Report, then Done. Fix it.

    It should print:

    Report
Done
    Answer

    A note needs # in front. A line that starts a block needs : at the end. And print is always written in small letters.

  22. Challenge. Type exactly what this code prints.

    Answer
    Room #12

    A # inside quotes is just text, so Room #12 prints in full. The # after the closing bracket starts a comment, and the last line is all comment.

  23. Challenge. This program prints the steps in the wrong order and has a debug line that should not print. Put the steps in order and switch off the debug line with a comment. The output must be Step 1: load data, Step 2: clean data, Step 3: make chart.

    Your code should print exactly:

    Step 1: load data
Step 2: clean data
Step 3: make chart
    Answer

    Python runs lines from top to bottom, so move the lines into the right order. A # in front of the debug line keeps it in the file but stops it from running.

  24. Challenge. Each of these lines has a mistake:
    1. print("Hi)
    2. prnt("Hi")
    3. print("Age: " + 25)
    Print the name of the error each one gives, one per line, in this order. (Try running each line to read its last error line.)

    Your code should print exactly:

    SyntaxError
NameError
TypeError
    Answer

    A missing quote is a grammar mistake: SyntaxError. A misspelt name is unknown to Python: NameError. Text + number is a TypeError.

  25. Challenge. Python is case-sensitive, so total, Total and TOTAL are three different names. Store 100 in total, 200 in Total and 300 in TOTAL. Then print all three with one print() in this order: TOTAL, total, Total.

    Your code should print exactly:

    300 100 200
    Answer

    Because capitals matter, the three names hold three separate values. The output is 300 100 200.
