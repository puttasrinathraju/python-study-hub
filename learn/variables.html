What is a variable?

A variable is a name that points to a value stored in the computer's memory. You create one by writing a name, an equals sign, and a value.

Diagram: Each variable is a name tag. It points at a value stored in memory.

Think of it like this

Think of a variable as a name tag stuck on a box. The box holds the value. When you write age = 17 later, you move the tag to a new box with 17 in it.

= does not mean equals

In maths, = means "is equal to". In Python, = means store the value on the right in the name on the left. To check if two things are equal, Python uses == (two equals signs). You will see this in the Operators chapter.

Rules for naming variables

Your course gave three simple rules: no spaces, never start with a number, and don't use reserved words. Here is the full list.

RuleGoodBad
Use letters, numbers and underscore _ onlyticket_priceticket-price, ticket price
Must start with a letter or _num1, _temp1num, 2nd_place
Cannot be a Python keywordclass_nameclass, if, for, while
Case-sensitivename and Name are two different variables

Keywords are words Python has reserved for itself: False None True and as assert async await break class continue def del elif else except finally for from global if import in is lambda nonlocal not or pass raise return try while with yield. You cannot use them as names.

Naming style

Python programmers usually write snake_case: small letters with underscores, like ticket_price or total_sales. Your course notebooks also use camelCase like ticketPrice. Both work. Pick one and stay consistent. Most important: choose names that say what the value is. total_sales beats ts or x.

Assigning many values at once

Easy tip

The swap trick p, q = q, p is a Python favourite. In many other languages you need a third temporary variable to swap two values.

The basic data types

Every value has a type. The type decides what you can do with it. You can add two numbers, but you cannot divide a name by 2.

Use type() to ask Python what type a value is.

isinstance() answers a yes or no question: is this value of this type?

Trap!

"25" with quotes is text, not a number. It looks like a number, but Python treats it like the word "twenty-five". This is the most common beginner bug, and it usually comes from input() or from reading a file.

Numbers: int and float

Trap! Decimals are not exact

Computers store decimals in binary, so some simple decimals cannot be stored exactly. Never compare money with ==. Round first.

Trap! round() rounds half to even

Python's round() sends an exact .5 to the nearest even number. This is called banker's rounding. It surprises everyone the first time.

Booleans and None

A boolean is either True or False, always with a capital first letter. Comparisons give you booleans. None means no value at all. It is often used as a starting value before you know the real one.

Dynamic typing

Python is dynamically typed. You never declare a type. Python looks at the value and works it out. The same name can even hold a different type later.

Animated explainer: Variables move, values stay

  1. Python creates the value 5 and points the name x at it.
  2. y = x means: point y at the value x has right now. Both are 5.
  3. Now x points at a new value, 10. Look: y did not change. It still holds 5.
  4. So the output is 10 5. Changing one variable never changes another number variable.
  5. x now holds text. Its type changed from int to str. Python allows this. That is dynamic typing.
  6. type(x) confirms it is now a string.

input() always gives you text

input() pauses the program, shows a message, and waits for the user to type something. Whatever the user types comes back as a string, even if they type a number. This example is from your course notebook.

Trap! Text times a number repeats the text

If you forget to convert, Python does not crash. It quietly does something else. Multiplying text by a number repeats the text.

Key takeaways

  • A variable is a name pointing at a value. = stores, == compares.
  • Names: letters, digits and _, no spaces, cannot start with a digit, no keywords, case matters.
  • Main types: int, float, str, bool, None. Check with type().
  • input() always returns a str. Convert with int() or float() before doing maths.
  • int() cuts decimals off. round() rounds .5 to the nearest even number. Decimals like 0.1 are not exact.

Flashcards

What is a variable?
A name that points to a value in memory. Created with name = value.
What is the difference between = and ==?
= stores a value in a variable. == compares two values and gives True or False.
Three naming rules for variables
No spaces, cannot start with a digit, cannot be a keyword like if or class. Names are case-sensitive.
Name the 5 basic data types
int (whole number), float (decimal), str (text), bool (True/False), None (no value).
How do you check a value's type?
type(value), for example type(5) gives <class 'int'>. Or isinstance(value, int) for a True/False answer.
What does input() return?
Always a string, even if the user types a number. Convert with int() or float().
What is "500" * 3?
"500500500". Text times a number repeats the text.
What does int(3.99) give?
3. int() cuts off the decimal. It does not round.
Why is 0.1 + 0.2 not exactly 0.3?
Decimals are stored in binary and some cannot be stored exactly. Use round() before comparing.
How do you swap two variables in Python?
a, b = b, a
