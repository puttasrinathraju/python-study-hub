Part 6 · Object-oriented Python · Overview

Part 6 overview: classes and objects

Object-oriented programming on one page: every word you need, how the parts of a class fit together, the four pillars, and the pairs that trip people up.

The whole Part in 5 lines

  1. A class is a blueprint. An object (or instance) is one thing built from it: s = Student("Asha", 82).
  2. __init__ runs when an object is created and sets up its attributes. self is the object itself and is the first parameter of every method.
  3. Attributes are an object's data (s.name). Methods are its actions (s.report()). Instance attributes belong to one object, class attributes are shared by all.
  4. Magic methods such as __str__, __eq__ and __len__ let your objects work with print(), == and len().
  5. The four pillars: encapsulation (protect the data), inheritance (class Child(Parent):), polymorphism (same method name, different behaviour) and abstraction (hide the details).

Key definitions

Object-oriented programming

A way of organising code around objects that bundle data and the actions on that data together.

Class

A blueprint that describes what data each object has and what it can do.

Object (instance)

One thing made from a class. Each object is separate, even when made from the same class.

__init__ (constructor)

A special method that runs automatically every time a new object is created. It sets up the attributes.

self

The object a method is working on. Python passes it in for you, so it is always the first parameter.

Attribute

A piece of data stored on an object, read with a dot and no brackets: s.name.

Method

A function defined inside a class. Call it on an object with brackets: s.report().

Instance attribute

Data that belongs to one object, set with self.x = …. Every object has its own copy.

Class attribute

Data written directly in the class body. It is shared by every object of that class.

Magic (dunder) method

A method with double underscores, like __str__. Python calls it for you when you use print(), ==, len() or +.

Inheritance

A child class gets everything from a parent class and can add or change parts: class Child(Parent):.

super()

Calls the parent class's version of a method, most often super().__init__(...) inside the child's __init__.

Method overriding

A child class writes its own version of a method that the parent already has. The child's version wins.

Polymorphism

Different classes share a method name, so one piece of code can work with all of them.

Encapsulation

Keeping data inside the object and changing it only through methods that check the rules. __name hides an attribute.

Abstraction

Hiding complicated details behind simple methods. You call df.groupby() without knowing the code inside it.

@property

Turns a method into something you read like an attribute, with no brackets.

Try it yourself

Build each class step by step and test it with a print(). Every comparison table above also has an Edit and run this example button.

  1. Write a Rectangle class that stores w and h and has an area() method. print(Rectangle(4, 5).area()) should print 20.

    Hint

    __init__(self, w, h) stores self.w and self.h. area(self) returns self.w * self.h.

    Solution

    __init__ saves the data on the object, and the method reads it back through self.

  2. Write BankAccount(owner, balance) with deposit(amount), withdraw(amount) (print Not enough money if it is too much) and a __str__ that shows Asha: ₹1500. Then deposit 500, try to withdraw 2000, and print the account.

    Hint

    In withdraw, check if amount > self.balance: before subtracting. __str__ must return a string.

    Solution

    This is encapsulation: the balance only changes through methods that check the rules.

  3. Make a Shape parent with area() returning 0, then Circle(r) and Square(s) children that override it. Print [round(s.area(), 2) for s in [Circle(1), Square(3)]] to get [3.14, 9].

    Hint

    Each child stores its own size in __init__ and has its own area(). Use 3.14159 for pi.

    Solution

    Inheritance gives both a shared parent, and polymorphism lets one comprehension call area() on each without checking its type.

  4. Give Student a class attribute count = 0 that goes up by 1 every time a student is created. Create three students and print 3.

    Hint

    Inside __init__, write Student.count += 1 (not self.count).

    Solution

    A class attribute is shared, so every new object adds to the same counter. self.count += 1 would create a separate instance attribute instead.

Flashcards

Class vs object
A class is the blueprint. An object is one thing built from it: s = Student("Asha", 82).
What does __init__ do?
It runs automatically when an object is created and sets up the object's attributes.
What is self?
The object the method is working on. It is always the first parameter of a method.
Attribute vs method
An attribute is data, read without brackets (s.name). A method is an action, called with brackets (s.report()).
Instance vs class attribute
Instance attributes (self.x) belong to one object. Class attributes are written in the class body and shared by all objects.
__str__ vs __repr__
__str__ is the friendly text for print(). __repr__ is the precise text for lists and the notebook.
How do you inherit from a class?
Put the parent in brackets and call its __init__ with super().
What is method overriding?
A child class defines a method with the same name as the parent's. The child's version runs.
The four pillars of OOP
Encapsulation, inheritance, polymorphism, abstraction.
Encapsulation in Python
Hide data with __name and change it only through methods or a @property that checks the rules.
@classmethod vs @staticmethod
A class method gets cls and often builds objects. A static method gets neither self nor cls; it is a helper.
What does @property do?
Lets you read a method like an attribute, without brackets: circle.area.
