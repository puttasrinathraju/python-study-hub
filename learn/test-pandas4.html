26.1 Big Test: Group & join

25 questions on Grouping, pivot tables and joining tables only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Print the total amount of each store.

    Your code should print exactly:

    store
Delhi    650
Goa      460
Pune     690
Name: amount, dtype: int64
    Answer

    Split by store, take the amount, add it up: one row per store, sorted A to Z.

  2. Basic. Print how many orders there are for each item, using size().

    Your code should print exactly:

    item
Coffee    2
Tea       5
dtype: int64
    Answer

    size() counts the rows in each group.

  3. Basic. Type exactly what this code prints.

    Answer
    [9, 7]

    Group a has 9; group b has 4 and 7, so its max is 7. Groups are sorted: a first.

  4. Basic. For each store, print the mean and the max amount in one table, using agg with a list.

    Your code should print exactly:

            mean  max
store            
Delhi  325.0  600
Goa    230.0  260
Pune   230.0  300
    Answer

    A list in agg gives one column per summary.

  5. Basic. This code should stack the two weeks into one table of 4 rows and print 4, but it stops with a TypeError. Fix it.

    It should print:

    4
    Answer

    pd.concat takes one list of tables: pd.concat([w1, w2]).

  6. Basic. Join orders with managers so that only stores found in both tables stay. Print the store, item and manager columns.

    Your code should print exactly:

       store    item manager
0   Pune     Tea    Asha
1  Delhi  Coffee    Ravi
2   Pune  Coffee    Asha
3  Delhi     Tea    Ravi
4   Pune     Tea    Asha
    Answer

    An inner join keeps only matching keys, so the Goa orders disappear.

  7. Basic. Type exactly what this code prints.

    Answer
    ['Low', 'Mid', 'High']

    Each value goes into the range it falls in: (0, 30], (30, 60] and (60, 100].

  8. Basic. Make a pivot table of the total amount with stores down the side and items across the top. Print it.

Goa       NaN  460.0
Pune    240.0  450.0

  10. Medium. This code should put each store's total amount on every order, but the new column is all NaN. Fix it.

    It should print:

  11. Medium. Add a column share = each order's amount as a percent of its store's total, rounded to 1 decimal. Print the store, amount and share columns.

  13. Medium. Print the store, item and amount of the biggest order in each store.

  14. Medium. Make a pivot table that counts the orders, stores down the side and items across, with 0 in empty cells. Print it.

  16. Medium. Stack w1 and w2 with the labels W1 and W2 (use keys=) and print the table.

  19. Challenge. Put the order amounts into bands with pd.cut: Small up to 200, Medium up to 400 and Large up to 1000. Print the number of orders in each band (group with observed=True).

    Your code should print exactly:

  20. Challenge. Using a left join of orders with managers, print the stores (once each) that have no manager, as a list.

    Answer

  21. Challenge. This code should count the orders in each band and print only the bands that have orders, with no warning. Fix the groupby.

    It should print:

Big      4
dtype: int64

    A pd.cut column is a category column. Without observed=True, empty bands like Tiny are kept and Pandas prints a FutureWarning.
