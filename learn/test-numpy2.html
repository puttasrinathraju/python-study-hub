21.1 Big Test: NumPy: maths, axis, filters

25 questions on NumPy operations for analysis only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    [20 40 60] [15 25 35]

    Maths on an array is done on every value at once: no loop needed.

  2. Basic. price = np.array([120, 45, 80]) and qty = np.array([2, 10, 3]). Print the revenue of each item, then the total revenue.

    Your code should print exactly:

    [240 450 240]
930
    Answer

    Two arrays of the same length are multiplied position by position.

  3. Basic. sales = np.array([12000, 15000, 18000, 14000]). Print the mean, the highest and the lowest value with one print().

    Your code should print exactly:

    14750.0 18000 12000
    Answer

    Arrays have built-in statistics methods. mean() always gives a float.

  4. Basic. rev = np.array([50000, 65000, 72000, 58000]). Print the first value, the last value, and the middle two (a slice), with one print().

    Your code should print exactly:

    50000 58000 [65000 72000]
    Answer

    Indexing and slicing work like lists. A slice of an array is an array.

  5. Basic. salaries = np.array([45000, 55000, 38000, 72000]). Print the salaries above 50000, using a boolean mask.

    Your code should print exactly:

    [55000 72000]
    Answer

    salaries > 50000 is an array of True/False. Putting it inside [ ] keeps only the True positions.

  6. Basic. This code should print [45000 55000], but it crashes. Fix the mask.

    It should print:

    [45000 55000]
    Answer

    For arrays, use & (and) and | (or), with brackets around each comparison. and only works on single True/False values.

  7. Basic. Type exactly what this code prints.

    Answer
    [ 9 12] [ 3  7 11]

    axis=0 goes down the rows, giving one total per column. axis=1 goes across, giving one total per row.

  8. Basic. This code should double every price and print [20 40 60]. Fix it.

    It should print:

    [20 40 60]
    Answer

    A list times 2 repeats the list. A NumPy array times 2 doubles every value.

  9. Medium. m = np.array([[1, 2, 3], [4, 5, 6]]). Add [10, 20, 30] to every row using broadcasting, and print the result.

    Your code should print exactly:

    [[11 22 33]
 [14 25 36]]
    Answer

    A row with the same number of columns is "stretched" over every row of the table.

  10. Medium. Rows are months and columns are products. Print the total per month, then the total per product.

    Your code should print exactly:

    [450 440 490]
[330 450 600]
    Answer

    One total per row (month) is axis=1. One total per column (product) is axis=0.

  11. Medium. Type exactly what this code prints.

    Answer
    5.0 2.0 4.5

    The mean is 40 / 8 = 5.0. The standard deviation of this classic example is exactly 2.0. The median averages the two middle values, 4 and 5.

  12. Medium. marks = np.array([45, 82, 30, 67]). Use np.where to label each mark Pass (35 or more) or Fail, and print the labels.

    Your code should print exactly:

    ['Pass' 'Pass' 'Fail' 'Pass']
    Answer

    np.where(condition, if_true, if_false) is a vectorised if/else.

  13. Medium. Rows are January to March, columns are products 1 to 3. Print the February row, then the column of product 3, then the March value of product 2.

    Your code should print exactly:

    [120 140 180]
[200 180 220]
160
    Answer

    [row, column]. A : means "all", so [:, 2] is the whole third column.

  14. Medium. This code should print the total per month (per row): [250 260]. Fix it.

    It should print:

    [250 260]
    Answer

    axis=0 adds up each column. One total per row needs axis=1.

  15. Medium. Type exactly what this code prints.

    Answer
    [ 1 99  3  4]

    A slice of an array is a view of the same data, so changing it changes the original too.

  16. Medium. ratings = np.array([5, 3, 5, 4, 3, 5]). Print the different ratings and how many times each one appears, using np.unique with return_counts=True.

    Your code should print exactly:

    [3 4 5] [2 1 3]
    Answer

    np.unique gives the sorted different values, and with return_counts=True also how often each appears.

  17. Medium. temps = np.array([31, 35, 29, 38, 33]). Print how many days were above 32, and their average rounded to 2 decimals.

    Your code should print exactly:

    3 35.33
    Answer

    Filter first with a mask, then use the statistics on the filtered array.

  18. Medium. This code should leave y unchanged and print [1 2 3 4]. Fix it.

    It should print:

    [1 2 3 4]
    Answer

    A slice is a view. .copy() makes independent data, so changes do not reach the original.

  19. Challenge. price = np.array([499, 1299, 299, 899]) and qty = np.array([10, 3, 25, 6]). Print the position of the product with the highest revenue (argmax), then the share of total revenue that comes from products with above-average revenue, as a percent with 1 decimal.

    Your code should print exactly:

    2
34.4%
    Answer

    Vectorise (price * qty), then summarise (argmax, mean), then filter with a mask: three NumPy steps in a few lines.

  20. Challenge. Occupancy in % for 3 hotels (rows) over 4 weeks (columns): occ = np.array([[60, 72, 75, 80], [55, 65, 70, 90], [70, 68, 74, 76]]). Print each hotel's average (rounded to 2 decimals), then the number of the best week (1 to 4) by average occupancy.

    Your code should print exactly:

    [71.75 70.   72.  ]
4
    Answer

    axis=1 averages each hotel across weeks; axis=0 averages each week across hotels. argmax counts from 0, so add 1.

  21. Challenge. Prices of 3 products: prices = np.array([100, 250, 400]). Make a table with one row per discount level, using a column of factors [[1.0], [0.9], [0.8]] (no discount, 10% off, 20% off) and broadcasting. Print the table.

    Your code should print exactly:

    [[100. 250. 400.]
 [ 90. 225. 360.]
 [ 80. 200. 320.]]
    Answer

    A column (3 x 1) times a row (3) broadcasts into a 3 x 3 table: every factor times every price.

  22. Challenge. Type exactly what this code prints.

    Answer
    ['Ravi' 'Neha' 'Asha']

    argsort gives the positions that would sort the scores (lowest first). Using them on names and reversing gives the names from highest to lowest score.

  23. Challenge. This code should print the values below 10 or above 20: [ 5 25]. Fix the mask.

    It should print:

    [ 5 25]
    Answer

    | runs before < and >, so without brackets Python tries 10 | a first. Put brackets around each comparison.

  24. Challenge. sal = np.array([45000, 55000, 38000, 72000, 41000, 65000]). Cap every salary at 60000 with np.where. Print the capped array and its mean rounded to 2 decimals.

    Your code should print exactly:

    [45000 55000 38000 60000 41000 60000]
49833.33
    Answer

    np.where can replace values: where the test is True use 60000, otherwise keep the salary.

  25. Challenge. scores = np.array([40, 55, 70, 85, 100]). Scale them to the range 0 to 1 with (x - min) / (max - min), and print the result.

    Your code should print exactly:

    [0.   0.25 0.5  0.75 1.  ]
    Answer

    Min-max scaling is one vectorised line: the lowest becomes 0, the highest becomes 1.
