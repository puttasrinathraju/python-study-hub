2.1 Big Test: Variables & data types

25 questions on Variables and data types only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    <class 'int'>
<class 'float'>
<class 'str'>

    250 is a whole number (int), 250.0 has a decimal point (float) and "250" is in quotes, so it is text (str).

  2. Basic. Store "Laptop" in a variable called product and 55000 in a variable called price. Then print both with one print().

    Your code should print exactly:

    Laptop 55000
    Answer

    = stores the value on the right in the name on the left. A comma in print() shows both values with a space between them.

  3. Basic. In ONE line, store "Delhi", "Mumbai" and "Chennai" in city1, city2 and city3. Then print the three cities.

    Your code should print exactly:

    Delhi Mumbai Chennai
    Answer

    Put the names on the left and the values on the right, both separated by commas. The first value goes to the first name, and so on.

  4. Basic. This code should print Ravi, but it crashes. Fix the variable name.

    It should print:

    Ravi
    Answer

    A variable name cannot start with a digit. second_place (or place_2) follows the rules.

  5. Basic. price = "450" is text. Convert it to a number and print the price of 3 items.

    Your code should print exactly:

    1350
    Answer

    int("450") turns the text into the number 450, so the maths works: 1350. Without int(), "450" * 3 would repeat the text.

  6. Basic. Type exactly what this code prints.

    Answer
    True None
<class 'NoneType'>

    True is a bool. None means "no value yet", and its type is NoneType.

  7. Basic. Print the answer of 7 divided by 2. On the next line, print the type of 10 / 2.

    Your code should print exactly:

    3.5
<class 'float'>
    Answer

    / always gives a float, even when the answer is a whole number: 10 / 2 is 5.0.

  8. Basic. This code should print 30, but it crashes. Fix it.

    It should print:

    30
    Answer

    "25" is text, and text + number gives a TypeError. Convert it first with int(age).

  9. Medium. morning_shift = "Asha" and night_shift = "Ravi". Swap them in ONE line, then print morning_shift and night_shift.

    Your code should print exactly:

    Ravi Asha
    Answer

    a, b = b, a swaps two values in one line. Python reads the whole right side first, so nothing is lost.

  10. Medium. Type exactly what this code prints.

    Answer
    9 4.0 123

    int() cuts off the decimal part (it does not round), float(4) adds .0, and str(12) + "3" joins two pieces of text.

  11. Medium. average = 82.4567. Print it rounded to 2 decimal places, then rounded to a whole number, with one print().

    Your code should print exactly:

    82.46 82
    Answer

    round(x, 2) keeps 2 decimal places. round(x) with no second number gives a whole number.

  12. Medium. Type exactly what this code prints.

    Answer
    2 4 0.3

    Python rounds an exact half to the nearest even number, so round(2.5) is 2 and round(3.5) is 4. round(..., 2) cleans up the tiny float error in 0.1 + 0.2.

  13. Medium. This text came from input(): weight = "62.5" (kilograms). Convert it and print the weight in grams (multiply by 1000).

    Your code should print exactly:

    62500.0
    Answer

    The text has a decimal point, so use float(), not int(). A float times 1000 is still a float: 62500.0.

  14. Medium. boxes came from input(). This code should print 10, but it prints 55. Fix it.

    It should print:

    10
    Answer

    input() always gives text, and text * 2 repeats it: "55". Convert it with int() first, then the maths works.

  15. Medium. Store 90 in score and print its type. Then store the text "ninety" in the same variable and print its type again.

    Your code should print exactly:

    <class 'int'>
<class 'str'>
    Answer

    A variable can hold any type, and the type can change when you store a new value. That is dynamic typing.

  16. Medium. value = 3.0. Use isinstance() to print whether it is an int, and then whether it is a float, with one print().

    Your code should print exactly:

    False True
    Answer

    3.0 has a decimal point, so it is a float, not an int, even though it looks whole.

  17. Medium. This code should print 10A, but it crashes. Fix the variable name.

    It should print:

    10A
    Answer

    class is a Python keyword, so it cannot be a variable name. Add a word, like class_name.

  18. Medium. A salary is 2,50,000 rupees a month. Write it with underscores (Indian style: 2_50_000) and print the salary for 12 months.

    Your code should print exactly:

    3000000
    Answer

    Underscores only make big numbers easier to read. Python ignores them, so 2_50_000 is just 250000.

  19. Challenge. From a form: units = "12" and unit_price = "45.50". Print the total as a float. On the next line, print the total as a whole number using int().

    Your code should print exactly:

    546.0
546
    Answer

    Convert each piece of text to the right type: int() for the units and float() for the price. int() then cuts off the .0.

  20. Challenge. Type exactly what this code prints.

    Answer
    False False True True True

    Only zero and empty text are False. A space is not empty, "0" is text that is not empty, and -1 is not zero, so they are all True.

  21. Challenge. This code should print 5.5, but it crashes. Fix it.

    It should print:

    5.5
    Answer

    int() cannot read text with a decimal point, so it gives a ValueError. Use float() for text like "4.5".

  22. Challenge. Start three counters wins, losses and draws at 0 in ONE line. Then add 3 to wins and 1 to losses. Print all three with one print().

    Your code should print exactly:

    3 1 0
    Answer

    a = b = c = 0 gives the same value to all three. Then each one is updated on its own: draws stays 0.

  23. Challenge. value = "100". Print its type. Then convert it to an int and print the new type. Then convert it to a float and print the value itself.

    Your code should print exactly:

    <class 'str'>
<class 'int'>
100.0
    Answer

    Each conversion makes a new value of a new type, and storing it back in value changes its type. The float version of 100 is 100.0.

  24. Challenge. Pretend these came from input(): name = "Priya" and age = "21". Print Priya will be 26 in 5 years, with Python working out the 26.

    Your code should print exactly:

    Priya will be 26 in 5 years
    Answer

    age is text, so convert it with int() before adding 5. Commas in print() join everything with single spaces.

  25. Challenge. Three marks came in as text: m1 = "78", m2 = "85", m3 = "91". Print their average, rounded to 1 decimal place.

    Your code should print exactly:

    84.7
    Answer

    Convert each mark with int(), add them inside brackets, then divide by 3. round(..., 1) keeps 1 decimal place: 84.7.
