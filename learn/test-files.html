17.1 Big Test: Files, CSV, JSON & pickle

25 questions on File handling only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    one
two

    The \n written into the file is a real new line, so reading the file back gives two lines.

  2. Basic. Write Hello File into note.txt, then open it again, read it and print what is inside.

    Your code should print exactly:

    Hello File
    Answer

    Mode "w" writes (and replaces the file). Opening with no mode reads.

  3. Basic. Write three lines, a, b and c, into abc.txt (each ending with \n). Then print how many lines readlines() gives.

    Your code should print exactly:

    3
    Answer

    readlines() gives a list with one string per line.

  4. Basic. Write Day 1 into log.txt with mode "w". Then add Day 2 on a new line with mode "a". Then print the whole file.

    Your code should print exactly:

    Day 1
Day 2
    Answer

    "a" (append) adds to the end and keeps what is there. "w" would wipe it first.

  5. Basic. This code should save the number and print 2000, but it crashes. Fix it.

    It should print:

    2000
    Answer

    write() only takes text. Convert numbers with str() (or an f-string) first.

  6. Basic. Type exactly what this code prints.

    Answer
    Hi
Bye

    Each readline() reads the next line. strip() removes the \n at its end.

  7. Basic. Write Asha and Ravi on two lines into names.txt. Read them back with a for loop over the file and print a list of the names without the \n.

    Your code should print exactly:

    ['Asha', 'Ravi']
    Answer

    Looping over a file gives one line at a time, each still ending with \n, so strip() it.

  8. Basic. This code should print data, but it crashes. Fix the second open().

    It should print:

    data
    Answer

    A file opened with "w" can only be written, and opening it with "w" also empties it. Read with "r".

  9. Medium. Write the rows [["name", "marks"], ["Asha", 82], ["Ravi", 67]] to marks.csv with csv.writer. Read it back with csv.DictReader and print one line per student: Asha: 82.

    Your code should print exactly:

    Asha: 82
Ravi: 67
    Answer

    DictReader uses the first row as column names, so each row is a dictionary like {"name": "Asha", "marks": "82"}.

  10. Medium. Save {"name": "Asha", "scores": [82, 91]} to s.json with json.dump. Load it back with json.load and print the sum of the scores.

    Your code should print exactly:

    173
    Answer

    JSON keeps the structure: the list comes back as a real list of numbers.

  11. Medium. Type exactly what this code prints.

    Answer
    {"ok": true, "coupon": null}

    In JSON, Python's True becomes true and None becomes null. JSON always uses double quotes.

  12. Medium. Use os.path.exists() to print whether "hotel_bookings.csv" exists and whether "missing.csv" exists, with one print().

    Your code should print exactly:

    True False
    Answer

    os.path.exists() checks for a file without opening it, so nothing can crash.

  13. Medium. This code should print File missing instead of crashing. Fix it with try / except.

    It should print:

    File missing
    Answer

    Opening a file that is not there raises FileNotFoundError, which you can catch like any error.

  14. Medium. Read hotel_bookings.csv with csv.DictReader and print how many bookings (data rows) it has.

    Your code should print exactly:

    41
    Answer

    The header row becomes the keys, so it is not counted as a booking.

  15. Medium. Type exactly what this code prints.

    Answer
    5

    The file holds x, new line, y, new line, z: 5 characters. writelines() adds no extra new lines.

  16. Medium. Write data is the new oil and data is power into quote.txt. Read it back and print the number of words and how many times data appears, with one print().

    Your code should print exactly:

    9 2
    Answer

    Once the text is read into a string, all the string and list tools work on it.

  17. Medium. Write {"theme": "light", "font": 14} to settings.json. Then load it, change theme to "dark", save it again, load it once more and print the dictionary.

    Your code should print exactly:

    {'theme': 'dark', 'font': 14}
    Answer

    Load, change, save: the usual way to update a settings file.

  18. Medium. This code should print {'a': 1}, but it crashes. Fix the line that saves the file.

    It should print:

    {'a': 1}
    Answer

    dumps() (with an s, for string) only makes text. dump() writes into a file.

  19. Challenge. From hotel_bookings.csv, add up amount per channel for confirmed bookings only. The data is messy: clean status with strip().title() and channel with strip().lower(); some amounts look like ₹5,200 (remove ₹ and ,) and some are empty (skip them). Print the channels sorted by total, highest first, as Channel: ₹amount (with commas).

    Your code should print exactly:

    booking.com: ₹67,800
goibibo: ₹48,400
makemytrip: ₹47,400
walk-in: ₹30,000
    Answer

    Real files are messy: Walk-in, Walk-in and goibibo must be cleaned before grouping, and amounts must be turned into plain digits before int().

  20. Challenge. From hotel_bookings.csv, write a file summary.txt with three lines: Bookings: <all rows>, Nights: <total nights> and Revenue: ₹<total amount with commas>. Skip empty nights or amounts, and remove ₹ and , from amounts like ₹5,200. Then print the file.

    Your code should print exactly:

    Bookings: 41
Nights: 86
Revenue: ₹234,800
    Answer

    Read, clean, calculate, then write a small report file that others can open.

  21. Challenge. Save {"Ramayan": 1000, "Drishyam": 500} with pickle, load it back, and print whether the loaded dict equals the original, and the loaded dict itself.

    Your code should print exactly:

    True {'Ramayan': 1000, 'Drishyam': 500}
    Answer

    pickle files are binary, so use "wb" and "rb". The object comes back exactly as it was.

  22. Challenge. Type exactly what this code prints.

    Answer
    Ravi 2150

    CSV values are always read as text, so int() is needed before adding.

  23. Challenge. Write apple, banana and cherry on three lines into fruits.txt. Read it back as a list of clean names using a list comprehension over the file, and print the list.

    Your code should print exactly:

    ['apple', 'banana', 'cherry']
    Answer

    A file is a sequence of lines, so it works directly in a comprehension.

  24. Challenge. Save this list of orders to orders.json: [{"customer": "Asha", "amount": 1200}, {"customer": "Ravi", "amount": 3400}, {"customer": "Neha", "amount": 800}]. Load it back, then print the total amount and the customer of the biggest order (use max() with key=lambda).

    Your code should print exactly:

    5400 Ravi
    Answer

    A JSON file can hold a whole list of records, ready for the usual list and dictionary tools.

  25. Challenge. This code should write onetwo and print it, but it crashes. Fix it.

    It should print:

    onetwo
    Answer

    The file closes as soon as the with block ends. Every write must be indented inside the block.
