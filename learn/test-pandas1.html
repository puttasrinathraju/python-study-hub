23.1 Big Test: Pandas basics

25 questions on Pandas basics: Series, DataFrames and reading files only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    30 15

    A Series adds up and finds its maximum like a NumPy array: 5 + 10 + 15 = 30, and the biggest is 15.

  2. Basic. Make a Series of the prices [250, 400, 150] with the labels ["tea", "coffee", "juice"], and print the price of coffee.

    Your code should print exactly:

    400
    Answer

    index= gives the labels; then you pick a value by its label, like a dictionary key.

  3. Basic. Build a DataFrame with the columns item = pen, book and price = 20, 150, and print it.

    Your code should print exactly:

       item  price
0   pen     20
1  book    150
    Answer

    A dictionary of lists becomes a table: each key is a column name.

  4. Basic. Print the shape of cart, then its column names as a list.

    Your code should print exactly:

    (3, 3)
['item', 'price', 'qty']
    Answer

    shape is (rows, columns); list(df.columns) gives the names.

  5. Basic. Read employees.csv and print how many rows it has, using len().

    Your code should print exactly:

    41
    Answer

    len(df) is the number of rows, the same as df.shape[0].

  6. Basic. This code should print the first 2 rows of cart, but it stops with an error. Fix it.

    It should print:

       item  price  qty
0   pen     20    5
1  book    150    2
    Answer

    head is a method, so it needs round brackets: head(2).

  7. Basic. Type exactly what this code prints.

    Answer

    isna() marks the two None values as True, and sum() counts them.

  8. Basic. Read employees.csv and print the last 2 values of the name column.

    Your code should print exactly:

    39      Rekha Murthy
40      Tarun Chopra
Name: name, dtype: object
    Answer

    tail(2) works on a single column (a Series) too.

  9. Medium. prices = pd.Series([100, 250, 80]). Print every price with 18% GST added, rounded to 2 decimals, as a list.

    Your code should print exactly:

    [118.0, 295.0, 94.4]
    Answer

    Maths on a Series works on every value at once; round(2) and tolist() work on the whole Series too.

  10. Medium. This code should print the item and qty columns of cart, but it raises a KeyError. Fix it.

  12. Medium. Type exactly what this code prints.

    Answer

  13. Medium. Read employees.csv and print the number of missing values in the whole table.

  14. Medium. Read employees.csv and print how many emp_id values appear again after their first time.

    Your code should print exactly:

    1

  15. Medium. This code saves cart and reads it back. It should print ['item', 'price', 'qty'], but an extra column appears. Fix the save line.

    It should print:

    ['item', 'price', 'qty']

    Without index=False, the row numbers are saved as a column and come back as Unnamed: 0.

  16. Medium. Read employees.csv and print the statistics of the score column with describe().

  17. Medium. Type exactly what this code prints.

  18. Medium. Read employees.csv and print the name of 2 random rows, using sample() with random_state=1.

    Your code should print exactly:

  19. Challenge. Make a Series from the dictionary {"Deluxe": 12, "Suite": 3, "Standard": 25}. Print the total rooms, then the share of Suite rooms in percent with 1 decimal.

    Your code should print exactly:

7.5

  20. Challenge. Read employees.csv. Print how many salaries are missing, then the share of rows with a missing salary in percent, with 1 decimal.

    Your code should print exactly:

  21. Challenge. Read student_scores.csv using its first column as the index. Print the shape, then the number of missing values in TestPrep.

21

  22. Challenge. This code should print how many rows of orders are exact duplicates (1), but it prints a column of True/False. Fix it.

    It should print:

    1
    Answer

    duplicated() gives one True/False per row; sum() counts the True values.

  24. Challenge. Build a DataFrame of 3 rooms with the columns type = Deluxe, Suite, Standard and price = 3500, 7000, 2200, using the room numbers [101, 102, 103] as the index. Print the table, then the total of the price column.

  25. Challenge. This code should print (3, 3), but it stops with a TypeError. Fix it.
