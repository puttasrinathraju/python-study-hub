NumPy operations for analysis

Vectorisation: maths on the whole array

With NumPy you write the maths once and it applies to every element. No loop needed. This is called vectorisation, and it is both shorter and much faster.

Trap! Lists and arrays react differently to maths

Multiplying a list repeats it. Multiplying an array multiplies every value. Same symbol, completely different result.

Broadcasting

When shapes differ, NumPy tries to broadcast: it stretches the smaller array to match the bigger one, without actually copying data. A single number works with any array. A row works with every row of a matrix.

Animated explainer: How broadcasting stretches a row

  1. We want to add a 1D row of 3 values to a 2 x 3 matrix. The shapes are (2, 3) and (3,).
  2. NumPy lines the shapes up from the right. The last dimensions match (3 and 3), so it stretches the row down to cover both rows.
  3. Now it adds element by element. Every row got 10, 20 and 30 added.
  4. If the sizes do not line up (3 vs 2), NumPy cannot stretch either one, and you get an error.

Statistics

Trap! Two different standard deviations

NumPy's .std() gives the population standard deviation (2608.75 here). The statistics.stdev() function and pandas' .std() give the sample standard deviation (2857.74). Neither is wrong, they answer slightly different questions. To make NumPy match pandas, write arr.std(ddof=1).

axis: the most confusing argument in NumPy

When you call sum(), mean() or max() on a 2D array, axis decides which direction to collapse. Without it, you get one number for the whole table.

Animated explainer: axis=1 vs axis=0 on the sales table

  1. With no axis, sum() adds every value: 1380. Now let us collapse in one direction only.
  2. axis=1 moves across each row, left to right. January: 100 + 150 + 200 = 450.
  3. February: 120 + 140 + 180 = 440.
  4. March: 490. One answer per row: these are the monthly totals.
  5. axis=0 moves down each column, top to bottom. Product A: 100 + 120 + 110 = 330.
  6. One answer per column: the product totals. The rows were squashed together.

Slides: Axis without tears

  1. axis tells NumPy which direction to squash.

    The axis you name is the one that disappears.

  2. axis=0 squashes the rows

    It goes down the columns. A (3, 3) table becomes 3 values: one per column.

  3. axis=1 squashes the columns

    It goes across the rows. A (3, 3) table becomes 3 values: one per row.

  4. A memory trick

    • axis=0: think "0 is a tall stick" → go down
    • axis=1: think "1 lies flat" → go across
    • Shape (rows, cols): axis 0 is rows, axis 1 is cols. Naming one makes it vanish.

  5. Same idea in pandas

    df.sum(axis=0) gives a total per column (the default). df.drop("col", axis=1) drops a column. Learn axis once here and it works there too.

Predict the output

  1. [5 6] [2 4 6]
  2. [2 4 6] [5 6]
  3. 6 6
  4. [5 6] [5 6]
Answer

[5 6] [2 4 6]. axis=0 goes down each column: max of (1, 3, 5) is 5, max of (2, 4, 6) is 6. axis=1 goes across each row: 2, 4, 6.

Filtering with boolean masks

A comparison on an array gives back an array of True/False, called a mask. Put the mask inside square brackets and you keep only the True positions. This is how you filter data.

Animated explainer: Filtering salaries above 50,000

  1. Six salaries. We want only the high earners: above 50,000.
  2. The comparison checks every value at once and gives a mask of True/False.
  3. Using the mask as an index keeps only the True positions: 55000, 72000 and 65000.
  4. Bonus trick: True counts as 1 and False as 0, so summing a mask counts the matches.

Combining conditions: & and |

Trap! Use & | ~ with brackets, never and / or

Python's and and or cannot work on a whole array, and you get a famous confusing error. Use & (and), | (or), ~ (not), and wrap each condition in brackets, because & binds tighter than >. The same rule applies in pandas.

Views vs copies

Trap! A slice is a view, not a copy

Slicing a list makes a new list. Slicing a NumPy array does not copy the data: it gives a view onto the same memory. Change the slice and the original changes too. Use .copy() when you need a separate array.

Key takeaways

  • Maths on arrays applies to every value: prices * 0.9. Lists repeat instead.
  • Broadcasting stretches a number, row or column to match the bigger array.
  • mean, sum, max, min, std, argmax, cumsum, np.median, np.percentile.
  • 2D indexing: m[row, col], m[0, :] a row, m[:, 1] a column.
  • axis=0 goes down (one result per column). axis=1 goes across (one result per row).
  • Filter with masks: a[a > 50]. Combine with &, |, ~ and brackets. Count with np.sum(mask).
  • Slices are views. Use .copy() to get a separate array.

Flashcards

What is vectorisation?
Applying an operation to every element at once without a loop, e.g. prices * 0.9.
[1, 2] * 2 vs np.array([1, 2]) * 2
List: [1, 2, 1, 2] (repeats). Array: [2 4] (multiplies).
What is broadcasting?
NumPy stretching a smaller array (a number, a row, a column) to match a bigger one so element-wise maths works.
How do you select a whole column in a 2D array?
m[:, col], e.g. m[:, 1]. A whole row is m[row, :] or m[row].
What does axis=0 do in sum(axis=0)?
Goes down the rows, giving one result per column.
What does axis=1 do in sum(axis=1)?
Goes across the columns, giving one result per row.
What is a boolean mask?
An array of True/False from a comparison, like a > 50. a[mask] keeps the True positions.
How do you count values that meet a condition?
np.sum(a > 50). True counts as 1.
How do you combine conditions in NumPy?
& (and), | (or), ~ (not), with brackets: a[(a > 10) & (a < 20)].
What does np.where(cond, x, y) do?
For each element: x where cond is True, y where it is False.
argmax vs max
max gives the largest value. argmax gives its index.
Is an array slice a copy?
No, it is a view on the same data. Use .copy() for an independent array.
