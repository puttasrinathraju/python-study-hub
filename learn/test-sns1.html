29.1 Big Test: Spread & categories

25 questions on Seaborn: distributions and categories only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Draw a Seaborn histogram of the Sales column of sales with 15 bins, and give it a title.

    Your code should print exactly:

    Answer
    Give the DataFrame to data= and the column name to x=; bins=15 makes 15 bars.
  2. Basic. Load the tips dataset with sns.load_dataset and draw a histogram of tip, coloured by smoker (hue=).
    Your code should print exactly:
    Answer
    hue= colours the bars by another column and adds the legend (Yes, No) by itself.
  3. Basic. Type exactly what this code prints.
    Answer
    [3, 4]
    Two bins from 5 to 9 split at 7: the 5, 5 and 6 fall in the first bin and the four 9s in the second.
  4. Basic. days = ["Mon", "Tue", "Mon", "Wed", "Mon", "Tue"]. Count each day with sns.countplot, in the order Mon, Tue, Wed, and set the y label to Orders.
    Your code should print exactly:
    Answer
    order= fixes the left-to-right order of the bars.
  5. Basic. This code should count the bills per day, but it stops with a TypeError. Fix it.
    It should print:
    Answer
    countplot counts one column: give it x= (upright bars) or y= (sideways bars), never both.
  6. Basic. Type exactly what this code prints.
    Answer
    [10.0, 6.0]
    barplot shows the mean: p has only 10, and q has (4 + 8) / 2 = 6.
  7. Basic. With tips, draw a box plot of total_bill for each time (Lunch and Dinner), with a title.
    Your code should print exactly:
    Answer
    One box per value of x=: two boxes.
  8. Basic. This code should use the white grid style, but it stops with a ValueError. Fix the style name.
    It should print:
    Answer
    The five styles are darkgrid, whitegrid, dark, white and ticks.
  9. Medium. With tips, draw a histogram of total_bill with bins 5 dollars wide (binwidth=5), stacked by time (multiple="stack").
    Your code should print exactly:
    Answer
    binwidth= sets the width of each bin; multiple="stack" puts dinner on top of lunch.
  10. Medium. Draw filled KDE curves of Sales for each Region, each with an area of 1 (common_norm=False), stopping at the real data (cut=0).
    Your code should print exactly:
    Answer
    cut=0 stops each curve at its smallest and largest order, so no negative sales appear.
  11. Medium. With tips, draw an ECDF of tip for each sex, and add a dashed grey vertical line at a tip of 3 with plt.axvline.
    Your code should print exactly:
    Answer
    At the line you can read the share of tips that are $3 or less for men and for women.
  12. Medium. Use sns.displot to draw histograms of total_bill from tips, with **one panel per time** (col=).
    Your code should print exactly:
    Answer
    displot is figure-level: col="time" makes a Lunch panel and a Dinner panel.
  13. Medium. Type exactly what this code prints.
    Answer
    FacetGrid 2
    A figure-level function returns a FacetGrid; two values of col give two panels.
  14. Medium. Draw the total sales per Region as bars with sns.barplot (estimator="sum"), with no error bars and the pastel palette (use hue="Region" and legend=False).
    Your code should print exactly:
    Answer
    A palette colours a hue= column: using the same column as x= gives each bar its own colour without a warning.
  15. Medium. This code should show the average tip per day with a 95% confidence interval, but it stops with a ValueError. Fix the errorbar value.
    It should print:
    Answer
    The interval is written as a pair: errorbar=("ci", 95). (That is also the default.)
  16. Medium. With tips, draw violins of tip per day, split in two halves by smoker (hue=, split=True), with dashed quartile lines (inner="quart").
    Your code should print exactly:
    Answer
    Each violin shows smokers on one side and non-smokers on the other.
  17. Medium. Type exactly what this code prints.
    Answer
    2
    A strip plot draws one group of dots per category: one for a and one for b.
  18. Medium. Draw a white box plot of Profit per Region without the outlier dots (showfliers=False), and put every order on top as small black dots with sns.stripplot.
    Your code should print exactly:
    Answer
    Both functions draw on the same axes: the summary and the real data together.
  19. Challenge. Make a Quarter column ("Q1" to "Q4") from Date, then draw the average profit per quarter with sns.pointplot, in the order Q1 to Q4.
    Your code should print exactly:
    Answer
    dt.quarter gives 1 to 4; turning it into text with "Q" in front makes good labels.
  20. Challenge. Use sns.catplot to draw violins of total_bill per day from tips, with one panel per sex.
    Your code should print exactly:
    Answer
    kind="violin" picks the chart and col="sex" makes two panels.
  21. Challenge. This code should draw a box plot in the left chart of a 1 × 2 figure, but Seaborn warns and draws a separate figure instead. Fix it.
    It should print:
    Answer
    catplot is figure-level and ignores ax=. The axes-level sns.boxplot(..., ax=axes[0]) draws inside the grid.
  22. Challenge. Use sns.set_theme(style="ticks", palette="colorblind"), draw a count of orders per Category split by Region (hue=), and remove the top and right border lines with sns.despine().
    Your code should print exactly:
    Answer
    despine() hides the top and right spines; the colorblind palette is safe for every reader.
  23. Challenge. Type exactly what this code prints.
    Answer
    10 3
    A named palette like pastel has 10 colours; color_palette("husl", 3) asks for exactly 3.
  24. Challenge. This code should stack the order values by region, but it stops with a ValueError. Fix it.
    It should print:
    Answer
    The four choices are "layer", "stack", "dodge" and "fill".
  25. Challenge. Draw the average Profit per Region as bars, highest average first. Work out the order with groupby(...).mean().sort_values(ascending=False).index, and show one standard deviation (errorbar="sd").
    Your code should print exactly:
    Answer
    Sorted bars are easier to compare, and the long sd lines show that single orders vary far more than the averages do.
