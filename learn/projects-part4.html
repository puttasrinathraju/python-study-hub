Part 4 projects: functions

Three programs built from small, reusable functions, the way real analysis scripts are written. Each brief names the functions to write. You may use everything up to Part 4, but no try, import, files or classes yet.

In the interactive version you write each program in the browser, run it with your own numbers, and press Submit to get an automatic score out of 100 with feedback. A score of 70 or more means you are ready for the next project.

Project 4.1 (Beginner): GST invoice builder

Build a shop invoice from small functions: line totals, discount and GST.

Suresh owns an office-supplies shop in Visakhapatnam. His billing is done on paper, and mistakes in the discount or GST are common.

Write a program that reads the items of one bill (item,qty,price) until done, and prints a clean invoice: one line per item, the subtotal, the discount, 18% GST on the amount after discount, and the grand total. The shop gives 5% off bills of ₹5,000 or more and 10% off bills of ₹10,000 or more.

The point of this project is to put each calculation in its own small function, so it can be checked and reused.

What you will practise

  • Write small functions that take parameters and return a value
  • Use a default parameter value
  • Call your functions from the main part of the program
  • Format an invoice cleanly

You may use: everything from Parts 1-3, def, parameters, return, default values, lambda.
Do not use yet: try / except, import, files, classes.

Your tasks

  1. Write line_total(qty, price) that returns qty × price.
  2. Write discount_for(subtotal) that returns the discount amount: 10% of the subtotal for ₹10,000 or more, 5% for ₹5,000 or more, otherwise 0.
  3. Write gst_amount(amount, rate=18) that returns rate% of the amount.
  4. In a loop, ask Item (name,qty,price) or done: . Stop at done (any capitals, spaces are fine). Split each row at the commas and strip each part. The quantity is a whole number; the price can have paise.
  5. For each item, print Tea x 3 = ₹60.00 using line_total(), and add it to the subtotal.
  6. If no items were entered, print No items.
  7. Otherwise print the subtotal, the discount, the GST (on the subtotal minus the discount) and the grand total, using your functions.
  8. Add a docstring or a comment to each function saying what it returns.

Lines your output must contain

<item> x <qty> = ₹<amount>
Subtotal: ₹<amount>
Discount: ₹<amount>
GST (18%): ₹<amount>
Grand total: ₹<amount>
No items

All money uses ₹, commas and 2 decimals (:,.2f). The item name is printed as typed, without the spaces around it. Rows are always name,qty,price with 3 parts.

Example run

Typed values: Tea,3,20, Coffee,2,45, Sandwich,1,120, done.

Tea x 3 = ₹60.00
Item (name,qty,price) or done: Coffee,2,45
Coffee x 2 = ₹90.00
Item (name,qty,price) or done: Sandwich,1,120
Sandwich x 1 = ₹120.00
Item (name,qty,price) or done: done
Subtotal: ₹270.00
Discount: ₹0.00
GST (18%): ₹48.60
Grand total: ₹318.60

Edge cases to think about

  • done straight away: print No items.
  • A subtotal of exactly ₹5,000 or ₹10,000 gets the discount (>=).
  • GST is worked out on the amount after the discount.
  • Prices with paise, like 12.75.
  • Spaces around the parts of a row, and DONE in capitals.
  • Very big bills with commas.

Hint 1

Start with the three functions at the top. Each one is 2-5 lines: for example def line_total(qty, price): then return qty * price.

Hint 2

discount_for() needs if subtotal >= 10000: return subtotal * 10 / 100, then an elif for 5000, and return 0 at the end.

Hint 3

Project 4.2 (Intermediate): Monthly payroll

Work out pay and tax for each employee with functions, then rank them.

Fatima is the HR analyst at a logistics company in Hyderabad. Every month she works out each employee's pay from their basic salary and overtime, deducts income tax using simple slabs, and sends a ranked summary to the finance team.

Overtime is paid at ₹250 per hour (keep this as a default value, because it may change). The company uses whole rupees, and tax is rounded down:

- no tax on the first ₹25,000 of gross pay,

- 10% on the part from ₹25,000 to ₹50,000,

- 20% on the part above ₹50,000.

Write the calculations as functions, read the employees until done, and print the ranked payroll and the totals.

What you will practise

  • Split a business rule into functions that call each other
  • Use default parameter values for rates
  • Sort records with key=lambda and a tie rule
  • Summarise a list of records

You may use: everything from Parts 1-3, def, return, default values, lambda with sorted(), tuples and lists of records.
Do not use yet: try / except, import, files, classes.

Your tasks

  1. Write gross_pay(basic, hours, rate=250) that returns basic + hours × rate.
  2. Write income_tax(gross) that returns the tax using the slabs above, rounded down to whole rupees with //.
  3. Write net_pay(gross) that returns gross − income_tax(gross) (one function calling another).
  4. Read rows name,basic,hours until done (any capitals). Strip the parts, clean the name (no extra spaces, title case) and convert the numbers with int().
  5. Store each employee as a record, for example a tuple (name, gross, tax, net), in a list.
  6. If there are no employees, print No employees. Otherwise rank them by net pay, highest first; equal net pay goes A to Z by name.
  7. Print one line per employee: 1. Neha: gross ₹54,500, tax ₹3,400, net ₹51,100.
  8. Print Employees, Total net pay, Average net pay (2 decimals), Total tax and Overtime cost (all overtime paid).

Lines your output must contain

<rank>. <Name>: gross ₹<amount>, tax ₹<amount>, net ₹<amount>
Employees: <count>
Total net pay: ₹<amount>
Average net pay: ₹<amount with 2 decimals>
Total tax: ₹<amount>
Overtime cost: ₹<amount>
No employees

Amounts are whole rupees with commas (:,), like ₹54,500. Only the average has 2 decimals (:,.2f).

Example run

Employee (name,basic,hours) or done: Ravi,22000,0
Employee (name,basic,hours) or done: Neha,52000,10
Employee (name,basic,hours) or done: done
1. Neha: gross ₹54,500, tax ₹3,400, net ₹51,100
2. Asha: gross ₹47,000, tax ₹2,200, net ₹44,800
3. Ravi: gross ₹22,000, tax ₹0, net ₹22,000

Overtime cost: ₹4,500

Edge cases to think about

  • done straight away: No employees.
  • Gross pay exactly on a slab edge (₹25,000 or ₹50,000).
  • Tax rounding: 10% of ₹10 is ₹1, but 10% of ₹5 is ₹0 (rounded down).
  • Two employees with the same net pay: A to Z.
  • A very high salary (the 20% slab).
  • Names typed in small letters or with extra spaces.

Hint 1

Project 4.3 (Challenging): Stock price tracker

Read daily closing prices through a generator and analyse the trend with your own functions.

Deepak follows one NSE stock and writes down its closing price every day. Sometimes he types junk: N/A on a holiday, a price with a comma, or 0.

He wants a small analysis tool: how much the price changed overall, the highest and lowest days, the 3-day moving averages that traders use to smooth out the noise, the best single day (the biggest percentage rise), and the longest run of rising days.

Build it from functions, and read the input through a generator that hands out one line at a time, like a real data pipeline. This is practice in analysis, not investment advice.

What you will practise

  • Write a generator that reads input lazily with yield
  • Validate text before converting it
  • Write functions that return lists and numbers from a list of prices
  • Combine max() / index() or a lambda to find the best day

You may use: everything from Parts 1-3, def, return, defaults, generators and yield, lambda, map(), filter().
Do not use yet: try / except, import, files, classes.

Your tasks

  1. Write a generator read_lines() that keeps asking Closing price (or end): , stops when the user types end (any capitals, spaces around it are fine), and yields every other line without its outer spaces.
  2. Write is_valid_price(text): True only if the text is a number with at most one decimal point (no commas, no minus sign) and is more than 0. Hint: text.replace(".", "", 1).isdigit().
  3. Write percent_change(old, new) that returns (new − old) ÷ old × 100.
  4. Write moving_averages(prices, window=3) that returns a list with the average of every 3 days in a row (days 1-3, 2-4, ...).
  5. Write longest_rising_streak(prices) that returns the most day-to-day rises in a row (prices 10, 11, 12 have a streak of 2).
  6. Read the prices with your generator, keep the valid ones as floats, and count the skipped ones. Print Days and Skipped. With no valid prices, print No prices to analyse and stop.
  7. Print the first and last price, the overall change (first to last), and the highest and lowest price with the day they happened (the first such day if repeated).
  8. Print the 3-day averages joined with , (or not enough data for fewer than 3 days), the best day (biggest percentage change from the day before; none with only 1 day), and the longest rising streak.

Lines your output must contain

Days: <count>
Skipped: <count>
First price: ₹<amount>
Last price: ₹<amount>
Overall change: <number>%
Highest: ₹<amount> on day <n>
Lowest: ₹<amount> on day <n>
3-day averages: <number>, <number>, ...
Best day: day <n> (<number>%)
Longest rising streak: <n> days
No prices to analyse

Prices and averages use commas and 2 decimals (:,.2f); percentages use 2 decimals (:.2f) and a % sign. Day 1 is the first valid price. Write days even for 0 or 1. Use 3-day averages: not enough data and Best day: none when there is too little data.

Edge cases to think about

  • Junk lines like N/A, 1,520, -5, 0 and 12.5.3 are skipped and counted.
  • Only one valid price: overall change 0.00%, no averages, no best day, a streak of 0.
  • Exactly two prices: still not enough for a 3-day average.
  • The best day is the biggest percentage rise, not the biggest rupee rise.
  • A price that falls every day: the best day is the smallest fall.
  • END in capitals ends the input.

Hints

Hint 1

The generator: def read_lines(): with while True: inside; read line = input(...).strip(), if line.lower() == "end": return, else yield line. Then for text in read_lines(): in the main program.

Hint 2

moving_averages(): loop for start in range(len(prices) - window + 1): and average prices[start:start + window]. The streak: walk through the days, add 1 to a counter when today is higher than yesterday, reset it to 0 otherwise, and keep the biggest value.

Hint 3

For the best day, build the list of changes changes = [percent_change(prices[d - 1], prices[d]) for d in range(1, len(prices))]. The best day number is changes.index(max(changes)) + 2 (change 0 is day 2). Highest day: prices.index(max(prices)) + 1.
