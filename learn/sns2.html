Scatter plots: hue, size and style

This chapter is about relationships: how one number moves with another. sns.scatterplot() is plt.scatter() plus three extras that each show one more column: hue= (colour), size= (dot size) and style= (marker shape). Each one gets its own legend.

Clothing and groceries orders sit at the bottom left; electronics and furniture spread out to the right. A few dots fall below 0: orders sold at a loss.

Easy tip

sizes=(20, 200) sets the smallest and biggest dot. bbox_to_anchor=(1.02, 1) moves a long legend outside the chart. Do not use all three extras without a reason: two is usually the limit for a clear chart.

Line plots and confidence bands

sns.lineplot() sorts the x values and joins them. When an x value has many rows (like 40 orders in January), it draws their mean, with a shaded 95% confidence band around it.

The band is wide because single orders vary a lot (₹108 to ₹11,352). For totals, use estimator="sum", and errorbar=None to remove the band.

You can also total the data with Pandas first and give Seaborn the small table. Then each x value has exactly one row, and there is no band.

Trap!

lineplot always sorts by x. That is right for months, but not for text labels in a special order like "Jan", "Feb": those sort A to Z (Apr, Aug, Dec ...). Use month numbers, or real dates.

Regression lines: regplot and lmplot

A regression line is the straight line that fits a scatter best (Chapter 28 found it with np.polyfit). sns.regplot() draws the scatter, the line and a 95% band in one line. Seaborn does not print the numbers, so use np.polyfit when you need the slope.

Animated explainer: From a scatter to a regression check

  1. 1. Start with the points: tips against bills. Bigger bills seem to get bigger tips.
  2. 2. regplot(..., ci=None) adds the best straight line. It rises: about 10 cents of tip per extra dollar of bill.
  3. 3. Without ci=None you also get the 95% band: where the true line probably lies. It is wider at the ends, where there are fewer points.
  4. 4. residplot shows what the line misses for each point. Points spread evenly around 0 mean a straight line is a fair fit.

Each extra ₹1 of sales brings about ₹0.15 of profit. scatter_kws and line_kws are dicts of options passed to the dots and the line. Real data is not always straight: order=2 fits a curve.

sns.lmplot() is the figure-level version: hue= draws one line per group, and col= / row= make panels.

Trap!

The band comes from bootstrapping (re-sampling the data many times), so it changes a tiny bit every run. regplot and lmplot still use ci= (ci=None removes the band); the newer name errorbar= is only for barplot, pointplot and lineplot.

Checking the fit: residplot

A residual is the real value minus the line's value: how far each point is from the line. sns.residplot() plots them around a flat line at 0. Look for a pattern: a curve means a straight line is the wrong shape.

Here the points spread out more as sales grow: a funnel. The line is right on average, but its guesses are less exact for big orders.

Faceted relations: relplot

sns.relplot() is the figure-level version of scatterplot (kind="scatter", the default) and lineplot (kind="line"). Use it for panels with col=, row= and col_wrap=.

Diagram: Seaborn's three families. Each figure-level function can draw any chart of its family, with panels. The axes-level functions below it draw one chart and accept ax=.

g.set(...) changes every panel at once, like ax.set(...) for one axes: g.set(xticks=..., ylim=(0, 5000)).

Predict the output

  1. Axes FacetGrid
  2. FacetGrid FacetGrid
  3. Axes Axes
  4. Figure Axes
Answer

Axes FacetGrid. scatterplot is axes-level and returns the Matplotlib axes; relplot is figure-level and returns a FacetGrid.

Heatmaps: correlations and pivot tables

In Chapter 28 a heatmap took a loop of plt.text(). sns.heatmap() does it in one line: give it a table of numbers (a DataFrame) and it uses the index and column names as labels.

Animated explainer: Building a correlation heatmap

  1. sns.heatmap(corr): one coloured cell per pair of columns, with the names on both axes and a colour bar.
  2. annot=True writes each value in its cell; fmt=".2f" rounds it to 2 decimals.
  3. A diverging colour scale (cmap="coolwarm") with center=0: red for positive, blue for negative, white for no link.
  4. The matrix is a mirror image, so a mask hides the upper half (True = hide). Now each pair appears once.

Predict the output

  1. (5, 5) 0.78
  2. (500, 5) 0.78
  3. (5, 5) 1.0
  4. (5, 2) 0.78
Answer

(5, 5) 0.78. A correlation table has one row and one column per number column: 5 × 5. Sales and profit have a strong link, 0.78.

Any pivot table makes a good heatmap: a grid of averages for two category columns.

Combine it with pd.cut() (Chapter 26) to turn a number column into groups first. Pass observed=True, because the groups are a category type.

Clustermap: grouping similar rows

sns.clustermap() is a heatmap that reorders the rows and columns so similar ones sit next to each other. The tree diagrams (dendrograms) on the sides show which ones were joined first.

Sales and profit are joined first: they are the most alike. The other columns barely move together. Clustermap needs the SciPy library: on this site it loads by itself the first time (a few seconds), and on your laptop pip install scipy.

Easy tip

standard_scale=1 rescales each column to run from 0 (its lowest value) to 1 (its highest) before drawing; 0 does the same for rows. The cells now show these scaled values, so in every region you see which categories are at the top and bottom. A clustermap has its own layout: put a title on g.ax_col_dendrogram, the tree at the top.

FacetGrid: your own panels

displot, catplot and relplot are built on a FacetGrid: a grid of panels, one per value of col= and row=. Make one yourself when you want any chart in the panels. Step 1 makes the empty grid; step 2 maps a chart onto every panel.

Pair plots: every pair at once

sns.pairplot() draws a scatter for every pair of number columns, and the shape of each column on the diagonal. It is the fastest first look at a new dataset.

Read it like a table: the panel in row Profit and column Sales is the Sales vs profit scatter. The diagonal shows each column alone. Age has no clear link with anything. corner=True drops the mirror half, and vars= picks the columns.

A PairGrid lets you choose the chart for each part: the upper triangle, the lower triangle and the diagonal.

Trap!

A pair plot of 10 columns is 100 charts and can take a long time. Pick 3 to 5 columns with vars= or a smaller DataFrame.

Joint plots: one pair in detail

sns.jointplot() shows one pair: the relationship in the middle, and each column's own shape on the top and right margins. kind= picks the middle chart: "scatter", "reg", "hex", "kde" or "hist".

With hundreds of points, dots hide each other. "hex" counts the points in little hexagons (darker = more), and "kde" draws smooth contour lines. A JointGrid lets you pick both parts yourself.

Contexts and colour scales

A context scales the text and lines for where the chart will be seen: "paper" (small), "notebook" (the default), "talk" (slides) and "poster" (big). sns.set_context("talk") sets it for every chart; with sns.plotting_context(...) for a few.

Pick the colour scale by the kind of data, not by taste.

Seaborn inside Matplotlib layouts

Axes-level functions take ax=, so you can build a dashboard with plt.subplots() from Chapter 28 and fill each panel with a Seaborn chart. ax.set(title=..., xlabel=..., ylabel=...) sets several labels at once.

Figure-level charts make their own figure, so save them through the grid: g.savefig("file.png", dpi=300). For an axes-level chart, plt.savefig() works as in Part 9.

Matplotlib vs Seaborn

You now know both libraries. They are not rivals: Seaborn is built on Matplotlib, so every Seaborn chart is a Matplotlib chart underneath. The difference is how much work each one does for you.

Diagram: The same question, average order value per region, answered both ways. Matplotlib needs the averages worked out first; Seaborn takes the whole table and does the maths, adds error bars and takes the axis labels from the column names. (The bar order differs too: see the note below.)

Trap!

Look at the bar order. groupby sorts the regions A to Z (East, North, South, West), but Seaborn keeps the order they first appear in the file (West, South, North, East). When the order matters, give Seaborn order=[...].

In real work you use both: Seaborn draws the chart and does the maths, then Matplotlib adds the finishing touches. Seaborn's bars are ordinary Matplotlib bars, kept in ax.containers, so ax.bar_label() from Chapter 28 works on them.

Key takeaways

  • scatterplot adds columns as hue, size and style; lineplot draws the mean per x with a 95% band (estimator="sum", errorbar=None).
  • regplot / lmplot draw a fitted line (order=2 for a curve, ci=None for no band); residplot shows what the line misses.
  • sns.heatmap(table, annot=True, fmt=..., cmap=..., center=...) works for any correlation or pivot table; clustermap reorders similar rows.
  • Grids: FacetGrid + map, pairplot (every pair), jointplot (one pair with margins); figure-level charts return a grid g.
  • Contexts scale text for paper or slides; choose qualitative, sequential or diverging colours; use ax= for dashboards and g.savefig() to save.
