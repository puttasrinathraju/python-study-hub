11.1 Big Test: Sets

25 questions on Sets only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    3 [1, 2, 3]

    A set keeps each value once, so only 1, 2 and 3 remain. sorted() gives them back as a list in order.

  2. Basic. visits = ["Pune", "Goa", "Pune", "Delhi", "Goa"]. Use set() to print how many different cities there are.

    Your code should print exactly:

    3
    Answer

    set() drops the repeats, and len() counts what is left.

  3. Basic. tags = {"sql", "python"}. Add "excel", then add "sql" again. Print the tags sorted.

    Your code should print exactly:

    ['excel', 'python', 'sql']
    Answer

    add() puts one item in. Adding a value that is already there changes nothing.

  4. Basic. a = {1, 2, 3, 4} and b = {3, 4, 5}. Print the sorted union and the sorted intersection, with one print().

    Your code should print exactly:

    [1, 2, 3, 4, 5] [3, 4]
    Answer

    | (union) gives everything in either set. & (intersection) gives only what is in both.

  5. Basic. This code should check whether "apple" is in the set and print True, but it crashes. Fix it.

    It should print:

    True
    Answer

    Sets have no order, so there is no index like [0]. Use in to check if a value is there.

  6. Basic. Type exactly what this code prints.

    Answer
    [1, 2, 3, 4, 5]

    discard() of a missing value does nothing (no error). add(2) changes nothing. update() adds several values.

  7. Basic. A = {1, 2} and B = {1, 2, 3}. Print whether A is a subset of B, and whether B is a subset of A, with one print().

    Your code should print exactly:

    True False
    Answer

    A is a subset of B when every item of A is also in B. B has 3, which A does not have.

  8. Basic. This code should print ['SQL'], but it crashes because "Excel" is not in the set. Fix it.

    It should print:

    ['SQL']
    Answer

    remove() gives a KeyError for a missing value. discard() removes it if it is there and stays quiet if not.

  9. Medium. mon = {"Tea", "Coffee", "Samosa"} and tue = {"Coffee", "Juice", "Samosa"}. Print the items sold on both days (sorted), then the items sold on only one of the two days (sorted).

    Your code should print exactly:

    ['Coffee', 'Samosa']
['Juice', 'Tea']
    Answer

    & keeps what both days share. ^ (symmetric difference) keeps what is in exactly one of them.

  10. Medium. Type exactly what this code prints.

    Answer
    [2] [8] [2, 8]

    a - b is what only a has. The order matters: b - a is different. ^ is both differences together.

  11. Medium. Use a set comprehension to collect the remainders of the numbers 10 to 20 when divided by 4. Print them sorted.

    Your code should print exactly:

    [0, 1, 2, 3]
    Answer

    A set comprehension looks like a list comprehension with curly brackets, and repeats drop out.

  12. Medium. This code should print [1, 2, 3], but it crashes. Fix it.

    It should print:

    [1, 2, 3]
    Answer

    Sets cannot be joined with +. The union operator is | (or a.union(b)).

  13. Medium. text = "the cat and the hat and the bat". Print how many different words it has.

    Your code should print exactly:

    5
    Answer

    split() makes a list of words, set() keeps each word once, and len() counts them.

  14. Medium. Type exactly what this code prints.

    Answer
    True False True

    <= is subset (equal sets count). < needs B to have something extra. A and C share nothing, so they are disjoint.

  15. Medium. Start with an empty set (careful: {} is not a set). Add the numbers from range(5, 8) in a loop. Print the sorted set and its type, with one print().

    Your code should print exactly:

    [5, 6, 7] <class 'set'>
    Answer

    set() makes an empty set. {} makes an empty dictionary.

  16. Medium. required = {"Python", "SQL", "Excel"} and candidate = {"SQL", "Python", "Power BI"}. Print the missing skills (sorted), then whether the candidate has all the required skills.

    Your code should print exactly:

    ['Excel']
False
    Answer

    required - candidate is what is needed but missing. The candidate covers everything only if required is a subset.

  17. Medium. This code should print {1}, but it crashes. Fix it.

    It should print:

    {1}
    Answer

    {} is an empty dictionary, which has no add(). An empty set is set().

  18. Medium. team = {"Asha", "Ravi"}. A new group {"Neha", "Ravi"} joins. Update team in place with |=, then print the sorted team and its size.

    Your code should print exactly:

    ['Asha', 'Neha', 'Ravi'] 3
    Answer

    |= adds everything from the other set into this one. Ravi is already there, so the size is 3.

  19. Challenge. orders = ["O1", "O2", "O1", "O3", "O2", "O4"]. Print how many entries are duplicates: the total number of entries minus the number of different orders.

    Your code should print exactly:

    2
    Answer

    6 entries but only 4 different orders, so 2 entries are repeats.

  20. Challenge. words = ["Data", "data", "DATA", "Python", "python"]. Use a set comprehension with lower() to print the different words, ignoring capitals, sorted.

    Your code should print exactly:

    ['data', 'python']
    Answer

    Make every word small first, so "Data" and "DATA" become the same value and the set keeps one.

  21. Challenge. Students per course: python = {"Asha", "Ravi", "Neha", "Kiran"}, sql = {"Ravi", "Neha", "Imran"}, excel = {"Neha", "Kiran", "Imran"}. Print (sorted) the students in all three courses, then the students who take Python but neither of the others.

    Your code should print exactly:

    ['Neha']
['Asha']
    Answer

    Set operators chain: & twice keeps what all three share, and - twice removes anyone in the other two.

  22. Challenge. Type exactly what this code prints.

    Answer
    2 [1, 3, 5]

    A frozenset is a set that cannot change, but you can still combine it with others to make a new set.

  23. Challenge. The candidate has SQL and Excel, and the job needs SQL. This code should print True (the candidate covers the need). Fix it.

    It should print:

    True
    Answer

    The question is whether every needed skill is in have, so need must be the subset (or use have.issuperset(need)).

  24. Challenge. jan = ["a@x.in", "b@x.in", "c@x.in"] and feb = ["b@x.in", "d@x.in", "c@x.in", "b@x.in"] are customer emails per month. Print the retention rate: customers seen in both months divided by customers in January, as a percentage with 1 decimal (:.1%).

    Your code should print exactly:

    66.7%
    Answer

    Turn both lists into sets (the repeat in February drops out), intersect them, then divide: 2 of 3 is 66.7%.

  25. Challenge. booked = {9, 10, 14} (hours). Two requests: req1 = {11, 15} and req2 = {10, 16}. For each request, print Free if it shares no hour with booked (use isdisjoint), otherwise print Clash: and the sorted clashing hours.

    Your code should print exactly:

    Free
Clash: [10]
    Answer

    isdisjoint() is True when two sets share nothing. If they do share something, & shows exactly what.
