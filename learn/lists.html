Lists

The list is Python's most used collection: an ordered, changeable row of items. Learn to add, remove, sort and copy, and avoid the copying trap that catches everyone.

In this chapter you will learn

  • Add items with append(), insert() and extend()
  • Remove items with remove(), pop(), del and clear()
  • Sort with sort() and sorted(), and know the difference
  • Copy lists the right way and avoid the aliasing trap

What is a list?

A list holds many values in one variable, in a fixed order. You write it with square brackets and commas. Lists are mutable: you can change them after creating them.

PropertyListsMeaning
OrderedYesItems keep the order you put them in
MutableYesYou can change, add and remove items
DuplicatesAllowedThe same value can appear many times
IndexedYesGet items by position, starting at 0

Indexing and slicing

Lists use exactly the same indexing and slicing rules as strings.

Diagram: colors[1:3] takes index 1 and 2: Blue and Yellow.

Easy tip

colors[-1][2:] works in two steps. colors[-1] gives the string "Brown". Then [2:] slices that string. Reading chained brackets from left to right makes them easy.

Trap! append() vs extend()

append() adds its argument as one item, even if that argument is a whole list. You end up with a list inside a list.

Sorting: sort() vs sorted()

list.sort()

  • Sorts the list in place (changes it)
  • Returns None
  • Only works on lists

sorted(list)

  • Makes a new sorted list
  • The original is untouched
  • Works on any collection: tuples, strings, sets, dict keys
Trap! x = x.sort()

sort() changes the list and returns None. If you store its result, you lose your list.

key= tells Python what to sort by. key=len sorts by length, key=str.lower sorts as if everything were lowercase. You will use key= with lambda in the Functions chapter.

Copying lists: the aliasing trap

This is the most important idea in this chapter. Writing b = a does not copy a list. It creates a second name for the same list. Change one and you change "both".

Animated explainer: Two names, one list

  1. Python builds a list in memory (object 1) and points a at it.
  2. b = a does not build a new list. b now points at the same object 1.
  3. We change the first item through b. There is only one list, so object 1 changes.
  4. Printing a shows 99. Surprise! a and b are two names for the same list.
  5. copy() builds a brand-new list (object 2) with the same items.
  6. Changing c only changes object 2.
  7. a is safe. Use .copy(), [:] or list() whenever you need an independent copy.
Trap! Shallow copies of nested lists

copy() copies only the outer list. Inner lists are still shared. For lists inside lists, use copy.deepcopy().

Answer

Nested lists

A list can hold other lists. This is how you store a table: a list of rows.

Diagram: matrix[1][2]: row 1, then item 2 in that row, which is 6.

Looping over lists

Trap! Do not remove items while looping over the same list

Removing shifts the remaining items left, so the loop skips one. Loop over a copy (for x in nums[:]:) or build a new list instead.

Key takeaways

  • Lists are ordered, mutable, allow duplicates. Index from 0, slice like strings.
  • append() adds one item. extend() adds each item of another list.
  • remove(x) removes by value. pop(i) removes by index and gives it back.
  • sort() changes the list and returns None. sorted() returns a new list.
  • b = a does not copy. Use a.copy(), a[:] or list(a). Use deepcopy for nested lists.
  • Never remove from a list while looping over it.

    1. [1, 2, 3]
    2. [1, 2, 3, 4]
    3. [4]
    4. An error
    Answer

    [1, 2, 3, 4]. b and a are the same list. Use a.copy() to get an independent copy.

    2. del lst[2]
    3. lst.pop(2)

    2. [1, 2, 1, 2]
    3. [[1, 2], [1, 2]]

Flashcards

Four properties of a list
Ordered, mutable (changeable), allows duplicates, indexed from 0.
append() vs extend()
append(x) adds x as one item. extend(list) adds each item of the list.
remove() vs pop()
remove(value) deletes the first match by value. pop(index) deletes by position and returns the item.
sort() vs sorted()
lst.sort() changes the list and returns None. sorted(lst) returns a new sorted list and leaves the original alone.
How do you sort largest first?
lst.sort(reverse=True) or sorted(lst, reverse=True)
What does b = a do for lists?
Makes b another name for the same list. Changes through b show up in a.
Three ways to copy a list
a.copy(), a[:], list(a). For nested lists use copy.deepcopy(a).
How do you get an item from a nested list?
Chain the brackets: matrix[row][col], e.g. matrix[1][2].
Why not remove items while looping over the same list?
Items shift left and the loop skips some. Loop over a copy or build a new list.
Average of a list
sum(lst) / len(lst)
Quick way to remove duplicates (order not kept)
list(set(lst))
