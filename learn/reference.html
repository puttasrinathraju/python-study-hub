A dictionary maps unique keys to values. d[key] raises KeyError for a missing key; get() does not.

MethodWhat it doesExampleOutput

Built-in exceptions

Each error's name tells you what went wrong. Catch the specific one, like except KeyError:. Some are parents of others: LookupError covers IndexError and KeyError, ArithmeticError covers ZeroDivisionError and OverflowError, and OSError covers FileNotFoundError and PermissionError. except Exception catches almost everything except SystemExit and KeyboardInterrupt.
