19.1 Big Test: Classes & objects

25 questions on Classes and objects (OOP) only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    Room False

    A class is the blueprint and each call Room() makes a new, separate object, so r1 and r2 are not the same object.

  2. Basic. Write a class Product whose __init__(self, name, price) stores both values. Create Product("Pen", 10) and print its name and price with one print().

    Your code should print exactly:

    Pen 10
    Answer

    __init__ runs when the object is created. self.name = name stores the value inside that object.

  3. Basic. Write a class Circle that stores a radius and has a method area() returning round(3.14159 * radius ** 2, 2). Print Circle(2).area().

    Your code should print exactly:

    12.57
    Answer

    A method is a function inside the class. It reads the object's data through self.

  4. Basic. The starter has a Student class. Create Student("Asha", 70), change its marks to 82, and print Asha 82.

    Your code should print exactly:

    Asha 82
    Answer

    Attributes are like variables that belong to one object. You can read and change them with a dot.

  5. Basic. Give Product a __str__ method so that print(Product("Pen", 10)) prints Pen: Rs 10.

    Your code should print exactly:

    Pen: Rs 10
    Answer

    print() calls __str__ to get the text for an object. It must return a string.

  6. Basic. This code should print Tata, but it crashes. Fix it.

    It should print:

    Tata
    Answer

    Every method needs self as its first parameter. Python passes the object in automatically.

  7. Basic. Type exactly what this code prints.

    Answer
    WsCube Other WsCube

    b.school = ... creates an instance attribute on b only. a and the class still share the class attribute.

  8. Basic. This code should print 500, but it crashes. Fix the method.

    It should print:

    500
    Answer

    Inside a method, the object's data is self.balance. A plain balance is an unknown local name.

  9. Medium. Write Person with introduce() returning "Hi, I am <name>". Write Employee(Person) that also stores a company and overrides introduce() to add " from <company>", using super().introduce(). Print Employee("Asha", "TCS").introduce().

    Your code should print exactly:

    Hi, I am Asha from TCS
    Answer

    The child class reuses the parent's code with super() and only adds what is new.

  10. Medium. Write classes Circle(r) and Square(side), each with an area() method (circle: round(3.14159 * r ** 2, 2)). Loop over [Circle(1), Square(3)] and print each area.

    Your code should print exactly:

    3.14
9
    Answer

    Polymorphism: the loop calls area() on every shape without caring which class it is. Each class does its own maths.

  11. Medium. Type exactly what this code prints.

    Answer
    A C True

    B inherits hello() from A. C overrides it. A C object is still an A, so isinstance is True.

  12. Medium. Write BankAccount with a private __balance, a deposit(amount) that raises ValueError("Deposit must be positive") for 0 or less, and get_balance(). Deposit 500, then try to deposit -50 (catch it and print the message), then print the balance.

    Your code should print exactly:

    Deposit must be positive
500
    Answer

    The balance can only change through deposit(), which checks the amount first. That is encapsulation.

  13. Medium. Give Product an __eq__ method so two products are equal when their prices are equal. Print Product("Pen", 10) == Product("Pencil", 10).

    Your code should print exactly:

    True
    Answer

    a == b calls a.__eq__(b). Without it, two different objects are never equal.

  14. Medium. This code should print Item: Pen once, but it crashes. Fix __str__.

    It should print:

    Item: Pen
    Answer

    __str__ must return the text. Printing inside it returns None, and print() then fails.

  15. Medium. Write Booking with a class attribute count = 0 that goes up by 1 every time a booking is created. Create 3 bookings and print Booking.count.

    Your code should print exactly:

    3
    Answer

    A class attribute is shared by all objects. Change it through the class name, Booking.count.

  16. Medium. Write Booking(guest, amount) with a class method from_text(cls, text) that makes a booking from text like "Asha,4500" (amount as an int). Create one with Booking.from_text("Asha,4500") and print its guest and amount.

    Your code should print exactly:

    Asha 4500
    Answer

    A class method gets the class as cls, so it can build and return a new object: another way to create one.

  17. Medium. Type exactly what this code prints.

    Answer
    Rate cannot be negative
2500

    The setter runs on every r.rate = .... It accepts 2500 and rejects -5, so the rate stays 2500.

  18. Medium. This code should print Asha 90, but it crashes. Fix Student.__init__.

    It should print:

    Asha 90
    Answer

    When a child class has its own __init__, the parent's __init__ does not run unless you call super().__init__(...).

  19. Challenge. Give Product a __lt__ method that compares prices, so sorted() works on products. Sort [Product("Pen", 10), Product("Bag", 450), Product("Ink", 45)] and print the list of names, cheapest first.

    Your code should print exactly:

    ['Pen', 'Ink', 'Bag']
    Answer

    sorted() compares objects with <, which calls __lt__. Now your own objects can be sorted.

  20. Challenge. Write Employee(name, salary) with pay() returning the salary. Manager(Employee) also has a bonus and pay() returns salary + bonus. Intern(name, stipend) has pay() returning the stipend. Print the total of pay() for [Employee("Asha", 40000), Manager("Ravi", 60000, 15000), Intern("Neha", 12000)].

    Your code should print exactly:

    127000
    Answer

    Every class answers pay() in its own way, so one line can add up the whole payroll.

  21. Challenge. Write a Cart class: add(item, price, qty=1) stores a line, total() returns the sum of price × qty, and count() returns the number of units. Add ("Pen", 10, 3) and ("Bag", 450), then print the total and the count.

    Your code should print exactly:

    480 4
    Answer

    The object keeps its own list of lines, and the methods work on that list.

  22. Challenge. Type exactly what this code prints.

    Answer
    2 True False

    len(t) calls __len__ and x in t calls __contains__, so your object works like a built-in collection.

  23. Challenge. Each basket should have its own items, so this code should print []. Fix it.

    It should print:

    []
    Answer

    A list made as a class attribute is shared by every basket. Make a new list per object in __init__.

  24. Challenge. Write a class GST with a static method add(amount, rate=18) that returns the amount plus GST, rounded to 2 decimals. Print GST.add(1000) and GST.add(250, 5) with one print().

    Your code should print exactly:

    1180.0 262.5
    Answer

    A static method needs no object and no self. It is a plain function kept inside the class it belongs to.

  25. Challenge. rows = [("Asha", 82), ("Ravi", 67), ("Neha", 91)]. Write Student(name, marks) with grade() returning "A" for 75 or more, else "B". Make the objects with a list comprehension and print the names of the A-grade students.

    Your code should print exactly:

    ['Asha', 'Neha']
    Answer

    Turning rows of data into objects lets every record carry its own logic, like grade().
