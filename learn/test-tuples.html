10.1 Big Test: Tuples

25 questions on Tuples only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    <class 'int'> <class 'tuple'>

    Brackets alone do not make a tuple: (11) is just the number 11. The comma makes the tuple.

  2. Basic. Make a tuple rgb with 255, 128 and 0. Print it and its length with one print().

    Your code should print exactly:

    (255, 128, 0) 3
    Answer

    Round brackets with commas make a tuple. len() works just like with lists.

  3. Basic. week = ("Mon", "Tue", "Wed", "Thu", "Fri"). Print the first day, the last day, and the middle three days as a tuple, with one print().

    Your code should print exactly:

    Mon Fri ('Tue', 'Wed', 'Thu')
    Answer

    Indexing and slicing work the same as with lists. A slice of a tuple is a tuple.

  4. Basic. votes = ("A", "B", "A", "C", "A"). Print how many votes "A" got and the position of the first "C", with one print().

    Your code should print exactly:

    3 3
    Answer

    Tuples have only two methods: count() and index().

  5. Basic. point = (17.38, 78.48). Unpack it into lat and lon, then print Latitude: 17.38, Longitude: 78.48.

    Your code should print exactly:

    Latitude: 17.38, Longitude: 78.48
    Answer

    Unpacking gives each item of the tuple its own name, in order.

  6. Basic. This code should print (1280, 1080), but it crashes. Fix it.

    It should print:

    (1280, 1080)
    Answer

    Tuples are immutable: you cannot change an item. Build a new tuple and store it in the same name.

  7. Basic. Type exactly what this code prints.

    Answer
    9 14

    The right side is worked out first, using the old values: (9, 5 + 9). Then it is unpacked into a and b.

  8. Basic. This code should print Asha, but it crashes. Fix it.

    It should print:

    Asha
    Answer

    When unpacking, you need one name for every item: 3 items need 3 names.

  9. Medium. scores = (55, 72, 90, 64, 81). Use first, *middle, last to print the first score, the last score, and how many scores are in the middle.

    Your code should print exactly:

    55 81 3
    Answer

    The starred name collects everything in between (as a list).

  10. Medium. stock = ("pen", "ink", "pad"). Replace "ink" with "gel" by converting to a list and back to a tuple. Print the new tuple.

    Your code should print exactly:

    ('pen', 'gel', 'pad')
    Answer

    To change a tuple, turn it into a list, change the list, and turn it back with tuple().

  11. Medium. Type exactly what this code prints.

    Answer
    6 7 (2, 3)

    The first index picks the inner tuple, the second picks the item. A slice of the inner tuple is a tuple.

  12. Medium. rooms = (("R101", 2499), ("R102", 3499), ("R103", 1999)). Loop over it and print each room with its rate: R101: ₹2,499.

    Your code should print exactly:

    R101: ₹2,499
R102: ₹3,499
R103: ₹1,999
    Answer

    Each item is a pair, so you can unpack it right in the for line.

  13. Medium. Type exactly what this code prints.

    Answer
    <class 'tuple'> ('h', 'i') 5

    Values with commas are packed into a tuple even without brackets. tuple("hi") splits the text into letters. + joins the two tuples.

  14. Medium. A booking record is fixed, so it is a tuple: row = (101, "Asha", "Deluxe", 3499.0). Unpack it and print Asha booked Deluxe for ₹3,499.00.

    Your code should print exactly:

    Asha booked Deluxe for ₹3,499.00
    Answer

    Unpacking gives each column a clear name, which makes the next line easy to read.

  15. Medium. This code should print 1 [2, 3], but it crashes. Fix it.

    It should print:

    1 [2, 3]
    Answer

    Two names cannot take three values. A starred name (*y) collects all the extra values.

  16. Medium. data = (1, [2, 3]). The tuple cannot change, but the list inside it can. Append 4 to the inner list and print the tuple.

    Your code should print exactly:

    (1, [2, 3, 4])
    Answer

    The tuple still holds the same list. The list itself is mutable, so append() works.

  17. Medium. a, b, c = "x", "y", "z". In one line, rotate them so a gets b's value, b gets c's and c gets a's. Print all three.

    Your code should print exactly:

    y z x
    Answer

    Python packs the right side into a tuple first, then unpacks it, so no value is lost.

  18. Medium. This code should print 1, the position of "ink", but it crashes. Fix it.

    It should print:

    1
    Answer

    find() is a string method. Tuples only have count() and index().

  19. Challenge. temps = (31, 33, 31, 35, 31, 33). Print each different temperature once, in order of first appearance, with how many times it appears: 31: 3, 33: 2, 35: 1. Use count() and index().

    Your code should print exactly:

    31: 3
33: 2
35: 1
    Answer

    index(t) gives the first position of t. If it equals the current position, this is the first time we see t.

  20. Challenge. records = (("Asha", 82), ("Ravi", 67), ("Neha", 91)). Print Average: 80.0, then Above: Asha Neha (the names above the average).

    Your code should print exactly:

    Average: 80.0
Above: Asha Neha
    Answer

    Two passes: the first works out the average, the second compares each mark with it.

  21. Challenge. Each sale is (product, qty, price): sales = (("Tea", 3, 20), ("Coffee", 2, 45), ("Juice", 1, 60)). Unpack each sale in the for line and print the total bill.

    Your code should print exactly:

    210
    Answer

    Unpacking three values per row gives clear names for the maths: 60 + 90 + 60 = 210.

  22. Challenge. This code should print (3, 4, 5), but it crashes. Fix it.

    It should print:

    (3, 4, 5)
    Answer

    Tuples have no append(). Join a new one-item tuple with +, and remember the comma in (5,).

  23. Challenge. Type exactly what this code prints.

    Answer
    d ['a', 't', 'a']

    Unpacking works on any sequence, text too. first gets d and the starred name gets the rest as a list.

  24. Challenge. scores = (72, 55, 90, 64). Make a sorted tuple (lowest first) and print it. Then print the highest score using an index of that sorted tuple.

    Your code should print exactly:

    (55, 64, 72, 90)
90
    Answer

    sorted() returns a list, so wrap it in tuple(). The biggest value is then the last item.

  25. Challenge. Build a list of the squares of 1 to 5 with a loop, turn it into a tuple, and print the tuple and its type with one print().

    Your code should print exactly:

    (1, 4, 9, 16, 25) <class 'tuple'>
    Answer

    Collect in a list (it can grow), then lock the finished data in a tuple with tuple().
