12.1 Big Test: Dictionaries

25 questions on Dictionaries only, from basic to challenge. Try each one first, then open the answer. Back to the chapter.

  1. Basic. Type exactly what this code prints.

    Answer
    Rajeev 2

    Keys are unique. When a key appears twice, the last value wins, so there are only 2 keys.

  2. Basic. Make a dictionary prices with "tea" costing 20 and "coffee" costing 45. Print the price of coffee.

    Your code should print exactly:

    45
    Answer

    Each entry is key: value. Square brackets with the key read its value.

  3. Basic. person = {"name": "Asha", "city": "Pune"}. Print the "email" value with get(), showing Not given when it is missing.

    Your code should print exactly:

    Not given
    Answer

    get(key, default) never crashes: it gives the default when the key is missing.

  4. Basic. stock = {"pen": 10, "ink": 4}. Add "pad" with 7, change "ink" to 9, and delete "pen". Print the dictionary.

    Your code should print exactly:

    {'ink': 9, 'pad': 7}
    Answer

    Assigning to a new key adds it, assigning to an existing key updates it, and del removes it.

  5. Basic. marks = {"Asha": 82, "Ravi": 67}. Loop over items() and print one line per student: Asha: 82.

    Your code should print exactly:

    Asha: 82
Ravi: 67
    Answer

    items() gives (key, value) pairs, which you unpack in the for line.

  6. Basic. This code should print 0 for an item that is not in stock, but it crashes. Fix it.

    It should print:

    0
    Answer

    Square brackets give a KeyError for a missing key. get(key, 0) gives 0 instead.

  7. Basic. Type exactly what this code prints.

    Answer
    ['a', 'b'] [1, 2] True False

    in checks the keys only, so 1 in d is False even though 1 is a value.

  8. Basic. This code should print 20, but it crashes. Fix it.

    It should print:

    20
    Answer

    Inside { }, each key and value are joined with a colon :, not =.

  9. Medium. Count how many times each letter appears in "mississippi", using a dictionary and get(). Print the dictionary.

    Your code should print exactly:

    {'m': 1, 'i': 4, 's': 4, 'p': 2}
    Answer

    The counting pattern: counts.get(ch, 0) + 1 starts a new letter at 1 and adds 1 to a letter already seen.

  10. Medium. Type exactly what this code prints.

    Answer
    20000

    The first key picks the movie, the second picks a field inside it: 40 × 500.

  11. Medium. prices = {"tea": 20, "coffee": 45, "juice": 60, "lassi": 35}. Use a dictionary comprehension to keep only the items under ₹50, each with its price raised by 10. Print it.

    Your code should print exactly:

    {'tea': 30, 'coffee': 55, 'lassi': 45}
    Answer

    {key: value for ... if ...} builds a new dictionary, changing each value and keeping only the items that pass the test.

  12. Medium. items = ["pen", "pad"] and qty = [10, 4]. Make a dictionary with dict(zip(...)) and print it.

    Your code should print exactly:

    {'pen': 10, 'pad': 4}
    Answer

    zip() pairs the two lists, and dict() turns the pairs into keys and values.

  13. Medium. This code should print each name and mark, but it crashes. Fix it.

    It should print:

    Asha 82
Ravi 67
    Answer

    Looping over a dictionary gives only the keys. To get both key and value, loop over items().

  14. Medium. cart = {"rice": 2, "dal": 1, "oil": 1}. Remove "dal" with pop() and print the removed quantity. Then print the cart.

    Your code should print exactly:

    1
{'rice': 2, 'oil': 1}
    Answer

    pop(key) removes the key and gives back its value.

  15. Medium. Type exactly what this code prints.

    Answer
    {'name': 'John', 'age': 32, 'city': 'Pune'}

    update() changes keys that exist (age) and adds new ones (city) in one step.

  16. Medium. emp = {"E1": {"name": "Asha", "salary": 50000}, "E2": {"name": "Ravi", "salary": 42000}}. Print the total salary, using a loop over values().

    Your code should print exactly:

    92000
    Answer

    Each value is itself a dictionary, so person["salary"] reads the salary inside it.

  17. Medium. sales = [("North", 120), ("South", 80), ("North", 60), ("East", 50), ("South", 40)]. Add up the sales per region in a dictionary and print it.

    Your code should print exactly:

    {'North': 180, 'South': 120, 'East': 50}
    Answer

    This is GROUP BY in plain Python: one key per region, adding each amount to its own total.

  18. Medium. This code should print {'a': 2, 'b': 1}, but it crashes. Fix it.

    It should print:

    {'a': 2, 'b': 1}
    Answer

    counts[w] += 1 reads the old value first, which does not exist the first time: KeyError. get(w, 0) starts it at 0.

  19. Challenge. marks = {"Asha": 82, "Ravi": 67, "Neha": 91}. Without min(), loop over items() to find the student with the lowest marks. Print the name and the marks.

    Your code should print exactly:

    Ravi 67
    Answer

    Keep the best key so far. None means "nothing seen yet", so the first student always becomes the lowest.

  20. Challenge. movies = {"Ramayan": {"price": 1000, "seats": 20}, "Drishyam": {"price": 500, "seats": 40}, "Udta Teer": {"price": 400, "seats": 50}}. For the movies with at least 30 seats, print the full-house revenue: Drishyam: ₹20,000.

    Your code should print exactly:

    Drishyam: ₹20,000
Udta Teer: ₹20,000
    Answer

    Loop over the outer dictionary, then read the inner fields to filter and calculate.

  21. Challenge. students = ["Asha", "Ravi", "Neha"] and marks = [82, 34, 91]. Make a dictionary of name → "Pass" or "Fail" (35 or more passes) with a dictionary comprehension, zip() and a ternary. Print it.

    Your code should print exactly:

    {'Asha': 'Pass', 'Ravi': 'Fail', 'Neha': 'Pass'}
    Answer

    zip() pairs each name with its marks, and the ternary picks the value for each key.

  22. Challenge. Type exactly what this code prints.

    Answer
    point False

    A tuple can be a key because it cannot change. (2, 1) is a different tuple from (1, 2).

  23. Challenge. This code should add Python to Asha's skills and print ['SQL', 'Python']. Fix it.

    It should print:

    ['SQL', 'Python']
    Answer

    = replaces the whole list with a string. To add to the list inside, call append() on it.

  24. Challenge. text = "data is good data is power data". Count the words with a dictionary, then use a loop (not max()) to print the most common word and its count.

    Your code should print exactly:

    data 3
    Answer

    First count, then search the counts for the biggest one. "data" appears 3 times.

  25. Challenge. stock = {"pen": 12, "ink": 3, "pad": 7}. Print the items sorted by quantity, lowest first, one per line: ink: 3. Use sorted(stock, key=stock.get).

    Your code should print exactly:

    ink: 3
pad: 7
pen: 12
    Answer

    sorted(stock) sorts the keys, and key=stock.get sorts them by their values instead.
