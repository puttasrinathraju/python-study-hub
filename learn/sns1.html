Seaborn: statistical charts in one line

Seaborn is a charting library built on Matplotlib. You give it a DataFrame and the names of the columns, and it does the grouping, counting, averaging and colouring for you. It is always imported as sns, next to plt, because the finished chart is still a Matplotlib chart.

sns.set_theme() switches on Seaborn's look: a grey background with a white grid and softer colours. Call it once at the top. After that, plain plt.title(), plt.xlabel() and plt.show() work as in Part 9.

Easy tip

From here on, the examples start with these four lines and sales = pd.read_csv("sales_data.csv") (or tips = sns.load_dataset("tips")). They are hidden to save space; Edit and run includes them.

Compare the two ways to draw the average order value per category. Matplotlib needs the numbers worked out first. Seaborn works them out from the raw rows.

Histograms with histplot

sns.histplot() cuts a number column into ranges (bins) and counts the rows in each, like plt.hist(). Add kde=True for a smooth curve of the shape on top.

The shape is right-skewed: most orders are small, and a few big ones stretch the tail to the right. That is why the mean (₹3,097) is higher than the median (₹2,582).

Animated explainer: hue and multiple: four ways to share one histogram

  1. layer (the default): one see-through histogram per category, drawn on top of each other. Fine for 2 groups, busy for 4.
  2. stack: the categories sit on top of each other, so the tower's height is the total in that bin.
  3. dodge: thin bars side by side in every bin. Good for comparing a few groups bin by bin.
  4. fill: every bin is stretched to 100%, so you see each category's share of the bin. Small orders are mostly groceries and clothing.

stat= changes what the bar height means, and binwidth= sets the width of each bin instead of the number of bins.

OptionDoes

With a number column on both axes, histplot draws a 2D histogram: a grid of squares, darker where more orders fall.

Predict the output

  1. [1, 2, 3]
  2. [3, 2, 1]
  3. [6]
  4. [1, 1, 1]
Answer

[1, 2, 3]. Three bins: one 1, two 2s and three 3s. ax.patches are the bars, from left to right.

Smooth curves: kdeplot, rugplot and ecdfplot

A KDE (kernel density estimate) is a smooth version of a histogram. Curves are easier than bars to compare when there are several groups. common_norm=False gives every curve an area of 1, so a small group is not squashed flat.

Groceries and clothing orders are small and close together; electronics and furniture are bigger and spread wide. bw_adjust= sets the smoothing: below 1 is more wiggly, above 1 is smoother.

Trap!

A KDE can run past the real data: here it goes below age 18 and above 65, where there are no customers. Add cut=0 to stop the curve at the smallest and largest value.

A rug plot draws one small tick for every value along the axis, so you see the real data under the curve.

An ECDF (empirical cumulative distribution) climbs from 0 to 1. At any value on the x-axis, its height is the share of rows at or below that value. No bins and no smoothing to choose.

Read it at the dashed line: about half of every region's orders are ₹2,500 or less. Where one line sits to the right of another, that region has bigger orders.

Figure-level charts: displot

Seaborn has two kinds of functions. Axes-level functions (histplot, kdeplot, boxplot ...) draw one chart on the current axes. Figure-level functions (displot, catplot, and in Chapter 30 relplot, lmplot, pairplot, jointplot) build a whole figure and can split it into panels with col= and row=.

Exampleshistplot, kdeplot, countplot, boxplotdisplot, catplot

PanelsUse plt.subplots + ax=col="Region", row=..., col_wrap=2
Sizeplt.figure(figsize=(w, h))height=3, aspect=1.5 (per panel)

"{col_name}" in set_titles() is replaced by each panel's value (North, South ...). y=1.03 lifts the big title a little above the panels. Older code writes g.fig instead of g.figure; both work.

Trap!

A figure-level function always makes its own figure. Put it after plt.subplot(1, 2, 1) and you get an empty subplot plus a separate figure. For charts inside a grid, use the axes-level function with ax=: sns.histplot(..., ax=axes[0]).

Counting categories: countplot

sns.countplot() counts the rows in each category and draws a bar for each: a histogram for text columns. Give it only x= (upright bars) or only y= (sideways bars).

value_counts().index lists the categories from the most rows to the fewest, which makes a good order=. Sorted bars are much easier to read.

Predict the output

  1. [3, 1, 1]
  2. [1, 1, 3]
  3. [5]
  4. [3, 2]
Answer

[3, 1, 1]. Without order=, the bars come in the order the values first appear: UPI (3), Cash (1), Card (1).

Averages with error bars: barplot

sns.barplot() does not count. It shows the mean of y for each category, plus a black error bar: the 95% confidence interval, the range where the true average probably lies. A long error bar means the average is not very certain.

estimator= picks another summary, like "sum" or "median". errorbar=None removes the error bars. To colour the bars with a palette, set hue= to the same column as x= and hide the legend.

errorbar=The line shows
("ci", 95) (default)95% confidence interval of the mean
"sd"One standard deviation each side: the spread of the data
"se"One standard error
NoneNo error bar
Trap!

The course notes write ci=95. That is the old name: Seaborn 0.13 still accepts it but warns you. Write errorbar=("ci", 95). And palette= without hue= also warns now: add hue= (same column as x=) and legend=False, or use one color=.

Predict the output

  1. [3.0, 9.0]
  2. [6.0, 9.0]
  3. [2.0, 4.0, 9.0]
  4. [2.0, 1.0]
Answer

[3.0, 9.0]. barplot shows the mean: (2 + 4) / 2 = 3 for a, and 9 for b. A sum would give 6; countplot would give 2 and 1.

Spread by group: boxplot and violinplot

To compare the spread of a number across groups, use a box plot (Chapter 27 shows how to read one) or a violin. Seaborn draws one per category in one line.

Animated explainer: From box plot to violin

  1. A box plot shows five numbers per group: the median, the box from Q1 to Q3, the whiskers and the outliers.
  2. A violin shows the whole shape: it is wide where many bills are and thin where few are. The mini box inside is a tiny box plot.
  3. inner="quart" draws dashed lines at the quartiles and the median instead of the mini box.
  4. With hue="sex" and split=True, each violin has two halves: men on the left, women on the right. One chart, two comparisons.

Every point: stripplot and swarmplot

Box plots hide how many rows there are. A strip plot draws every row as a dot. jitter= moves the dots a little sideways so they do not sit on one line.

A swarm plot moves the dots so that none overlap, which shows the shape like a violin made of dots. It needs room, so use it for a few hundred rows at most.

A favourite of analysts: a box plot with the real dots on top. showfliers=False stops the outliers being drawn twice.

Means across groups: pointplot

sns.pointplot() shows the same mean and error bar as barplot, but as a dot, and joins the dots with a line. It is good for following one number across ordered groups, like quarters.

dodge=0.3 shifts the groups apart so their error bars do not cover each other. Electronics and furniture orders grow towards the festival quarter (Q4).

Trap!

Look at the y-axis: it runs only from about 3.7 to 4.1, so tiny differences look huge. The averages are 3.83 to 4.00 out of 5. Use plt.ylim(1, 5) when you want to show how small the gap really is.

Many panels at once: catplot

sns.catplot() is the figure-level version of all the category charts. Pick the chart with kind= and split it into panels with col= or row=.

kind=Same as
"strip" (default)stripplot
"swarm"swarmplot
"box" / "violin" / "boxen"boxplot / violinplot / boxenplot
"bar" / "point"barplot / pointplot

Trap!

Forget kind= and catplot draws a strip plot, not bars. Always write the kind you want.

Themes, styles and palettes

sns.set_theme(style=..., palette=...) sets the look of every chart after it. There are five styles. with sns.axes_style("ticks"): uses a style for just the charts made inside the with block.

sns.despine() removes the top and right border lines, like ax.spines[...] in Chapter 28. A palette is a list of colours. sns.color_palette(name) gives one, and .as_hex() shows the colour codes.

Easy tip

In Jupyter, set_theme() stays on for every later cell, like plt.style.use(). Undo it with sns.reset_defaults(). (On this site every code box starts fresh.)

Practice with real data: sales by category

  1. From sales, draw a histogram of Sales with 20 bins, stacked by Category (multiple="stack"), with the x label Sales (₹).

    Hint

    sns.histplot(data=sales, x="Sales", hue="Category", multiple="stack", bins=20), then plt.xlabel(...).

    Solution

    The legend shows the four categories; each tower is the total for its bin.

  2. Use sns.catplot to draw a box plot of Sales per Category, with one panel per Region (col="Region", col_wrap=2).

    Hint

    sns.catplot(data=sales, x="Category", y="Sales", kind="box", col="Region", col_wrap=2).

    Solution

    Four regions, so four panels. The pattern is the same everywhere: electronics and furniture orders are the big ones.

  3. Draw the total profit per category as bars, largest first (order=["Furniture", "Electronics", "Clothing", "Groceries"]), with estimator="sum", no error bars and a title.

    Hint

    sns.barplot(data=sales, x="Category", y="Profit", estimator="sum", errorbar=None, order=[...]).

    Solution

    Furniture earns the most profit (₹80,580) although electronics has the biggest sales: profit margins differ.

Key takeaways

  • sns.chart(data=df, x=..., y=..., hue=...): Seaborn groups, counts and averages from the raw rows; plt.title() and friends still work.
  • One column's shape: histplot (bins, kde=True, multiple=), kdeplot (smooth, cut=0), ecdfplot (share up to a value).
  • countplot counts rows; barplot and pointplot show the mean with a 95% interval (errorbar=, estimator=).
  • Spread: boxplot and violinplot (split=True); every row: stripplot and swarmplot.
  • Figure-level displot and catplot make panels with col=; style with set_theme, palette= (with hue=) and despine().

Chapter quiz
  1. What does hue="Region" do in a Seaborn chart?
    1. Sorts the bars by region
    2. Colours the data by region and adds a legend
    3. Makes one panel per region
    4. Filters to one region
    Answer
    Colours the data by region and adds a legend. hue= splits by colour inside one chart; col= (figure-level) makes panels.
  2. Which function draws a histogram of one number column?
    1. sns.countplot
    2. sns.histplot
    3. sns.barplot
    4. sns.boxplot
    Answer
    sns.histplot. histplot bins numbers. countplot counts the values of a category column.
  3. By default, what is the height of each bar in sns.barplot(data=df, x="city", y="sales")?
    1. The number of rows per city
    2. The total sales per city
    3. The mean sales per city, with a 95% interval
    4. The largest sale per city
    Answer
    The mean sales per city, with a 95% interval. barplot's estimator is the mean; add estimator="sum" for totals.
  4. What does this print?
    1. 2
    2. 3
    3. 1
    4. 0
    Answer
    2. Two different values, a and b, so two bars.

    1. One histogram per region, in panels of one figure
    2. A list of charts
    3. A pie chart
    4. An error
    Answer
    One histogram per region, in panels of one figure. displot is figure-level: col= makes one panel per value.
  6. You put sns.catplot(...) after plt.subplot(1, 2, 1). What happens?

    2. It makes its own new figure; the subplot stays empty
    3. It fills both subplots
    4. Nothing is drawn

    It makes its own new figure; the subplot stays empty. Figure-level functions always make their own figure. Use an axes-level function with ax= inside a grid.

    2. Draws the two groups as the two halves of each violin
    3. Splits the y-axis
    4. Removes the legend

    Draws the two groups as the two halves of each violin. Each violin shows one group on each side, so you compare them directly.
  8. Seaborn 0.13 warns about sns.barplot(data=df, x="cat", y="v", palette="pastel"). What is the clean fix?

    2. Add hue="cat", legend=False
