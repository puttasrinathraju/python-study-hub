# Python Study Hub: build notes

Everything needed to rebuild and extend the site at https://puttasrinathraju.github.io/python-study-hub/.
The published site is the repo root. This `source/` folder holds the build files.

## Layout
- `source/hub2/`: the site source (single-page app built from JS data files).
  - `parts.js` (PARTS, `chapter()`, `overview()`), `ch/NN_id.js` (one chapter each), `decks.js`, `realdata.js`, `mixed.js` (Part 3 "collections inside collections"; generated by `gen/gen_mixed.py`), `posters_*.js`, `ov_N.js` (Part overviews), `sheets.js`, `videos.js`, `reference.js` (generated by `genref.py`), `exercises.js` (generated by `gen/gen_ex.py`), `bigtests.js` (generated by `gen/gen_bigtests.py`), `engine.js` (all UI), `base.html` (CSS + shell), `py-worker.js` (Pyodide 0.27.7 runner in a Web Worker), `sw.js` (offline cache, VERSION `pyhub-v7`).
  - `build_site.py`: runs `node static_pages.js` (text pages in `learn/`, sitemap, no-JS fallback) then writes `site/`.
  - `extract.js` + `runcheck.py`: pull every runnable example/answer into `out/items.json` and run it in real Python. Must report `failed 0`.
  - `pyodide_check.js <prefix...>`: runs items in the browser's Python (needs the local test server). Use it for anything NumPy or platform-sensitive.
- `source/gen/`: generators. `bt/bt_NN_<chapterid>.py` = one Big Test each (see `bt_08_strings.py`).
- `source/merge_extra/`: `404.html` and the `v2/` forwarding stub. Copy these to the repo root on every deploy (never delete them).
- `img/` is NOT in source: copy the repo root `img/` folder into `hub2/img/` before building.

## Build, check, test, publish
```bash
cd source/hub2 && node extract.js && python3 runcheck.py      # must say failed 0
python3 build_site.py                                          # writes site/
# local test (Playwright + Chromium are preinstalled)
mkdir -p ../site_test && cp -r site/. ../site_test/ && cp -r ../merge_extra/. ../site_test/ && cp out/items.json ../site_test/
# pyodide_local: npm pack pyodide@0.27.7, extract package/* into site_test/pyodide_local/,
# plus numpy-2.0.2-cp312-cp312-pyodide_2024_0_wasm32.whl (stream github.com/pyodide/pyodide/releases/download/0.27.7/pyodide-0.27.7.tar.bz2 | tar -xj --wildcards '*/numpy-2.0.2-*.whl')
cd ../site_test && python3 -m http.server 8765      # run in background; open http://localhost:8765/?localpy#<route>
# publish: copy site/ + merge_extra/ to the repo root, commit, push to main (GitHub Pages serves main)
```
Browser Python is 32-bit (NumPy ints are int32). Never print dtypes/itemsize, huge int sums, or exact random values in checked answers. Never print a set of strings directly (order changes per run): use `sorted()`.

## Content rules (from the owner, Srinath)
- Plain, simple English. Short sentences. Indian context is fine (₹, Indian names and cities).
- Quality is 100% important. Save tokens wherever possible, but never at the cost of quality.
- Every code example/answer must be run in real Python (generators do this) and in browser Python.
- A chapter's test/project may only use concepts from that chapter and earlier chapters. Never use a later concept. No repeated questions.
