Part 4 · Functions · Overview

Part 4 overview: functions

Both function chapters on one page: how to define and call a function, every way to pass inputs, scope, and the advanced tools. The pairs people confuse most are in the "don't mix these up" tables.

The whole Part in 5 lines

  1. A function is a named block of code that runs only when you call it: def name(params): defines it, name(args) runs it.
  2. Parameters are the names in the def line. Arguments are the values you pass in the call.
  3. return hands a value back and ends the function. With no return, a function gives back None. print only shows text.
  4. Defaults (b=1), keyword arguments (f(b=2)), *args (extra values, as a tuple) and **kwargs (extra named values, as a dict) make calls flexible.
  5. Names made inside a function are local (the LEGB rule). lambda makes tiny functions, yield makes generators and @decorator wraps a function.

Key definitions

Function

A named, reusable block of code. It can take inputs and give back a result.

Defining vs calling

def only stores the function. Nothing inside runs until you call it with brackets.

Parameter

A name in the def line. It is a placeholder that receives a value when the function is called.

Argument

The actual value you pass when you call the function.

Return value

What return hands back. You can store it and keep calculating with it.

Default parameter

A parameter with a value already filled in. The caller can leave it out.

Keyword argument

An argument passed by name. The order no longer matters.

*args

Collects any number of extra positional arguments into a tuple.

**kwargs

Collects any number of extra keyword arguments into a dict.

Scope

Where a name can be seen. A name created inside a function is local to it.

LEGB rule

The order Python searches for a name: Local, Enclosing function, Global, Built-in.

lambda

A tiny function with no name and one expression. Mostly used for key= in sorted(), max() and min().

Recursion

A function that calls itself. It needs a base case that stops the calls.

Iterator

An object that hands out items one at a time with next(). Every for loop uses one behind the scenes.

Generator

A function that uses yield. It produces values one at a time, pausing between them.

Decorator

A function that wraps another function to add behaviour. Put @name above the def.

Try it yourself

Write each function, then call it. Every comparison table above also has an Edit and run this example button.

  1. Write grade(score) that returns "A" (90+), "B" (75+), "C" (50+) or "F". Then print [grade(s) for s in [95, 80, 52, 30]].

    Hint

    Use if / elif / else and return in each branch. Check the highest band first.

    Solution

    return ends the function, so once a band matches, the lower checks never run.

  2. Write stats(*nums) that returns the smallest, the largest and the average (rounded to 1 decimal). Then lo, hi, avg = stats(4, 9, 1, 6) and print 1 9 5.0.

    Hint

    *nums is a tuple, so min(), max(), sum() and len() all work on it. Return three values with commas.

    Solution

    Returning several values really returns one tuple, which you unpack into three names.

  3. Write make_bill(**items) that takes item=price pairs and returns the total. print(make_bill(tea=20, samosa=15, coffee=45)) should print 80.

    Hint

    items is a dict, so sum(items.values()) adds the prices.

    Solution

    **items gathers every keyword argument into a dict: {'tea': 20, 'samosa': 15, 'coffee': 45}.

  4. This function has the mutable default bug. Fix it so the two calls print ['x'] ['y'].

    Hint

    Change the default to None and create the list inside the function.

    Solution

    A default list is created once and shared by every call. None plus a new list inside gives each call its own list.

  5. products = [("pen", 10), ("bag", 450), ("book", 120)]. Print them sorted by price, most expensive first.

    Hint

    sorted(products, key=lambda p: p[1], reverse=True)

    Solution

    The lambda tells sorted() to compare item [1], the price, of each tuple.

    2. ['a', 'b']

    2. 5
    3. None
    4. An error
    Answer

    2. 12

    4. An error

    1. 4
    2. 10
    3. 24
    4. It never stops

    10. 4 + 3 + 2 + 1 + 0 = 10. The base case n == 0 stops the recursion.

  9. What does this print?

    1. after then 1
    2. 1
    3. 1 then after
    4. None
    Answer

    1. return ends the function at once, so the line after it never runs.

  10. What does this print?

    1. [1]
    2. [1, 2]
    3. 2
    4. <generator>
    Answer

    [1, 2]. list() keeps asking the generator for values until it runs out.

  11. Which def line is valid Python?

    1. def f(a, b=2):
    2. def f(a=1, b):
    3. def f(**kw, *args):
    4. def f(a b):
    Answer

    def f(a, b=2):. Parameters with defaults must come after the ones without, and *args comes before **kwargs.

  12. Why does sorted(words, key=len) have no brackets after len?

    1. It is a typo
    2. You pass the function itself, and sorted() calls it on each item
    3. len does not need brackets anywhere
    4. Brackets would sort in reverse
    Answer

    You pass the function itself, and sorted() calls it on each item. len is the function. len() would try to run it right away, with nothing to measure.

Flashcards

Parameter vs argument
A parameter is the name in the def line. An argument is the value you pass in the call.
print vs return
print shows text and the function gives back None. return hands the value back so you can use it.
What does a function return without a return line?
None.
What does *args become inside the function?
A tuple of the extra positional arguments.
What does **kwargs become inside the function?
A dict of the extra keyword arguments.
What is the LEGB rule?
The order Python looks up a name: Local, Enclosing, Global, Built-in.
Local vs global
Local names live inside one function call. Global names are made outside all functions and are visible everywhere.
Why is def f(x, items=[]) dangerous?
The list is created once and shared by every call. Use items=None and create the list inside.
When would you use lambda?
For a tiny one-off rule, usually as key= in sorted(), max() or min().
return vs yield
return gives one value and ends. yield gives values one at a time and pauses, making a generator.
What does every recursive function need?
A base case that stops it from calling itself forever.
What is a decorator?
A function that wraps another to add behaviour. You apply it with @name above the def.
Return several values
Separate them with commas. You get a tuple that you can unpack.
