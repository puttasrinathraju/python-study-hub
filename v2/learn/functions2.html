*args: any number of positional arguments

Put * before a parameter name and it collects all extra positional arguments into a tuple. The name args is just a convention.

A note on the course notebook

The notebook called add([11, 12]), passing one list, and then used sum(*args). It works, but by accident: args becomes ([11, 12],), a tuple holding one list, and *args unpacks it again. The normal way is to pass separate values, add(11, 12), and use sum(args). If you already have a list, unpack it in the call: add(*my_list).

**kwargs: any number of keyword arguments

Put ** before a parameter name and it collects all extra keyword arguments into a dictionary.

Easy tip

The course notebook wrote def getDetail(*kwargs) with one star. One star always means a tuple of positional values, whatever you name it. For keyword arguments you need two stars: **kwargs.

The usual order is: normal parameters, then defaults, then *args, then **kwargs.

Scope: where a variable lives

A variable created inside a function is local: it only exists while the function runs. A variable created outside all functions is global: it can be read anywhere.

Diagram: The LEGB rule: Python searches Local, then Enclosing, then Global, then Built-in. The first match wins.

Trap! Changing a global inside a function

Reading a global inside a function is fine. But as soon as you assign to a name inside a function, Python treats it as local for the whole function. So count += 1 tries to read a local count that does not exist yet.

Fix 1: global keyword

Works, but makes code harder to follow. Use sparingly.

Fix 2 (better): pass in, return out

The function gets what it needs as a parameter and returns the result.

The mutable default argument trap

This is a famous Python interview question. A default value is created once, when the function is defined, not each time it is called. If the default is a list, every call shares the same list.

lambda: tiny one-line functions

A lambda is a small function with no name, written in one line: lambda parameters: expression. It automatically returns the expression.

Lambdas shine when another function needs a small "rule", like key= in sorted(), max() and min().

map() and filter()

Easy tip

map and filter do the same jobs as list comprehensions. [x * 2 for x in nums] and [x for x in nums if x > 0] are usually easier to read. Know both, because you will see both in other people's code.

Recursion: a function that calls itself

A recursive function solves a problem by calling itself on a smaller version of the same problem. It must have a base case: a simple case it can answer directly, which stops the calls.

Animated explainer: The call stack for fact(4)

  1. fact(4) cannot answer yet. It needs fact(3), so it pauses and calls it.
  2. fact(3) also needs help, so it pauses and calls fact(2). The paused calls pile up like a stack of plates.
  3. fact(2) calls fact(1).
  4. fact(1) is the base case. It returns 1 straight away, with no more calls.
  5. Now the stack unwinds. fact(2) gets its answer: 2 x 1 = 2.
  6. fact(3) gets 2 back: 3 x 2 = 6.
  7. fact(4) gets 6 back: 4 x 6 = 24. Every paused call finished in reverse order.
Trap! No base case means no end

The course notebook shows a greet() that calls itself forever. Python stops it after about 1,000 calls with RecursionError: maximum recursion depth exceeded. Always check that each call moves closer to the base case.

Easy tip

Anything you can do with recursion, you can also do with a loop. For data analysis you will rarely need recursion, but it is common in interviews and for tree-shaped data like folders inside folders.

Iterators

An iterator hands out items one at a time. for loops use them behind the scenes. iter() makes an iterator, and next() asks it for the next item. When it runs out, it raises StopIteration, which is how a for loop knows to stop.

Generators and yield

A generator is an easy way to make an iterator. It looks like a function, but uses yield instead of return. Each yield hands out one value and pauses the function until the next value is requested.

Why analysts care

Generators produce values on demand, so they use almost no memory. Reading a 5 GB log file line by line works the same way. sum(x for x in range(10_000_000)) never builds a 10-million-item list.

Decorators

In Python, functions are objects: you can store them in variables and pass them to other functions. A decorator is a function that wraps another function to add extra behaviour, without changing its code. The @ line applies it.

Easy tip

You will use other people's decorators more than you write your own. You will see @property and @classmethod in the OOP chapter, and @app.route in Flask. Recognising the pattern is enough for now.

Key takeaways

  • *args collects extra positional arguments into a tuple. **kwargs collects keyword arguments into a dict.
  • Use f(*list) and f(**dict) to unpack when calling.
  • Local variables live inside a function. LEGB: Local, Enclosing, Global, Built-in.
  • Assigning inside a function makes a name local. Prefer passing values in and returning them out.
  • Never use a list as a default value. Use None and create the list inside.
  • lambda x: ... for small rules in sorted(key=...), map, filter.
  • Recursion needs a base case. Generators use yield. Decorators wrap functions with @.

Flashcards

What does *args do?
Collects any number of extra positional arguments into a tuple.
What does **kwargs do?
Collects any number of extra keyword arguments into a dictionary.
How do you pass a list as separate arguments?
Unpack it with a star: f(*my_list). For a dict of keyword arguments: f(**my_dict).
What is the LEGB rule?
Python looks up names in this order: Local, Enclosing, Global, Built-in.
Why does count += 1 inside a function raise UnboundLocalError?
Assigning makes count local, but it has no local value yet. Use global count, or better, pass it in and return it.
The mutable default trap
def f(x, lst=[]) shares one list across calls. Use lst=None and create the list inside.
Write a lambda that doubles a number
double = lambda x: x * 2
Sort a list of dicts by a field
sorted(rows, key=lambda r: r["marks"])
map vs filter
map(f, items) applies f to every item. filter(f, items) keeps items where f is truthy.
What is a base case?
The simple input a recursive function answers directly, without calling itself. It stops the recursion.
Generator vs normal function
A generator uses yield, hands out values one at a time, and pauses between them. It saves memory.
What does @log_call above a function do?
Replaces the function with log_call(function), a wrapped version with extra behaviour.
