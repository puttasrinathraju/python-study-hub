What is NumPy?

NumPy (Numerical Python) is a library for fast maths on large amounts of numbers. Its main tool is the array: a grid of values that are all the same type. It is used in data science, machine learning, scientific computing, AI, image processing and financial analysis.

Installing and importing

Spot the difference: no commas

A printed array has no commas: [1 2 3 4]. A printed list has commas: [1, 2, 3, 4]. That is the quickest way to tell which one you have. In Jupyter, if an array is the last line of a cell, it shows as array([1, 2, 3, 4]).

1D, 2D and 3D arrays

The number of dimensions (also called axes) is how many index numbers you need to reach one value.

Diagram: 1D: a single row. One index: a[2] is 20.

Diagram: 2D: a table of rows and columns. Two indexes: m[1, 2] is 35.

Diagram: 3D: a stack of 2D tables. Three indexes: layer, row, column.

Reading shape

shape is a tuple with one number per dimension. (4,) means 4 items in one row. (2, 3) means 2 rows, 3 columns (rows always come first). (2, 2, 2) means 2 layers of 2 rows and 2 columns. A pandas table of 1,000 rows and 8 columns has shape (1000, 8).

Trap! arange vs linspace

np.arange(start, stop, step): you choose the step, and stop is not included. np.linspace(start, stop, num): you choose how many numbers, and stop is included. np.arange(0, 10, 2.5) gives 4 numbers ending at 7.5, but np.linspace(0, 10, 5) gives 5 numbers ending at 10.

Easy tip

Newer NumPy code often uses a random generator object: rng = np.random.default_rng(42) then rng.integers(1, 10, 5) or rng.random(3). It does the same job and is the modern recommendation. You will see both styles.

One array, one data type

Every value in an array has the same type (dtype). If you mix types, NumPy quietly upcasts everything to a type that can hold them all.

Trap! One text value turns everything into text

If a single value in your data is text (like "N/A"), the whole array becomes strings, and maths on it fails. This is the NumPy version of the input() problem. Clean the data first, then convert with .astype(float).

Reshaping

reshape() reorganises the same values into a new shape. The total number of values must stay the same: 6 values can be 2 x 3 or 3 x 2, but never 4 x 2.

Animated explainer: Reshaping 6 values

  1. We start with 6 values in one row.
  2. reshape(2, 3): 2 rows of 3. NumPy fills the first row with the first 3 values, then the next row.
  3. reshape(3, 2): 3 rows of 2. Same values, same order, different shape.
  4. -1 means "work it out for me". With 6 values and 2 columns, NumPy calculates 3 rows.
  5. flatten() turns any shape back into a single row.
  6. 4 x 2 needs 8 values, but we only have 6. NumPy refuses.
Easy tip

ravel() does the same as flatten() but tries to avoid copying the data, so it is faster on big arrays. For learning, either is fine.

Key takeaways

  • import numpy as np. Arrays hold one data type and print without commas.
  • shape is (rows, columns). size is the total count, ndim the number of dimensions, dtype the type.
  • arange excludes the stop. linspace includes it and takes a count.
  • Mixed types are upcast: one string makes the whole array strings.
  • reshape(r, c) keeps the same values in a new shape. -1 means "work it out".
  • concatenate joins, vstack stacks as rows.

Flashcards

Why use NumPy arrays instead of lists for numbers?
Much faster, less memory, and maths works on the whole array at once (vectorised).
How do you create an array?
import numpy as np then np.array([1, 2, 3]).
What does shape tell you?
The size of each dimension: (rows, columns) for 2D, e.g. (3, 4).
size vs ndim vs dtype
size: total number of values. ndim: number of dimensions. dtype: the data type of every value.
arange vs linspace
arange(start, stop, step) excludes stop. linspace(start, stop, num) includes stop and gives num values.
What happens when you mix types in an array?
NumPy upcasts to one type: ints + floats become floats; any string makes everything strings.
How do you convert an array's type?
arr.astype(float) or arr.astype(int) (int cuts off decimals).
What does reshape(-1, 2) mean?
2 columns, and NumPy works out the number of rows.
np.vstack vs np.concatenate for two 1D arrays
vstack stacks them as two rows (2D). concatenate joins them into one long 1D row.
Make a 3 x 3 array of zeros
np.zeros((3, 3)) (note the double brackets: the shape is a tuple).
