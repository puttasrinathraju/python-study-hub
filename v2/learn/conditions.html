If, elif and else

Teach your program to make decisions: run some code only when a condition is True, and choose between several paths.

In this chapter you will learn

  • Write if, if-else and if-elif-else blocks
  • Put if statements inside each other (nesting)
  • Combine conditions with and, or and not
  • Know which values count as True or False (truthy and falsy)
  • Use the one-line if, pass, and match-case

The basic if

An if statement runs a block of code only when its condition is True. The condition is any expression that gives True or False.

Remember this

Get three things right every time. Put a colon at the end of the if line. Indent the lines inside by 4 spaces. Go back to the left when the block ends.

if-else: two paths

else gives Python something to do when the condition is False. Exactly one of the two blocks runs, never both.

Diagram: Only one path runs. Both paths meet again after the if-else block.

if-elif-else: many paths

elif is short for "else if". Python checks the conditions from top to bottom. The first True one wins, its block runs, and Python skips everything else in the chain. else at the end catches anything left.

Animated explainer: Watch Python walk down an elif ladder

  1. We start with a score of 85.
  2. First question: is 85 >= 90? No, it is False. Python skips the block under this if.
  3. Next question: is 85 >= 80? Yes, True. Python enters this block.
  4. It stores "B" in grade.
  5. A branch has run, so Python **skips all the remaining elif and else lines** and jumps to the first line after the chain. Line 6 was never even checked.
Trap! Order matters

Because the first True condition wins, put the strictest check first. If you check >= 45 first, a score of 92 matches it and never reaches the A grade.

Predict the output

  1. big
  2. big then medium
  3. medium
  4. big then small
Answer

big then medium. These are two separate if statements, not one chain. The first prints "big". The second is checked on its own and prints "medium".

Combining conditions

Use and, or and not to build bigger conditions. This BMI checker is from your course notebook.

Easy tip

bmi > 18 and bmi < 25 can be written as 18 < bmi < 25. Python allows chained comparisons and they read more naturally.

Trap! if x == 1 or 2

This looks right but is always True. Python reads it as (x == 1) or (2), and 2 on its own counts as True. Write the full comparison each time, or use in.

Nested if

You can put an if inside another if. The inner one is only checked when the outer one is True. This login check is from your course notebook.

Easy tip

Deep nesting gets hard to read. If you are three levels deep, try combining conditions with and, or use elif.

Truthy and falsy values

A condition does not have to be a comparison. Python can treat any value as True or False. These values count as falsy (False): 0, 0.0, "" (empty text), [], (), {}, set(), None and False. Everything else is truthy.

Short forms: one-line if and ternary

The ternary form is great when you just need to choose between two values. For longer logic, use a normal if-else block. It is easier to read.

pass: an empty placeholder

A block cannot be empty. If you want to write the logic later, put pass there. It does nothing, but keeps Python happy.

match-case (Python 3.10 and newer)

When you compare one value against many fixed options, match can be cleaner than a long elif chain. case _: catches everything else, like else.

Why analysts care

In data work, conditions decide how each row is labelled: "High value" customers, "Late" deliveries, "Weekend" bookings. Later, pandas lets you apply the same logic to a million rows at once.

Key takeaways

  • if condition: then an indented block. else: runs when the condition is False.
  • In an if-elif-else chain, only the first True branch runs. Put the strictest check first.
  • Combine with and, or, not. Never write x == 1 or 2. Write x in (1, 2).
  • Falsy: 0, 0.0, "", [], (), {}, set(), None, False. Everything else is truthy.
  • a if cond else b picks between two values. pass is an empty placeholder.

Flashcards

Syntax of if-elif-else
In an elif chain, how many branches run?
At most one: the first one whose condition is True. If none are True, else runs (if there is one).
Why does order matter in an elif chain?
The first True condition wins. Put the strictest condition (like >= 90) before looser ones (like >= 45).
List the falsy values
0, 0.0, "", [], (), {}, set(), None and False. Everything else is truthy.
What is wrong with if x == 1 or 2:?
It is always True, because 2 alone is truthy. Write if x == 1 or x == 2: or if x in (1, 2):.
What is a ternary expression?
A one-line if/else that picks a value: status = "Adult" if age >= 18 else "Minor".
What does pass do?
Nothing. It is a placeholder for a block you will fill in later.
What does case _: mean in match-case?
The default case. It matches anything not matched above, like else.
