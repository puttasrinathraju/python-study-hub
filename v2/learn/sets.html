Sets

A set is a bag of unique items with no order. It removes duplicates for free and compares groups in one line: who is in both lists, who is missing, who is new.

What is a set?

A set is a collection of unique items with no order and no index. Sets are mutable (you can add and remove items), but every item inside must be immutable, like numbers, strings or tuples.

PropertySets
OrderedNo. The printed order can differ from the order you typed
IndexedNo. s[0] is an error
DuplicatesNot allowed. Extra copies are dropped automatically
MutableYes, you can add and remove items
Items must beImmutable (hashable): numbers, strings, tuples. Not lists or dicts
Trap! {} is an empty dictionary, not a set

Curly brackets with nothing inside make a dictionary. Use set() for an empty set.

Easy tip

Sets of strings can print in a different order after you restart Python. That is normal. If you need a fixed order, wrap the set in sorted().

Easy tip

Prefer discard() when you are not sure the item exists. Use remove() when a missing item would mean a bug you want to hear about.

Set operations: comparing two groups

This is where sets shine. Imagine set a is customers who bought in September and set b is customers who bought in October. One operator answers each business question.

Animated explainer: The four set operations on a Venn diagram

  1. Two sets. The middle area holds items that are in both: 2, 7 and 8.
  2. Union a | b: everything in either set. "All customers from both months."
  3. Intersection a & b: only items in both. "Customers who came back."
  4. Difference a - b: in a but not in b. "Customers we lost." Order matters: b - a is a different answer.
  5. b - a: in b but not in a. "New customers this month."
  6. Symmetric difference a ^ b: in one set or the other, but not both. "Customers who came in only one of the two months."
OperationOperatorMethodGives
Uniona | ba.union(b)Everything in either
Intersectiona & ba.intersection(b)Only in both
Differencea - ba.difference(b)In a, not in b
Symmetric differencea ^ ba.symmetric_difference(b)In one, not both

Real-world uses

Why analysts care

Checking x in some_set is much faster than x in some_list for big collections. A list checks items one by one. A set jumps straight to the answer using a hash, like a book's index. With a million IDs, that is the difference between instant and painfully slow.

Key takeaways

  • Sets hold unique items, with no order and no index.
  • {} is an empty dict. Use set() for an empty set.
  • add() one, update() many. remove() errors if missing, discard() does not.
  • | union, & intersection, - difference, ^ symmetric difference.
  • Great for removing duplicates and fast in checks. Wrap in sorted() for a fixed order.

  7. Why does s[0] fail on a set?

    1. Sets are empty
    2. Sets have no order, so no index

Flashcards

Three key properties of a set
Unique items only, no order, no index.
How do you make an empty set?
set(). Writing {} makes an empty dictionary.
remove() vs discard()
Both delete an item. remove() raises KeyError if it is missing. discard() does nothing.
Union
a | b or a.union(b): everything in either set.
Intersection
a & b or a.intersection(b): only items in both.
Difference
a - b: items in a that are not in b. Order matters.
Symmetric difference
a ^ b: items in one set or the other, but not both.
How do you check if every item of A is in B?
A.issubset(B) or A <= B
What is a frozenset?
An immutable set. It can be used as a dictionary key or inside another set.
