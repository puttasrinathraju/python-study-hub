Functions: the basics

A function is a named, reusable block of code. Write it once, call it whenever you need it. This is how you stop copying and pasting code.

In this chapter you will learn

  • Define a function with def and call it
  • Tell parameters and arguments apart
  • Understand return, and why it is not the same as print
  • Use default values and keyword arguments
  • Return several values and write docstrings

What is a function?

A function is a block of code that does one specific job. It only runs when you call it. You have already used many functions: print(), len(), type(), input(). Now you will write your own.

Think of it like this

A function is like a recipe. Instead of explaining every step of making tea each time, you just say "make tea". The recipe is written once. You can follow it as many times as you like, with different ingredients (2 cups, less sugar).

Why use functions?What it means
ReusabilityWrite once, use many times. No copy-paste.

Defining and calling a function

Diagram: The parts of a function.

Trap! Define before you call

Python runs top to bottom. If you call a function on a line above its def, Python has not seen it yet. In Jupyter this often happens when you restart and run cells out of order.

Parameters and arguments

These two words confuse many beginners. Here is the difference.

Parameter

  • The name in the function definition
  • A placeholder, like an empty box
  • name in def greet(name):

Argument

  • The actual value you pass when calling
  • What goes into the box
  • "Ravi" in greet("Ravi")

return: sending a result back

return ends the function and hands a value back to the line that called it. You can store that value, print it, or use it in maths.

Animated explainer: Watch a function call jump in and out

  1. def only creates the function and gives it the name add. The code inside does not run yet.
  2. Line 5 calls add(5, 7). Python pauses this line and jumps into the function.
  3. The arguments are copied into the parameters: a = 5, b = 7. These are local variables. They only exist inside this call.
  4. The body runs: result is 12.
  5. return result sends 12 back to the line that called the function, and the function ends.
  6. Back on line 5, add(5, 7) is replaced by 12, so total = 12. The local variables a, b and result are gone.
  7. Line 6 prints the total.

print vs return

Your course notebook has a whole cell on this, because it is the most common functions mistake.

print() inside a function

  • Shows a value on the screen
  • The caller gets nothing back (None)
  • Good for messages to a human

return inside a function

  • Gives the value back to the caller
  • Nothing appears on screen by itself
  • Good for results you want to use later
Remember this

A function with no return (or a bare return) gives back None. If you see None printed where you expected a number, you probably used print instead of return inside the function.

Trap! Code after return never runs

return ends the function immediately. In the course's check_age example, the print after each return is never reached.

Predict the output

  1. positive not positive
  2. positive positive
  3. not positive
  4. None None
Answer

positive not positive. f(5) returns at the first return. f(-2) skips the if and reaches the second return.

Default values and keyword arguments

A default value is used when the caller leaves that argument out. A keyword argument passes a value by naming the parameter, so the order does not matter.

Trap! Defaults go last

Parameters with defaults must come after parameters without defaults.

Easy tip

When you call with both styles, positional arguments must come first: bill(500, tax=0.05) works, bill(tax=0.05, 500) does not.

Docstrings and help()

A docstring is a triple-quoted string on the first line inside a function, right under def. It explains what the function does. help() shows it, and Jupyter shows it when you press Shift + Tab inside the brackets.

Key takeaways

  • def name(params): creates a function. It runs only when called: name(args).
  • Parameters are the names in the definition. Arguments are the values you pass.
  • return gives a value back and ends the function. No return means None.
  • print shows. return hands back. Use return for results you want to use.
  • Defaults: def f(a, b=1). Keyword arguments: f(b=2, a=1). Defaults go last.

Chapter quiz

  1. What keyword starts a function definition?

    1. function
    2. def
    3. fun
    4. define
    Answer

    def. Python uses def.

  2. In def greet(name): and greet("Asha"), what is "Asha"?

    1. A parameter
    2. An argument
    3. A docstring
    4. A return value
    Answer

    An argument. The value passed in a call is an argument. name is the parameter.

  3. What does this print?

    1. hi then hi
    2. hi then None
    3. None
    4. An error
    Answer

    hi then None. The function prints "hi" and returns nothing, so x is None.

  4. What does this print?

    1. 5
    2. 15
    3. 10
    4. An error
    Answer

    15. b uses its default value of 10.

  5. What does this print?

    1. 10
    2. 7
    3. 25
    4. An error
    Answer

    10. Keyword arguments match by name, so order does not matter.

  6. What happens after a return line runs?

    1. The next line in the function runs
    2. The function ends and sends the value back
    3. The program stops
    4. Python returns to the top of the function
    Answer

    The function ends and sends the value back. return immediately ends the function.

  7. Which definition is valid?

    1. def f(a=1, b):
    2. def f(a, b=1):
    3. def f(a=1, b, c=2):
    4. def f(=1, b):
    Answer

    def f(a, b=1):. Parameters without defaults must come before parameters with defaults.

  8. What does this print?

    1. 8
    2. 5
    3. (1, 9)
    4. An error
    Answer

    8. The function returns (1, 9). 9 - 1 = 8.

  9. What does help(my_function) show?

    1. The source code
    2. The function's docstring
    3. Its return value
    4. Nothing
    Answer

    The function's docstring. help() displays the docstring, the triple-quoted text at the top of the function.

Parameter: the name in the def line. Argument: the actual value passed in the call.
What does return do?
Sends a value back to the caller and ends the function immediately.
What does a function return if it has no return?
None.
print vs return
print shows a value on screen. return gives it back so you can store or use it.
What is a default parameter?
A value used when the caller leaves the argument out: def greet(name="Guest").
What is a keyword argument?
Passing a value by naming the parameter: intro(age=21, name="Rahul"). Order does not matter.
How do you return two values?
return a, b returns a tuple. Unpack with x, y = f().
What is a docstring?
A triple-quoted description on the first line inside a function, right under def. Shown by help().
Why might you get NameError when calling your function?
You called it before the def line ran (or there is a typo in the name).
