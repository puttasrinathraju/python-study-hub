File handling

Save results to files and load data back in. Plain text, CSV, JSON and pickle: the four ways you will move data in and out of Python.

In this chapter you will learn

  • Open files with the right mode: r, w, a, x, and the binary b versions
  • Read with read(), readline(), readlines() and a for loop
  • Write and append text, and remember write() only takes strings
  • Always use with open(...) so files close automatically
  • Save and load data with csv, json and pickle

Why files?

Variables disappear when your program stops. Files keep data on your disk, so you can save results, load data from other people, and share work. The basic recipe is always: open the file, read or write, close it.

Opening a file: the modes

open(filename, mode) returns a file object. The mode tells Python what you plan to do.

ModeMeaningIf the file existsIf it does not exist
"r"Read (the default)Reads itFileNotFoundError
"w"WriteWipes it clean firstCreates it
"a"AppendAdds to the endCreates it
"x"CreateFileExistsErrorCreates it
"rb", "wb"Read / write binary dataUsed for pickle, images
"r+"Read and writeKeeps contentFileNotFoundError

Animated explainer: What each mode does to a file

  1. Here is demo.txt with two lines in it. Let us see what each mode does.
  2. r (read): you can read the contents. The file is not changed. This is the default mode.
  3. w (write): the moment you open with "w", the old content is deleted. Then your new text is written. Be careful!
  4. a (append): old content stays, and new text is added at the end. Notice we had to write \n ourselves to start a new line.
  5. x (create): only works if the file does not exist yet. A safe way to avoid overwriting something by accident.
Trap! "w" deletes what was there

Opening an existing file in "w" mode empties it immediately, even if you never call write(). If you want to add to a file, use "a".

Writing to a file

Trap from the course: write() only accepts strings

The notebook tried f.write(2000) and got an error. Convert numbers first with str() or an f-string.

The with statement (always use it)

with open(...) as f: opens the file and closes it automatically when the indented block ends, even if an error happens inside. No forgotten close(), no locked files.

Manual: easy to forget close()

with: closes for you (recommended)

Easy tip

Each line you read keeps its \n at the end. If you print it directly, you get an extra blank line. line.strip() removes it. This is why almost every file loop uses .strip().

Paths, and checking or deleting files

A file name like "demo.txt" is a relative path: Python looks in the current folder (in Jupyter, the folder the notebook is in). A full path like C:\Users\Raman\data.csv works from anywhere. On Windows, put r before the string so the backslashes are not treated as escape characters: r"C:\Users\Raman\data.csv".

CSV files

A CSV (comma-separated values) file is a table saved as text: one row per line, columns separated by commas. Excel opens it, and it is the most common data file you will receive. Python's built-in csv module handles the commas and quotes for you.

Why analysts care

In real projects you will usually load CSVs with pandas: pd.read_csv("sales.csv"). It does all of this in one line. But it helps to know that underneath, a CSV is just text, and every value comes in as a string until something converts it.

JSON files

JSON is the text format the web uses to send data. It looks almost exactly like Python dictionaries and lists. The json module converts between the two.

Easy tip

Notice how Python's True became true and None became null. That is JSON's spelling. The s in dumps and loads stands for string: those versions work with text in memory instead of a file.

pickle: save any Python object

pickle saves a Python object to a binary file and loads it back exactly as it was. It works for dicts, lists and even objects of your own classes. Saving is called serialization, loading is deserialization. Pickle needs binary modes: "wb" and "rb".

Easy tip

The course notebook saved its pickle into movie_ticket_db.txt. It works, because the extension is only a label, but if you open that file in Notepad you will see gibberish. Use .pkl so everyone knows it is a pickle.

Never unpickle files you do not trust

Loading a pickle can run code hidden inside it. Only load pickles you created yourself. For sharing data with others, use CSV or JSON.

Key takeaways

  • open(name, mode): r read, w overwrite, a append, x create new. Add b for binary.
  • "w" wipes the file the moment it opens. Use "a" to add.
  • Use with open(...) as f: so the file always closes.
  • write() needs a string and does not add \n. Read lines with for line in f: and .strip().
  • CSV for tables, JSON for nested data, pickle (wb/rb) for Python objects you made yourself.

Chapter quiz

  1. Which mode adds text to the end of a file without deleting what is there?

    1. "r"
    2. "w"
    3. "a"
    4. "x"
    Answer

    "a". a means append.

  2. What happens when you open an existing file with "w"?

    1. It adds to the end
    2. Its old content is deleted
    3. FileExistsError
    4. Nothing until you call write()
    Answer

    Its old content is deleted. w mode empties the file as soon as it opens.

  3. What does f.readlines() return?

    1. One string
    2. A list of lines, each keeping its \n
    3. The first line
    4. The number of lines
    Answer

    A list of lines, each keeping its \n. readlines() gives a list with one string per line.

  4. Why use with open(...) as f:?

    1. It is faster
    2. It closes the file automatically, even after an error
    3. It is the only way to read
    4. It creates a backup
    Answer

    It closes the file automatically, even after an error. The with block closes the file when it ends.

  5. What does f.write(2000) do?

    1. Writes 2000
    2. Writes "2000\n"
    3. Raises TypeError
    4. Writes nothing
    Answer

    Raises TypeError. write() only accepts strings. Use f.write(str(2000)).

  6. Which modes does pickle need?

    1. "r" and "w"
    2. "rb" and "wb"
    3. "a" and "x"
    4. Any mode
    Answer

    "rb" and "wb". Pickle stores binary data, so it needs binary modes.

  7. What does json.dumps({"a": True}) return?

    1. A dict
    2. The string {"a": true}
    3. A file
    4. {'a': True}
    Answer

    The string {"a": true}. dumps converts to a JSON string. Note True becomes true.

  8. Which mode fails if the file already exists?

    1. "w"
    2. "a"
    3. "x"
    4. "r"
    Answer

    "x". x is for creating a brand-new file only.

Flashcards

The four main file modes
r read, w write (wipes first), a append, x create (error if it exists). Add b for binary.
Safest way to open a file
read() vs readline() vs readlines()
Whole file as one string / next line / list of all lines.
Why use .strip() when reading lines?
Each line ends with \n. strip() removes it so you do not get blank lines or messy values.
What does write() need?
A string. It does not add a newline, so add \n yourself.
How do you check if a file exists and delete it?
os.path.exists("f.txt") and os.remove("f.txt") (after import os).
Save and load with pickle
json.dump vs json.dumps
dump writes to a file. dumps returns a string. Same for load / loads.
CSV vs JSON vs pickle
CSV: tables. JSON: nested data, readable, shareable. Pickle: any Python object, binary, only for your own trusted files.
