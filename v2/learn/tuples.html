Tuples

What is a tuple?

A tuple is an ordered collection like a list, but it is immutable: once created, its items cannot be changed, added or removed. You write it with round brackets.

Creating tuples

Trap! A one-item tuple needs a comma

Brackets alone are just maths grouping. It is the comma that makes a tuple.

Indexing, slicing and looping

Everything you learned about indexing and slicing lists works on tuples too. Slicing a tuple gives you a new tuple.

Only two methods

Because tuples cannot change, they only have two methods, and both just look things up.

Immutability

Need to change one? Your course notebook shows the trick: convert to a list, change the list, convert back. You are really building a new tuple.

Trap! A tuple can hold something that changes

The tuple itself cannot change which objects it holds. But if one of those objects is a list, the list can still change.

Packing and unpacking

Packing means putting several values into one tuple. Unpacking means taking them out into separate variables in one line. The number of variables must match the number of items.

Animated explainer: Unpacking a tuple

  1. Packing: three values travel together in one tuple called person.
  2. Unpacking: Python matches by position. Item 0 goes into the first name on the left.
  3. Item 1 goes into the second name.
  4. Item 2 goes into the third name. Three items, three names. If the counts do not match, you get a ValueError.
  5. A star * collects "everything else" into a list. Useful when you only care about the first or last items.

Why use a tuple?

  • Fixed records that should not change by accident: a date (2026, 10, 25), a GPS point (17.38, 78.48), an RGB colour.
  • Returning several values from a function: return (1920, 1080).
  • Dictionary keys: tuples can be keys if everything inside them is also unchangeable. Lists cannot.
  • Slightly faster and smaller than lists.

List [ ]

  • Mutable: add, remove, change
  • Many methods
  • Use for collections that grow or change: a shopping cart, a log of transactions

Tuple ( )

  • Immutable: fixed once made
  • Only count() and index()
  • Use for fixed records, function return values, dictionary keys
Why analysts care

When you read a database row in Python, it often comes back as a tuple, like (101, "Asha", "Deluxe", 3499.0). Unpacking it into named variables makes your code readable: booking_id, guest, room, rate = row.

Key takeaways

  • Tuples are ordered and immutable. Written with ( ), or just commas.
  • A one-item tuple needs a trailing comma: (11,).
  • Only two methods: count() and index().
  • Unpack with a, b, c = t. Use *rest to collect extras into a list.
  • Use tuples for fixed records, multiple return values and dictionary keys.

    Keys must be immutable (hashable), and lists are mutable. A key must never change, so only immutable types like str, int and tuple can be keys.

Flashcards

How is a tuple different from a list?
A tuple is immutable: after creating it you cannot add, remove or change items. A list can change.
How do you make a tuple with one item?
Add a trailing comma: (11,). (11) is just the number 11.
What is packing?
Putting several values into one tuple: person = "John", 25, "NY"
What is unpacking?
Taking items out into variables: name, age, city = person. Counts must match.
What does first, *rest = (1, 2, 3) give?
first = 1, rest = [2, 3] (a list).
How do you "update" a tuple?
Convert to a list, change it, convert back: t = tuple(list_version). Or join: t = t + (x,).
Three good uses for tuples
Fixed records (dates, coordinates), returning several values from a function, dictionary keys.
