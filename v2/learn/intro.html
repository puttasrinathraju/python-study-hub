What is Python?

Python is a programming language. A programming language is a way to give instructions to a computer. You type the instructions as plain text, and Python carries them out.

It was created by Guido van Rossum and released in 1991. Today it is one of the most popular languages in the world. It is easy to read, free, and works on Windows, Mac and Linux.

Think of it like this

Python is like a very obedient assistant. It does exactly what you write, in the order you write it. It never guesses what you meant, so small typos matter.

How Python runs your code

Python is an interpreted language. A program called the interpreter reads your code from top to bottom. It runs one line, then moves to the next. One exception: a SyntaxError anywhere stops the whole cell before any line runs.

Animated explainer: Watch Python run a program line by line

  1. Python always starts at the top. The yellow line is the line running right now.
  2. Line 1 runs print(). The text appears in the Output box.
  3. Line 2 creates a variable called city and stores the text "Jaipur" in it. Nothing is printed.
  4. Line 3 stores the number 31 in a variable called temp.
  5. Line 4 prints four things. The commas put a space between them.
  6. Python works out the right side first: 31 + 2 = 33. Then it stores 33 back in temp. The old value 31 is gone.
  7. Line 6 prints the new value. The program ends after the last line.

Running a cell

In Jupyter or Colab, click inside a cell and press Shift + Enter to run it. The number in In [3]: tells you the order cells were run in. If you run cells out of order, your variables can get confusing. When in doubt, use Kernel > Restart Kernel and Run All Cells (Jupyter) or Runtime > Restart session and run all (Colab).

Your first program: print()

print() shows something on the screen. Put text inside quotes. Numbers do not need quotes.

Notice the last line. Python worked out 10 + 5 first, then printed the answer. Each print() starts on a new line.

Predict the output

  1. 15 and 15
  2. 10 + 5 and 15
  3. 10 + 5 and 10 + 5
  4. An error
Answer

10 + 5 and 15. Anything inside quotes is text, so Python prints it exactly as written. Without quotes, 10 + 5 is maths, so Python prints 15.

Comments: notes for humans

A comment starts with #. Python ignores everything after # on that line. Use comments to explain why your code does something.

Easy tip

In Jupyter and VS Code, select some lines and press Ctrl + / to comment or uncomment them all at once. This is handy for switching code off while testing.

The syntax rules that matter

Syntax means the grammar rules of a language. Python has very few, but you must follow them exactly.

  1. One instruction per line. No semicolons needed at the end.
  2. **A colon : starts a block.** Lines like if, for, while and def end with a colon.
  3. Indentation marks the block. The lines inside a block are pushed right by 4 spaces. Python uses this instead of curly brackets { }.
  4. Case matters. print works. Print and PRINT do not.
  5. Quotes must match. "hello" and 'hello' are fine. "hello' is an error.

Correct

Error: no indentation

Trap!

Mixing tabs and spaces, or using 3 spaces on one line and 4 on the next, causes IndentationError. Jupyter inserts 4 spaces when you press Tab. Colab inserts 2 by default. Both work, as long as you stay consistent, so just press Tab and let the editor do it.

Errors are normal

Every programmer sees errors every day. An error message is Python telling you what went wrong and where. Read the last line first. It names the error type.

Key takeaways

  • Python runs code from top to bottom, one line at a time.
  • print() shows output. Text goes in quotes. Numbers and maths do not.
  • # starts a comment. Python ignores it.
  • A colon : opens a block, and 4 spaces of indentation keep lines inside it.
  • Read the last line of an error first. It tells you the error type.

Chapter quiz

  1. How does Python run the code in a cell or file?

    1. All lines at the same time
    2. From top to bottom, one line at a time
    3. From bottom to top
    4. Only the lines that contain print()
    Answer

    From top to bottom, one line at a time. The interpreter reads and runs one line, then moves to the next, from top to bottom.

  2. What does Python use to group lines into a block, for example the lines inside an if?

    1. Curly brackets { }
    2. Indentation (spaces at the start of the line)
    3. Semicolons ;
    4. The word end
    Answer

    Indentation (spaces at the start of the line). Python uses indentation, normally 4 spaces, after a line that ends with a colon.

  3. Which line is a Python comment?

    1. # total sales for March
    2. // total sales for March
    3. /* total sales */
    4. -- total sales
    Answer

    # total sales for March. Python comments start with #. The others are comment styles from other languages.

  4. What is printed?

    1. 21
    2. 7 * 3
    3. "7 * 3"
    4. An error
    Answer

    7 * 3. The maths is inside quotes, so it is text. Python prints the text exactly.

  5. Why does Print("hi") give an error?

    1. The quotes are wrong
    2. Python is case-sensitive, so Print is not the same as print
    3. You need a semicolon
    4. print only works with numbers
    Answer

    Python is case-sensitive, so Print is not the same as print. Python treats capital and small letters as different. The built-in function is print, all lowercase.

  6. You see IndentationError: expected an indented block. What is the most likely fix?

    1. Add 4 spaces at the start of the line after the colon
    2. Remove the colon
    3. Reinstall Python
    4. Put the code in quotes
    Answer

    Add 4 spaces at the start of the line after the colon. After a line ending with :, Python expects at least one indented line.

  7. In Jupyter, what does In [3]: beside a cell mean?

    1. This cell has 3 lines
    2. This was the 3rd cell run in this session
    3. There are 3 errors
    4. The cell will run 3 times
    Answer

    This was the 3rd cell run in this session. The number shows the order in which cells were run. It helps you spot cells run out of order.

Flashcards

What is Python?
A free, easy-to-read programming language. You write instructions as text and Python runs them, one line at a time.
What does print() do?
It shows a value on the screen, in the output area below the cell.
How do you write a comment?
Start it with #. Python ignores everything after # on that line.
How does Python know which lines belong to a block?
By indentation. The lines indented (usually 4 spaces) under a line ending in : form one block.
Is Python case-sensitive?
Yes. name, Name and NAME are three different names. Print is not print.
What is Jupyter Notebook?
A tool where you write code in cells, run each cell with Shift + Enter, and see the output right under it. Google Colab is the online version.
Which line of an error message should you read first?
The last line. It names the error type, like NameError, and says what went wrong.
What is the difference between print("5 + 5") and print(5 + 5)?
The first prints the text 5 + 5. The second does the maths and prints 10.
