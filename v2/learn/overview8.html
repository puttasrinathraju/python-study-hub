  4. Real-world tools (Parts 5–6): catch bad input with try / except, save data to files, import modules, and model real things with classes.
  5. NumPy and projects (Parts 7–8): arrays do fast maths on whole datasets, and every program is data structures plus functions plus a loop.

The 16 definitions that matter most

If you can explain each of these in one sentence and write the tiny example, you know the course. Each card links to the Part overview with the full comparison tables.

Variable

A name that points at a value.

Data type

The kind of value: int, float, str, bool, None, or a collection.

Operator

A symbol that does work on values: maths, comparisons, logic.

Condition

An expression that is True or False, used by if and while to decide what runs.

Loop

Repeats a block: for once per item, while until a condition becomes False.

String

An ordered, immutable sequence of characters.

List

An ordered, mutable collection that allows duplicates.

Tuple

An ordered, immutable collection: a fixed record.

Set

An unordered collection of unique items.

Dictionary

Key: value pairs, looked up by key.

Function

A named block that takes parameters and returns a result.

Exception

An error that happens while the code runs. try / except catches it.

File

Data saved outside your program, opened with with open(name, mode) as f:.

Module

A .py file of reusable code that you import.

Class and object

A class is a blueprint. An object is one thing built from it, with its own data and methods.

NumPy array

A grid of values of one type that does maths on every value at once.

Don't mix up: A script vs functions vs a class

ScriptFunctionsClass
Looks likeLines that run top to bottomEach job in its own defData and the functions that use it, together

Rule of thumb: Start with a script. When you copy code a second time, make it a function. When several functions share the same data, make it a class.

Try it yourself

Each task is a small piece of a real program, so it mixes several Parts at once. Every comparison table above also has an Edit and run this example button.

  1. book = {"Asha": [82, 91], "Ravi": [67, 58], "Neha": [95, 88]}. Write average(name) and print a report sorted from the highest average, like Neha: 91.5.

    Hint

    sum(marks) / len(marks) inside the function. Then sorted(book, key=average, reverse=True) and an f-string.

    Solution

    A dict holds the data, a function does one job, sorted() with key= orders the names, and an f-string prints the report.

  2. Make the gradebook survive a restart: save book to book.json, then write load_book() that returns the saved data, or {} if the file does not exist yet. Print load_book()["Asha"].

    Hint

    json.dump with "w". In load_book, put json.load in a try and catch FileNotFoundError.

    Solution

    This is exactly how the Part 8 projects start: try to load the saved data, and fall back to an empty one on the very first run.

  3. Write a Stock class with add(item, qty), remove(item, qty) (print Not enough pen if there is too little) and low(limit) that returns a sorted list of items below the limit. Test it to print Not enough pen and then ['ink', 'pen'].

    Hint

    Keep a dict in self.items. Use self.items.get(item, 0) so new items start at 0.

    Solution

    A class keeps the stock and the rules together. Inside, it uses a dict, get, an if, and a sorted comprehension: Parts 2 to 6 in one small object.

  4. A week of sales: sales = np.array([120, 340, 90, 410, 260, 380, 150]) and days = np.array(["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]). Print the best day, the average and the days above average.

    Hint

    days[sales.argmax()], sales.mean() and the mask sales > sales.mean() used on days.

    Solution

    argmax finds the position, the mask filters a second array of the same length, and no loop is needed.

    4. [0, 1, 2, 3]

    3. A set
    4. A dictionary
    Answer

    A dictionary. Look-ups by a key such as an ID are exactly what dictionaries are for.

Flashcards

= vs ==
= stores a value in a name. == compares two values and gives True or False.
What type does input() always give?
str. Convert it with int() or float() before doing maths.
for vs while
for walks through items or a range(). while repeats until its condition becomes False.
The five collections in one line each
String: text. List: ordered and changeable. Tuple: ordered and fixed. Set: unique, no order. Dict: key: value look-ups.
String vs tuple
Both are ordered and immutable. A string holds only characters, a tuple holds any values as a fixed record.
Mutable vs immutable types
Mutable: list, set, dict. Immutable: int, float, bool, str, tuple.
print vs return
print shows text. return hands a value back so other code can use it.
*args vs **kwargs
*args collects extra positional values into a tuple. **kwargs collects extra named values into a dict.
The try family
try the risky line, except a named error, else when it worked, finally always.
Pick a file format
Text for lines, CSV for tables, JSON for nested data, pickle for your own Python objects.
Class vs object
A class is the blueprint. An object is one thing built from it.
The four pillars of OOP
Encapsulation, inheritance, polymorphism, abstraction.
axis=0 vs axis=1
axis=0: down the rows, one result per column. axis=1: across, one result per row.
Filter a NumPy array with two conditions
Use & or |, with brackets around each condition.
How do you build any small program?
Choose the data structure, write one function per action, test with fixed values, then add the menu loop and save the data.
