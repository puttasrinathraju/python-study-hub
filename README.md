# Python Study Hub

A free, interactive Python course for aspiring data analysts, from your first `print()` to NumPy.

**Open it here:** https://puttasrinathraju.github.io/python-study-hub/

## What's inside
- 22 chapters in plain, simple English, in 8 parts
- Animated explainers that run code line by line, like a video you can pause
- Slide decks, mind maps and a revision poster for every chapter
- An overview page at the end of every Part (and one for the whole course): key definitions, big comparison tables, "don't mix these up" tables, a mixed quiz and flashcards
- A built-in Python runner (real Python 3.12 + NumPy, in your browser) under every practice task
- Predict-the-output puzzles, practice tasks with hidden solutions, quizzes, flashcards, a final exam and a cheat sheet
- Progress is saved in your browser

Built from my Data Analytics course material (Python module), plus the W3Schools Python topic list.
The Python runner uses [Pyodide](https://pyodide.org).
