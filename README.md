# Python Study Hub

A free, interactive Python course for aspiring data analysts, from your first `print()` to NumPy.

**Open it here:** https://puttasrinathraju.github.io/python-study-hub/

## What's inside
- 23 chapters in plain, simple English, in 8 parts
- A built-in Python runner (real Python 3.12 + NumPy, in your browser) under every practice task, with a **Check my answer** button, and a **Try it** button on every code example
- Plain-English hints when your code has an error, and a small celebration when you solve a task
- 115 quick fill-in-the-blank exercises (5 per chapter) with instant checking
- A full Python reference: every string, list, tuple, set, dictionary and file method, every built-in function, every keyword and the built-in exceptions, each with a runnable example
- Animated explainers that run code line by line, plus optional slide decks, mind maps and a revision poster for every chapter
- A painted picture cheat sheet for every Part (pictures made with AI; text and icons checked by hand), with a "Save as image" button
- An overview page at the end of every Part (and one for the whole course): key definitions, big comparison tables, "don't mix these up" tables, a mixed quiz and flashcards
- Real-data practice on a messy hotel bookings file, plus an end-to-end mini project
- A short video by a real teacher for every chapter (English, plus Telugu where a good one exists)
- Predict-the-output puzzles, practice tasks with hidden solutions, quizzes, a final exam, flashcards with spaced repetition, a cheat sheet and a glossary
- A plain-text version of every chapter (in `learn/`), so search engines and AI tools can read the course
- Save and load your progress as a file; progress is also saved in your browser
- Works offline after your first visit

Built from my Data Analytics course material (Python module), plus the W3Schools Python topic list.
The Python runner uses [Pyodide](https://pyodide.org).
